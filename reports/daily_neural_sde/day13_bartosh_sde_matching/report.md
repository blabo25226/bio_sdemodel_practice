## 1. 論文要約

### 1.1 問題と提案

潜在 SDE の通常の学習は、事後過程を数値積分し、その解を通して変分境界を逆伝播する。
SDE Matching は、その境界自体は変えず、推定の仕方だけをシミュレーションフリーにする。
事前過程は

$$
dz_t = h_\theta(z_t, t)\,dt + g_\theta(z_t, t)\,dw,
$$

で、\(h_\theta\) と \(g_\theta\) はニューラルネットである（式 (15)）。
事後周辺は、観測列 \(X\) を条件とする可逆な再パラメータ化

$$
z_t = F_\varphi(\varepsilon, t, X) = \mu_\varphi(X, t) + \sigma_\varphi(X, t)\,\varepsilon, \qquad \varepsilon\sim N(0, I)
$$

で直接サンプルする（式 (16)、式 (37)。\(\sigma_\varphi\) は対角）。
この流れの時間微分 \(\bar f_\varphi\) を確率流の恒等式で SDE のドリフトに戻すと、事後ドリフトは

$$
f = \bar f_\varphi + \tfrac12 g_\theta g_\theta^\top \nabla\log q_\varphi + \tfrac12 \nabla\cdot(g_\theta g_\theta^\top)
$$

になる（式 (19)–(20)）。拡散 \(g_\theta\) は事前と事後で共有する。
損失は事前の初期 KL、拡散のずれ \(\tfrac12\|g^{-1}(h-f)\|^2\) の時間積分、観測の再構成、の和である（式 (21)–(24)、Algorithm 1）。
積分は一様時刻の 1 サンプルで置き、事後 SDE は解かない。

実験は 3 次元の確率 Lorenz、モーションキャプチャ、振り子の動画である。
付録 C.3 は状態依存の拡散が必要な例として、確率 Lotka–Volterra を置いている。
本文は、同じ変分境界を随伴法で最適化した場合と精度が同程度で、1 step のコストが小さい、と述べている。

### 1.2 選定理由

Day 1 は Lorenz 上の随伴勾配、Day 10 は逆時間のスコア SDE、Day 12 は経路の二時刻カーネルスコアである。
本日は、時系列の変分境界を事後周辺の直接サンプルで最小化する、という未使用の学習を選んだ。
採録は ICML 2025 で、drift と diffusion がどちらもニューラルネットである査読付き論文のうち新しいものである。
NeurIPS 2025 の Neural Stochastic Flows は遷移法則を正規化流で学ぶため、本日の枠の外に置いた。
系は付録 C.3 の Lotka–Volterra にした。Day 1 がすでに Lorenz を蒸留している。

この 2 次元座標は個体群の観測座標であり、遺伝子規制の式でも潜在遺伝子空間の式でもない。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと teacher

データ法則は次の乗法ノイズ付き Lotka–Volterra である。
ドリフト係数は Course & Nair (NeurIPS 2023) 付録 G.1 の \(\alpha=2/3\)、\(\beta=4/3\)、\(\delta=\gamma=1\)。
Bartosh ら付録 C.3 は拡散を \(\sigma=0.15\) の乗法ノイズに置き換えている。
\(T=6\)、保存刻み \(\Delta t=0.1\)（60 步、61 点）。生成は 1 保存步あたり 5 步の Euler–Maruyama（生成刻み 0.02）である。

$$
\begin{aligned}
dx &= \big(\tfrac{2}{3} x - \tfrac{4}{3} x y\big)\,dt + 0.15\, x\, dW^{1},\\
dy &= \big(x y - y\big)\,dt + 0.15\, y\, dW^{2}.
\end{aligned}
$$

初期条件は決定論的平衡 \((1, 1/2)\) の周りの対数正規（対数標準偏差 0.25）を \([0.25, 2.5]\times[0.12, 1.8]\) に切ったものである。
分割は軌道単位で train 128 / validation 64 / test 128。query の非有限脱落は 0 である。
train 軌道の平均は \((0.984,\ 0.503)\)、標準偏差は \((0.332,\ 0.210)\)。
teacher はその正規座標 \(z\) の上で学ぶ。報告する場は \(h_x=\mathrm{std}\cdot h_z\)、\(g_x=\mathrm{std}\cdot g_z\) で元の \((x,y)\) に戻してある。線形変換なので伊藤補正は付かない。

状態依存 teacher の事前は、入力 \((z_x, z_y, t/T)\) の MLP（幅 32、tanh 2 層、出力 2）。
拡散は同じ形の MLP に softplus と床 \(10^{-3}\) を足した対角である。
事後は、観測を時刻の逆順に通した GRU（隠れ 32）の文脈から、\(\mu\) と \(\sigma\) を別の MLP で出す。
\(\sigma\) は床 0.05 に softplus を足す。観測モデルは正規座標の等方 Gauss で、標準偏差は床 0.05 に softplus を足した学習スカラーである。
学習は Algorithm 1 の 1 サンプル推定で、拡散項には区間長 \(T\) を掛け、再構成項には観測数 61 を掛ける。
Adam（学習率 \(10^{-3}\)）、1200 step、バッチ 32、勾配クリップ 1。非有限の step は 0 であった。
状態依存 teacher の損失は 2472 から 180 まで動いた（終端で事前 KL 3.84、拡散 11.1、再構成 165、\(\rho=0.290\)）。

H6 のベースラインは、同じ初期化手順・同じ step 数・同じミニバッチ乱数で、拡散ネットの入力を \(t/T\) だけにしたものである。
終端損失は 147（拡散 11.6、再構成 131、\(\rho=0.289\)）。蒸留するのは状態依存 teacher だけである。

### 2.2 逸脱の明示

1. **モーションキャプチャと振り子動画を使わない。Lorenz も繰り返さない**: 前者は外部の高次元系列、後者は Day 1 の系である。データ法則は付録 C.3 の 2 次元伊藤拡散にした。論文の Lorenz 図と動画は再現していない。随伴法の teacher は学習していない。H6 は付録 C.3 が対比している状態依存拡散と状態非依存拡散である。
2. **潜在状態を置かない**: 論文の \(z\) は観測ネット \(p(x\mid z)\) の背後にあり、識別できない。本日の事前状態は観測された \((x,y)\) で、拡散は対角である。デコーダは正規座標の等方 Gauss に固定し、尺度だけ床の上で学習する。
3. **短い軌道を多数使う**: Course & Nair の 50 秒・10 Hz の 1 本系列ではなく、\([0,6]\) の 320 本である。軌道単位の分割にするためである。
4. **幅 32、GRU 1 層、softplus の床**: 論文は Li et al. (2020) の幅と \(\log\sigma\) を使う。\(\sigma=\sigma_{\mathrm{floor}}+\mathrm{softplus}\) はスコア \(\varepsilon/\sigma\) を有限に保つ数値上の置き換えである。事前拡散にも床 \(10^{-3}\) を足す。
5. **1200 step の Adam、CPU**: 論文の Lorenz 実験は随伴法より少ない関数評価で同程度の境界に達する、という計算比較であり、その wall-clock は再現していない。
6. **損失は式 (23) の時間積分を一様時刻 1 点で推定する**: 再構成は観測添字 1 点に観測数を掛ける。これは Algorithm 1 のとおりである。追加の重みは掛けていない。
7. **正規化は train 軌道だけ**: 検証と test の query にはこの平均と標準偏差を使う。SINDy の標準化は train query だけから取り直す。

真値の場は上の閉じた形である。対 teacher の指標と対真値の指標は結果の表で分けた。

## 3. 仮説（config に事前凍結）

実行前に `configs/daily_neural_sde_day13.json` へ書いた。test のあとでしきい値は動かしていない。

- **H1** (drift): test で symbolic 対 teacher の NRMSE \(\le 0.25\)、teacher 対真値 \(\le 0.40\)、symbolic 対真値 \(\le 0.50\)。三つとも必要。残差 RMS は併記し、ゲートにはしない。
- **H2** (diffusion): symbolic 対 teacher \(\le 0.30\)、teacher 対真値 \(\le 0.40\)、symbolic 対真値 \(\le 0.50\)、\(\Sigma=g^{2}\) の symbolic 対 teacher \(\le 0.45\)。
- **H2c**: test query のうち symbolic \(g\) の成分が 0 以下になる行の割合 \(\le 0.02\)。
- **H3**: 係数回復の仮説は置かない。次数 3 の VIF 最大（定数列を除く）が 10 を超えたら係数読みは不定。10 以下でも閉じた形としては読まない。
- **H4**: test の 128 本、同じ初期条件、同じ Wiener 増分。失敗率は各モデル \(\le 0.05\) かつ symbolic と teacher の差 \(\le 0.02\)。失敗クラスは `non_finite`、`negative_state`、`outside_radius`。\(\|X\|>5\) の逸脱率の差 \(\le 0.10\)。失敗率ゲートと H7 を通過したときだけ、平均経路の RMSE（symbolic 対 teacher \(\le 0.30\)、teacher 対真値 \(\le 0.40\)）と終端共分散の相対 Frobenius（symbolic 対 teacher \(\le 0.50\)）を判定する。
- **H5**: 同じ初期法則から引き直した平均経路 RMSE は teacher 対観測 \(\le 0.35\)、symbolic 対観測 \(\le 0.45\)。終端共分散の相対 Frobenius は teacher \(\le 0.55\)、symbolic \(\le 0.70\)。失敗率 \(>0.05\)、または真値対観測のフロアが teacher のしきい値を超えたら不定。
- **H6**: 同じ test query で、拡散の対真値 NRMSE は状態依存 teacher が時刻だけの拡散より 0.05 以上小さく、かつ状態依存側が 0.40 以下。両方 0.80 以上なら共倒れと記録する。drift の差は報告のみ。
- **H7**: teacher の \(\Delta t=0.1\) と \(\Delta t=0.02\)（細増分 5 本の和を \(\sqrt{5}\) で割った粗増分）の終端 RMSE \(\le 0.50\)、かつ両方が有限な割合 \(\ge 0.95\)。外れたら H4 の平均と共分散は不定。

## 4. 方法

teacher への直接 query。特徴は観測軌道上の \((x,y,t)\)（各分割の全時刻。train 7808、validation 3904、test 7808）。
SINDy の標準化は train query だけから取る。ライブラリは \((x,y,t)\) の冪だけである。
次数 \(\{1,2,3\}\)、しきい値 \(\{0.02,0.05,0.1,0.2,0.35\}\)、ridge \(10^{-4}\)。
drift と diffusion を別々に、validation の pooled NRMSE 最小で選ぶ。同点はより小さい次数、次に小さいしきい値。
test はこの選択のあと 1 回。

選択結果: drift は次数 3・しきい値 0.02（標準化座標で活性 25、ライブラリ 20 項、検証 NRMSE 0.0947）。
diffusion は次数 3・しきい値 0.02（活性 14、検証 NRMSE 0.0321）。
シミュレーションは失敗をラッチし、`non_finite`、`negative_state`、`outside_radius` を分ける。
対の真値積分は保存軌道の再読込ではなく、同じ初期条件を保存刻み \(\Delta t=0.1\) で閉じた形から積分したものである。

### 5.2 変分境界は場を回復していない

H1 の対 teacher は 0.124（残差 RMS 0.00969）で、しきい値 0.25 の内側にある。
同じ query への次数 3 OLS は 0.124 で、しきい値 0.02 の SINDy と同じである。
活性は 40 係数中 25 なので、対 teacher の残りは疎化のしきい値だけでは説明できない。
対真値は teacher も symbolic も 0.78 で、残差 RMS 0.188 は真値 RMS 0.241 の約 8 割である。
oracle は \(2.5\times 10^{-15}\) なので、次数 3 の冪は真の双一次ドリフトを表現できる。
config の帰属規則により、この失敗はライブラリの次数不足ではなく teacher の場に帰属する。

拡散も同じ構造である。対 teacher は 0.0364（残差 RMS 0.00226）、OLS は 0.0231。
対真値は 0.546 で、残差 RMS 0.0681 は真値 RMS 0.125 の約半分である。
零関数の NRMSE は 1 なので、学習された拡散は零ではない。水準が真値より小さい。
oracle は \(1.8\times 10^{-15}\) なので、真の \(0.15x\) と \(0.15y\) はライブラリの中にある。

終端の損失は再構成 165 に対し拡散項 11.1 である。\(\rho\) は 0.150 から 0.290 へ増えた。
train 上の事後標準偏差の平均は 0.110（最小 0.085、最大 0.172）で、teacher の \(g\sqrt{\Delta t}=0.0276\) の 3.99 倍である。
真値の \(g\sqrt{\Delta t}\) は 0.0536 である。
事後の雲が 1 步の拡散より広いとき、式 (23) が見ているのはその雲の速度であって、乗法ノイズの場そのものではない。
Day 12 の「カーネル幅が 1 步の拡散より広い」は、本日は「事後 \(\sigma\) が \(g\sqrt{\Delta t}\) より広い」として現れた。
平均の比で見た teacher の 1 步は \(|h|\Delta t=0.00938\) に対し \(g\sqrt{\Delta t}=0.0276\)（比 0.339）で、学習後の更新は拡散側が大きい。真値の拡散步よりは小さい。
