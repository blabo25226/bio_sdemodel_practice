# Reflections log — Daily Neural SDE → SINDy

各日の反省を 1 行ずつ追記する。翌日の分析は最低 1 つを適用し、レポートに適用した旨を書く。

| Day | Reflection |
|---|---|
| 1 | 推定器の離散化バイアスを最初に疑うこと (線形成分と非線形成分で $\hat g$ を比較し、補正次数への安定性を見る)。係数回復の仮説には共線性診断をセットで事前に置き、field 水準と係数水準の仮説を分ける。diffusion の絶対水準が主題の日は 1-step 尤度でなく内部 substep のシミュレーションに基づく推定を使う。 |

| 3 | 推定器の $g$ 一点比較は差が $10^{-3}$ 程度の同点域では優劣を検出できないため、$g$ 条項には同点域を事前に設けるか drift のレジーム別誤差を主条項にすること。終端観測のみの変分フィットでは $A$ の同定を仮説に含めず、弱同定そのものを結果として測ること。メッシュ研究ではモンテカルロ誤差が効果量より大きい場合、共通乱数によるメッシュ間結合を使うこと。off-manifold 格子がデータ範囲と重なる場合は強い外挿主張をしないこと。 |
| 4 | シミュレーション検証の判定条項には失敗率とは別にドメイン妥当性 (v < 0 逸脱率など状態の許容領域からの逸脱率) を事前に含めること。drift の弱同定が疑われる系では drift の NRMSE 比較だけで推定器の優劣を判定せず、絶対誤差と $\Sigma$ の誤差を併記し、真値 field がゼロ付近を通るレジームの分母効果に注記すること。downstream 指標では点推定の合格だけでなく paired 標準誤差も判定文に含め、paired SE がしきい値と同程度の場合は「統計的に確定しない」と明記すること。多項式の高次係数が on-manifold の打ち消しで大きくなっている場合は物理的意味として読まず、off-manifold での発散リスクとして明記すること。 |
| 5 | 単一初期条件からの周辺分布一致だけでは SDE の field は同定されないこと ($W_2$ teacher は分布損失 0.00395 と真値フロアに近いのに drift NRMSE 1.32、$\Sigma$ NRMSE 0.99)。$W_2$ 型 teacher の評価では分布損失に加えて遷移レベルの指標を必ず併記すること。teacher の field が真値から大きくずれている場合、蒸留・シミュレーション・downstream の「成」は真値について何も言わないため、対 teacher 指標と対真値指標を同じ表に並べること。off-manifold 格子上の NRMSE が 1 を大きく超える場合は分母効果と絶対誤差の両方を報告すること。次数 3 多項式が野生的な teacher field を off-manifold で増幅しうるため、格子診断を次数選択に組み込む場合は validation 的な位置づけで使い test 漏れを起こさないこと。 |
