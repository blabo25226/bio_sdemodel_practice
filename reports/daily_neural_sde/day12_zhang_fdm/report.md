## 1. 論文要約

### 1.1 問題と提案

連続な Markov 過程の法則は、二時刻の同時分布の族で決まる、という主張が定理の核である。
有限次元の厳密プロパーなスコアを \((X_{t_1}, X_{t_2})\) に載せると、経路法則に対する厳密プロパーなスコアになる
（Theorem 2）。実装上の例は RBF カーネルのカーネルスコアで、これを Neural SDE の
drift ネット \(\mu_\theta(t, Z_t)\) と diffusion ネット \(\sigma_\theta(t, Z_t)\) について最適化する
（Algorithm 1、Finite Dimensional Matching）。
シグネチャカーネルの \(O(D^2)\) や GAN の識別器を避け、離散化ステップ数 \(D\) に対して \(O(D)\) だと述べている。

実験は金属・株価指数・為替・エネルギー・債券の Dukascopy 価格と、合成の rough Bergomi である。
評価は時刻ごとの周辺分布の KS 検定で、FDM が SigKer、TruncSig、SDE-GAN より良い、と報告している。
アーキテクチャは Issa et al. (2023) に合わせた全結合ネットで、公開コードの
`FDDiscriminator` は隣接格子時刻の結合 \((X_t, X_{t+1})\) について
\(\mathbb{E}[k(X,X')] - 2\mathbb{E}[k(X,Y)]\) を損失として返す。
カーネルは \(\exp(-\|u-v\|^2/(2\sigma^2))\)、\(\sigma=1\) である。

### 1.2 選定理由

前日までとの重なりを避けた。Day 2 は GAN、Day 5 は \(W_2\)、Day 10 は逆時間のスコア、
Day 3 は変分、Day 8 はジャンプ、Day 9 は平均場、Day 11 はタスク損失と初期状態の拡散である。
本日は **二時刻同時分布のカーネルスコアで drift と diffusion を同時に学習する** という未使用の目的を選んだ。
採録は ICLR 2025 で、drift と diffusion がどちらもニューラルネットである査読付き論文のうち新しいものである。
NeurIPS 2025 の Neural Stochastic Flows は遷移法則を正規化流で直接学ぶため、
本日の「ニューラルな drift / diffusion を teacher にする」という枠の外に置いた。

この 2 次元座標は振動子の観測座標であり、遺伝子規制の式でも潜在遺伝子空間の式でもない。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと teacher

データ法則は次の Markov 伊藤拡散である。初期条件は \(N(0,I_2)\)、\(T=1.5\)、\(\Delta t=0.05\)（30 步）。

$$
\begin{aligned}
dx &= y\,dt + (0.25 + 0.05\,x^{2})\,dW^{1},\\
dy &= \big((1-x^{2})y - x\big)\,dt + 0.30\,dW^{2}.
\end{aligned}
$$

分割は軌道単位で train 256 / validation 128 / test 256。query の非有限脱落は 0 である。
train 軌道から座標ごとに平均と標準偏差を取り（平均 \((0.0237,\ 0.0212)\)、標準偏差 \((1.104,\ 1.190)\)）、
teacher はその正規座標 \(z\) の上で学ぶ。報告する場は \(f_x=\mathrm{std}\cdot f_z\)、
\(g_x=\mathrm{std}\cdot g_z\) で元の \((x,y)\) に戻してある。線形変換なので伊藤補正は付かない。

teacher は入力 \((z_x, z_y, t/T)\) の MLP（幅 32、tanh 2 層、出力 2）。
拡散側の出力は softplus。学習は公開コードと同じ隣接時刻の損失を最小化するもので、
Adam（学習率 \(10^{-3}\)）、1200 step、バッチ 64、勾配クリップ 1、非有限の step は 0 であった。
FDM の損失は \(-0.181\) から \(-0.203\) まで動いた。
同じ初期化・同じブラウン増分・同じ step 数の周辺分布だけの損失（各時刻の状態、二時刻に結合しない）を
H6 のベースラインとした。こちらは \(-0.311\) から \(-0.330\) まで動いた。蒸留するのは FDM teacher だけである。

### 2.2 逸脱の明示

1. **Dukascopy と rough Bergomi を使わない**: 市場系列は外部データで、rough Bergomi は非 Markov かつ 16–32 次元である。
   定理が同定するのは Markov 過程の生成器なので、データ法則は上の 2 次元伊藤拡散にした。
   論文の KS 表は再現していない。
2. **潜在状態を置かない**: 論文の \(Z\) は隠れ次元 16、ブラウン次元 8、一般ノイズ、線形読み出しである。
   その座標は識別できない。本日の状態は観測された \((x,y)\) で、拡散は対角である。
3. **LipSwish と最終 tanh を tanh と softplus に替える**: 論文が採用する Issa et al. (2023) の設定である。
   幅 64・3 層は幅 32・2 層にした。softplus は拡散を正に保つ。
4. **1200 step の Adam、CPU**: 論文は H100 上で 10000 step の Adadelta である。
5. **損失は公開コードに合わせた**: 本文の式は一様な \((t_1,t_2)\) と最大化を書いているが、
   式の符号と「最大化」は逆向きである。`FDDiscriminator.forward` は隣接時刻の
   \(\mathbb{E}k_{xx}-2\mathbb{E}k_{xy}\) を返し、これを最小化した。
   データ項を除けば MMD\(^2\) の最小化である。
6. **正規化は train 軌道だけ**: 論文の mean/variance 前処理に対応する。\(\sigma=1\) はこの座標での単位バンド幅である。
7. **初期分布はデータの \(N(0,I)\)**: 学習される \(\xi_\theta\) は置かない。

真値の場は上の閉じた形である。対 teacher の指標と対真値の指標は結果の表で分けた。

## 3. 仮説（config に事前凍結）

実行前に `configs/daily_neural_sde_day12.json` へ書いた。test のあとでしきい値は動かしていない。

- **H1** (drift): test で symbolic 対 teacher の NRMSE \(\le 0.25\)、
  teacher 対真値 \(\le 0.40\)、symbolic 対真値 \(\le 0.45\)。三つとも必要。
- **H2** (diffusion): symbolic 対 teacher \(\le 0.30\)、teacher 対真値 \(\le 0.40\)、
  symbolic 対真値 \(\le 0.45\)、\(\Sigma=g^{2}\) の symbolic 対 teacher \(\le 0.45\)。
  残差 RMS は併記し、ゲートにはしない。
- **H2c**: test query のうち symbolic \(g\) の成分が 0 以下になる行の割合 \(\le 0.02\)。
- **H3**: 係数回復の仮説は置かない。次数 3 の VIF 最大（定数列を除く）が 10 を超えたら係数読みは不定。
- **H4**: test の 256 本、同じ Wiener 増分。失敗率は各モデル \(\le 0.05\) かつ symbolic と teacher の差 \(\le 0.02\)。
  \(\|X\|>3.5\) の逸脱率の差 \(\le 0.10\)。失敗率ゲートと H7 を通過したときだけ、
  平均経路の RMSE（symbolic 対 teacher \(\le 0.30\)、teacher 対真値 \(\le 0.35\)）と
  終端共分散の相対 Frobenius（\(\le 0.50\)）を判定する。失敗した軌道は平均から落とさず、ゲートで不定にする。
- **H5**: 正規座標の二時刻 MMD\(^2\)（config の 8 組）は teacher \(\le 0.04\)、symbolic \(\le 0.06\)。
  元座標の平均経路 RMSE は teacher 対観測 \(\le 0.35\)、symbolic 対観測 \(\le 0.45\)。
  失敗率 \(>0.05\) なら不定。真値対観測の MMD はフロアでありゲートではない。
- **H6**: 同じ test query で、拡散の対真値 NRMSE は FDM が周辺ベースラインより \(0.05\) 以上小さい。
  drift の差は報告のみ。
- **H7**: teacher の \(\Delta t=0.05\) と \(\Delta t=0.01\)（細増分 5 本の和を \(\sqrt{5}\) で割った粗増分）の
  終端 RMSE \(\le 0.50\)、かつ両方が有限な割合 \(\ge 0.95\)。外れたら H4 の平均と共分散は不定。

## 4. 方法

teacher への直接 query。特徴は観測軌道上の \((x,y,t)\)（各分割の全時刻、train 7936、validation 3968、test 7936）。
SINDy の標準化は train query だけから取る。ライブラリは \((x,y,t)\) の冪だけである。
次数 \(\{1,2,3\}\)、しきい値 \(\{0.02,0.05,0.1,0.2,0.35\}\)、ridge \(10^{-4}\)。
drift と diffusion を別々に、validation の pooled NRMSE 最小で選ぶ。同点はより小さい次数、次に小さいしきい値。
test はこの選択のあと 1 回。

選択結果: drift は次数 3・しきい値 0.05（標準化座標で活性 10、ライブラリ 20 項、検証 NRMSE 0.151）。
diffusion は次数 3・しきい値 0.02（活性 22、検証 NRMSE 0.0275）。
シミュレーションは失敗をラッチし、`non_finite` と `outside_radius` を分ける。
真値の再積分と保存した test 軌道の最大絶対差は 0 であった。

### 5.2 拡散は teacher の段階でほぼ消えている

H2 の対 teacher は 0.031（残差 RMS \(5.4\times 10^{-4}\)）で、しきい値 0.30 の内側にある。
同じ query への次数 3 OLS は 0.0126 で、しきい値 0.02 の SINDy と近い。
活性は 40 係数中 22 なので、失敗の原因は疎化のしきい値ではない。
対真値は teacher も symbolic も 0.949 で、残差 RMS 0.300 は真値 RMS 0.317 とほぼ同じである。
零関数の NRMSE は 1 なので、学習された拡散は零に近い。
oracle が \(10^{-14}\) なので、次数 3 の冪は真の \(0.25+0.05x^{2}\) と定数 \(0.30\) を表現できる。
対真値の失敗はライブラリの表現力ではなく、FDM teacher の場がそこにないことである。

| 点 | 真値 \(g\) | teacher \(g\) | symbolic \(g\) |

| \((0,0)\) | \((0.25,\ 0.30)\) | \((0.0240,\ 0.0265)\) | \((0.0245,\ 0.0270)\) |
| \((1,0)\) | \((0.30,\ 0.30)\) | \((0.0217,\ 0.0243)\) | \((0.0223,\ 0.0250)\) |
| \((0,1)\) | \((0.25,\ 0.30)\) | \((0.0216,\ 0.0236)\) | \((0.0217,\ 0.0237)\) |

H2c が pass なのは、この小さい正の面を多項式が正の側に保ったからである。
水準は真値の約 10 分の 1 である。平均の比で見た one-step の大きさは
\(|f|\Delta t=0.0718\) に対し \(g\sqrt{\Delta t}=0.00524\)（比 13.7）で、
学習後の teacher では 1 步の更新が drift に支配されている。
真の \(g\sqrt{\Delta t}\) は 0.07 の桁なので、単位バンド幅 \(\sigma=1\) のカーネルから見ると
1 步の拡散は状態の標準偏差よりかなり小さい。損失の動きが 0.02 程度だったことと整合する。

H6 もこの床の上での比較である。周辺ベースラインの対真値 NRMSE は 0.939（残差 RMS 0.297）で、
FDM は 0.949 である。改善は \(-0.0105\) でしきい値 0.05 に届かない。
両方とも零拡散の NRMSE 1 のすぐそばにあり、二時刻損失は周辺損失より拡散を回復していない。
drift では FDM 0.498、周辺 0.543 で、FDM が 0.045 小さい。これは判定条項の外である。

### 5.3 drift は軌道上で teacher に近く、真値の係数ではない

H1 の対 teacher は 0.202（残差 RMS 0.216、成分は 0.083 と 0.270）で、単独のゲート 0.25 の内側にある。
次数 3 OLS の test NRMSE は 0.211 で、しきい値 0.05 の疎な式の方が test ではわずかに小さい。
疎化が test の誤差を増やした、という読みはあたらない。
対真値は teacher 0.498（残差 RMS 0.745）、symbolic 0.488（残差 RMS 0.729）で、
どちらもしきい値の外にある。oracle は \(5.3\times 10^{-15}\) なので、
真の drift（\(y\) と \((1-x^{2})y-x\)）は同じライブラリで回復できる。
0.49 という差は teacher の場の差である。

VIF は 7.969 でゲート 10 の内側である。標準化座標の活性は 10 項で、
元座標へ展開すると時刻 \(t\) の項は残っていない。係数は teacher の軌道上の場の記述として読める。
閉じた形との対応は次のとおりで、一致していない。
\(f_1\) の \(y\) の係数は 1.085（真値 1）。
\(f_2\) の \(y\) は 0.472（真値 1）、\(x\) は \(-1.107\)（真値 \(-1\)）、
\(x^{2}y\) は \(-0.233\)（真値 \(-1\)）。
\(t=0\)、\((0,1)\) の \(f_2\) は真値 1、teacher 0.895、symbolic 0.488 である。

格子（選択外、train の 5–95 百分位を半分だけ広げた \(9\times 9\)）では軌道上の近さが残らない。
drift の symbolic 対 teacher は \(t=0\) で NRMSE 1.590、RMS 2.334 である。
\(t=0.75\) と \(t=1.5\) も RMS 2.33 で、時刻を変えても同じ桁である。
teacher 対真値の格子 RMS は 11.19（NRMSE 0.961）で、真値の 3 次項が格子の端で大きい。
symbolic 対真値の格子 RMS は 9.26（NRMSE 0.795）である。
NRMSE が 1 前後のときは絶対 RMS を主に見る。式をデータ環の外へ持ち出さない。

## 6. 考察

蒸留の対象は FDM teacher の場である。閉じた形との比較は同じ表の別の列である。

軌道上では、次数 3 の冪が teacher の drift を NRMSE 0.202、拡散を NRMSE 0.031 まで追えている。
拡散の式が小さい多項式なのは、teacher の拡散が点ごとに 0.02 前後だからである。
真の拡散（0.25 から 0.30）は oracle が示すとおりライブラリの中にあるのに、teacher がそこへ行っていない。
隣接時刻の単位バンド幅 RBF を 1200 step 最小化しても、周辺だけの損失でも、拡散は零の床に残った。
二時刻スコアが生成器を分ける、という定理の結論は、このバンド幅とこの step 数の有限標本では拡散に現れていない。

法則側の H5 と経路側の H4 は凍結したしきい値を通過した。
MMD のしきい値はモンテカルロフロアより一桁大きい。
平均経路と終端共分散は、拡散がほぼ無い teacher でも drift の流れが雲を運ぶ範囲では真値に近くなりうる。
場の NRMSE 0.95 と経路指標の合格は、この実験では両立している。

係数は VIF 7.97 の下で teacher の多項式として読める。
\(f_2\) の \(y\) と \(x^{2}y\) は真値の半分以下で、格子の drift RMS は 2.3（対 teacher）と 9.3（対真値）である。
式の使用範囲は学習 query の環の中である。
