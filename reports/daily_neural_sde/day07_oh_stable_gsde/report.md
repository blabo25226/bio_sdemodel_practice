## 1. 論文要約

### 1.1 問題と提案

不規則サンプリングや欠測を含む時系列では、drift / diffusion を自由なニューラルネットで近似する
naïve な Neural SDE は、強解の不存在、確率的 destabilization、Euler 離散化の不安定化といった
病理を起こしうる (論文 §2.2)。論文は、理論的に well-defined な 3 つの安定クラスを提案する:
Langevin 型 LSDE (§3.1, Eq. (4): drift はネット、diffusion は t のみの関数)、
線形ノイズ LNSDE (Eq. (5): diffusion が σ(t)·z の乗算型)、
幾何型 GSDE (Eq. (6): dz/z = γ(t, z)dt + σ(t)dW、すなわち Itô 形では dz = zγdt + zσdW)。
GSDE については Proposition 3.4(ii) が、γ の最終層が tanh / sigmoid ならば解は almost surely 非負で、
0 は吸収状態であることを示す (ReLU ネットの活性・非活性ニューロンとの対応)。
さらに Theorems 3.5–3.6 が、欠測による分布シフトのもとでの出力分布の Wasserstein 安定性を示す。
実証面では PhysioNet Mortality / Sepsis、Speech Commands、MuJoCo で、複数の欠測率のもとで
提案クラスが既存手法を上回り、欠測率に対して頑健であることを報告している。
Figure 1 では、50% 欠測のもとで |z|³ 型や自由なネット型の diffusion が学習を destabilize することが
動機づけの例として示されている。

### 1.2 本日の切り取りと選定理由 (多様性の観点)

前日までとの重なり回避: Day 1 は勾配ベース学習 (Li)、Day 2 は GAN (Kidger)、Day 3 は変分潜在モデル (Tzen)、
Day 4 は市場較正 (Gierjatowicz)、Day 5 は W₂ 分布一致 (Zhang)、Day 6 は遅延 SDDE (Eggen & Midtfjord) であった。
本日は **構造制約による安定化 (stability-constrained class)** という未使用の手法系、
**不規則サンプリング・欠測ロバストネス**という未使用の評価軸、
**乗算型 diffusion と正値ドメイン**という未使用の field 構造を選んだ。
次元は 2 次元で Day 3–6 と重なるが、状態の意味が異なる: 本日の状態は正値ドメイン上の観測量そのものであり、
GSDE の非負性・吸収状態というドメイン構造が検証の主対象である。
データ入手可能性: 論文は実データベンチマーク (PhysioNet 等) を用いるが、潜在座標は識別不能であるため、
憲章のスコープ境界に従い、識別可能な座標で teacher を再構成する:
線形 γ と定数 σ を持つ観測可能な 2 次元 GSDE を真値とし、合成データとして再生成する
(憲章の選定条件 (a) は「生成過程が特定できる」ことで満たす)。
LSDE・LNSDE は扱わず、論文の Figure 1 の対比そのものである「GSDE vs naïve 自由ネット」に絞る。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと真値

真値は論文 Eq. (6) の時間同次・定数 σ の特殊ケースで、γ を線形とした:

$$
\begin{aligned}
\gamma^1 &= 0.60 - 0.25 X^1 - 0.10 X^2, &
\gamma^2 &= -0.10 + 0.20 X^1 - 0.30 X^2, \\
f^1 &= X^1 \gamma^1, & f^2 &= X^2 \gamma^2, \\
g^1 &= 0.30 X^1, & g^2 &= 0.25 X^2.
\end{aligned}
$$

内部平衡点は (X¹, X²) = (2, 1) で、ヤコビ行列 [[−0.5, −0.2], [0.2, −0.3]] は安定スパイラルである。
この選び方の要点は、有効 drift がちょうど 2 次多項式、有効 diffusion がちょうど 1 次多項式になることであり、
Day 6 の tanh 真値とは異なり、係数回復が意味のある問いになる。
軌道は Euler–Maruyama (dt_fine = 0.01) でシミュレーションし、0.05 ごとに観測した (t ∈ [0, 10]、201 点)。
軌道数は 1024 本で、trajectory-disjoint に train 640 / validation 192 / test 192 (seed 0)。
初期値は X¹(0) ~ LogNormal(log 2, 0.4)、X²(0) ~ LogNormal(0, 0.4) の独立抽出で、常に正値である。
状態統計 (train query 状態): X¹ の平均 1.895、標準偏差 0.578、範囲 [0.37, 7.13]。
X² の平均 0.915、標準偏差 0.361、範囲 [0.10, 3.33]。
真値 drift の RMS は test query で 0.273、真値 g の RMS は 0.450 である。

### 2.2 逸脱の明示

1. **潜在分類タスクから観測可能 GSDE への置換**: 論文の GSDE は分類・補間のための潜在表現であり、
   その潜在座標は観測データから識別不能である。憲章に従い、潜在 + 分類器 + controlled path (Eq. (10)) の
   パイプライン全体を切断し、識別可能な観測座標上の 2 次元 GSDE として teacher を再構成した。
   したがって本日の結果は論文のベンチマーク性能について何も主張しない。
2. **訓練法の置換**: 論文の solver 経由の潜在パイプライン訓練ではなく、シリーズ標準の
   Euler–Maruyama 遷移尤度 (EM) で teacher を訓練した。欠測データに対しては遷移ごとに実際の dt を用いる
   variable-dt EM とした。これは方法の置換であり、論文の訓練法の再現ではない。
3. **クラスの削減**: LSDE・LNSDE は扱わず、GSDE vs naïve 自由ネットの 2 クラス比較とした。
   これは論文の Figure 1 の対比 (安定クラス vs naïve diffusion) に対応するが、3 クラス比較ではない。
4. **欠測シフトの合成版への置換**: 論文の実データ欠測率実験ではなく、合成軌道の観測点を
   独立に 50% 間引く (最初と最後は必ず残す、seed 123) ことで欠測シフトを再現した。
   間引き後の遷移数は train で 64,356 (密な 128,000 遷移の約半分) である。
   論文の PhysioNet / Speech / MuJoCo の欠測率ロバストネス主張は、本日の合成版でのみテストした。
5. **PhysioNet / Speech / MuJoCo ベンチマーク、controlled path、分類器ヘッド、分布シフト定理の
   数値検証は本日は扱わない**。Theorems 3.5–3.6 の Wasserstein bound 自体は検証対象ではなく、
   その経験的アナロジー (欠測率シフトのもとでの field 劣化と粗刻みシミュレーションでの負値) をテストした。

## 3. 仮説 (実行前に config へ凍結)

- **H1 (drift 蒸留)**: symbolic drift の test NRMSE (対 teacher) ≤ 0.30。
- **H2 (diffusion 蒸留)**: symbolic diffusion (g¹, g² の joint) の test NRMSE (対 teacher) ≤ 0.30、かつ
  symbolic の implied Σ (diag(g²)) の test NRMSE (対 teacher の Σ) ≤ 0.30。
- **H3 (真値回復、field 水準)**: symbolic drift の test NRMSE (対真値) ≤ 0.60。
- **H3c (真値回復、線形係数水準)**: 展開後の symbolic drift の線形係数
  (f¹ の X¹ 係数・真値 0.60、f¹ の X² 係数・真値 0.00、f² の X¹ 係数・真値 0.00、f² の X² 係数・真値 −0.10)
  の最大絶対誤差 ≤ 0.20。2 次係数は VIF が高いため判定なしで表に載せるだけとする。
- **H4 (シミュレーション)**: symbolic の失敗率 ≤ 0.05 かつ teacher との差 ≤ 0.02、
  paired RMSE (対 teacher) の中央値 ≤ 1.0、かつドメイン条項として
  半径 > 8 の逸脱率の symbolic − teacher ≤ 0.10 かつ負値率の symbolic − teacher ≤ 0.10。
  失敗は non-finite または半径 > 30。
- **H5 (論文軸: GSDE vs naïve)**: 両条項が成ること。
  (a) 欠測劣化: test query での drift 二乗誤差について、劣化 = (間引き teacher の平均二乗誤差 − 密 teacher の平均二乗誤差)
  とし、劣化(naïve) − 劣化(GSDE) > 0 かつ paired SE の 2 倍超。
  (b) 粗刻み負値: dt = 0.5、T = 10 の paired シミュレーションで、負値率 (naïve − GSDE) > 0 かつ paired SE の 2 倍超。
  固定の絶対マージンは置かない (Day 6 H5 と同じ paired-SE 規則)。
- **H6 (離散化バイアス診断、Day 1・Day 6 の反省)**: 遷移数を揃えた制御比較で、
  (a) GSDE 構造 EM (Δt = 0.5) の drift field NRMSE が EM (Δt = 0.05、同一遷移数) より 0.03 以上悪化すること、
  (b) 悪化幅が大半径レジーム (半径 > 3) で小半径レジーム (半径 < 2) より 0.02 以上大きいこと。
- **H7 (論文軸の代理: one-step 予測)**: test 遷移での one-step-ahead X¹ MSE について
  |MSE_symbolic − MSE_teacher| ≤ 0.005。paired 標準誤差を併記し、paired SE ≥ 0.0025 の場合は
  点推定が合格しても「統計的に確定しない」とする (Day 4 の反省)。

## 4. 方法 (main と同じ流儀)

- teacher への直接 query で function distillation。query 点は各 split の観測状態
  (trajectory-disjoint)。変換 (mean/scale) と RMS 正規化は train query のみから。
- teacher: GSDE 構造 teacher (γ ネット [32, 32] tanh、出力 1.5·tanh で有界化 — 論文の tanh 最終層に対応;
  σ ネット [16] tanh、入力は t のみ、出力 softplus + 0.01; 有効 drift fʲ = Xʲγʲ、有効 diffusion gʲ = Xʲσʲ(t)) と
  naïve 自由ネット teacher (drift・diffusion ともに [32, 32] tanh MLP、入力 (t, X¹, X²)、g = softplus + 0.01)。
  両者とも EM 遷移尤度で訓練 (密: 128,000 遷移、間引き: 64,356 遷移、Adam lr 0.003、50 epochs、batch 8192)。
  蒸留対象は GSDE 間引き teacher で、事前に固定した (論文の設定は不規則データであるため)。
  EM の分散には 1e-8 のフロアを加えた (Xʲ が小さいときの NLL の発散防止)。
- 候補: drift は次数 {1, 2, 3} (変数は X¹, X² のみ — 真値は時間同次であり、teacher の t 依存は別診断とした)、
  diffusion は成分ごとに次数 {0, 1, 2} (変数は (t, 自成分) のみ)、STLSQ しきい値 {0.02, 0.05, 0.1, 0.2, 0.35}。
  field ごとに validation NRMSE で選択し、test は確定後に 1 回だけ評価。
- oracle 診断: 同じ SINDy 手順を真値 field に fit (天井の診断)。
- 共線性診断: fit の前に train query 状態で corr と VIF を計算 (線形変数と次数 2 ライブラリの両方)。
- 格子診断 (Day 2 の反省により標準手順): t = 5 に固定した正象限格子 (88 点) と near-zero コーナー (4 点) で
  teacher / symbolic / 真値を比較する。選択には使わない (報告専用)。
- teacher の t 依存診断: test query から抽出した 20 状態で、GSDE teacher の drift を t = 0, 2, 5, 8, 10 で評価し、
  t 方向の標準偏差と field RMS の比を報告する (真値は時間同次なので、t 依存は teacher の spurious な成分である)。
- シミュレーション検証: test 軌道の初期値から、teacher / symbolic / 真値 / naïve の各モデルを
  同一 Brownian 増分 (paired) で Euler–Maruyama (dt = 0.05、t ∈ [0, 10]) によりシミュレーション。
  失敗は non-finite / 半径 > 30 で分類し、質量を保持する。半径 > 8 の経験は「逸脱」、
  いずれかの成分 < 0 の経験は「負値」として失敗とは別に数える。
- 粗刻みシミュレーション (H5b): dt = 0.5、20 ステップ、同一増分で GSDE 間引き teacher と naïve 間引き teacher を比較する。

## 5. 結果

### 5.1 推定器の比較 — teacher の対真値 field 誤差 (test query 状態、38,592 点)

| teacher | drift NRMSE vs 真値 (RMS 誤差) | g NRMSE vs 真値 | Σ NRMSE vs 真値 |
|---|---|---|---|
| GSDE 間引き (蒸留対象) | 0.1965 (0.0536) | 0.0272 | 0.0546 |
| GSDE 密 | 0.1662 (0.0454) | 0.0129 | 0.0270 |
| naïve 間引き | 0.2273 (0.0621) | 0.0336 | 0.0845 |
| naïve 密 | 0.2301 (0.0628) | 0.0195 | 0.0414 |
| GSDE 粗視化 (Δt = 0.5) | 0.2133 (0.0582) | 0.1369 | 0.2623 |
| GSDE 細分対照 (Δt = 0.05、同一遷移数) | 0.3125 (0.0853) | 0.1206 | 0.2541 |

読み取り:

- **絶対水準では GSDE が naïve を両方の欠測条件で上回る** (密: drift 0.166 vs 0.230、g 0.013 vs 0.020;
  間引き: drift 0.197 vs 0.227、g 0.027 vs 0.034、Σ 0.055 vs 0.084)。
  構造制約 (乗算型 diffusion、t のみの σ) は、密データでも間引きデータでも field 精度で有利に働いた。
  ただしこれは H5 の凍結条項 (劣化の比較) とは別の軸であり、§5.7 で分けて論じる。
- **間引きによる GSDE の劣化は小さいがゼロではない** (drift 0.166 → 0.197、g 0.013 → 0.027)。
  naïve は密でも間引きでもほぼ同じ誤差 (drift 0.230 → 0.227) であり、欠測の影響が見えない。
  これは naïve の誤差が欠測以外のバイアス (自由なネットの関数近似バイアス) に支配されているためと読むのが妥当である。
- **粗視化・細分対照ペアの diffusion 誤差がともに大きい** (g NRMSE 0.137 / 0.121、Σ 0.262 / 0.254)。
  12,800 遷移という小サンプルでは、drift だけでなく diffusion の推定も大きく劣化する
  (密 128,000 遷移の GSDE では g 0.013)。H6 の比較はこのサンプルサイズ効果を共有しているが、
  drift については粗視化の SNR 利益がそれを上回った (§5.8)。

### 5.2 蒸留の精度

| field | 選択 (次数, しきい値, 活性項) | validation NRMSE | test NRMSE 対 teacher | test NRMSE 対真値 |
|---|---|---|---|---|
| drift | 次数 3, 0.02 | 0.0712 | **0.0768** | 0.1768 |
| diffusion (g joint) | 次数 2, 0.02 (両成分) | 0.0141 / 0.0075 | **0.0134** | 0.0239 |
| diffusion の implied Σ | — | — | **0.0281** | 0.0434 |
| oracle drift (天井) | 次数 2, 0.02 | — | — | 0.0000 |
| oracle diffusion (天井) | 次数 2, 0.02 | — | — | 0.0000 |

読み取り: 蒸留そのものは on-manifold では成功している (対 teacher 0.077 / 0.013)。
対真値 0.177 は oracle の天井 0.0000 からは遠いが、これは蒸留手順の失敗ではなく teacher の誤差である:
teacher 自体の対真値 drift NRMSE が 0.197 であり、symbolic は teacher を 0.077 で近似しているため、
対真値誤差はほぼ teacher の誤差で説明できる。oracle がちょうど 0 になるのは、真値が次数 2 / 次数 1 の
多項式そのものであるためであり、Day 6 の tanh 真値 (oracle 0.076) とは対照的である。
すなわち本日の蒸留誤差の分解は「多項式クラスの限界 ≈ 0、teacher 誤差 ≈ 0.20、蒸留の追加誤差 ≈ 0.08 (field 水準)」である。
なお drift の選択が次数 3 になったのは、teacher が正確な 2 次多項式ではない (MLP の γ) ため、
次数 3 が validation で次数 2 を上回ったためである。次数 3 の選択が係数回復を壊した側面については §5.4 で論じる。

### 5.3 求めた symbolic SDE (TeX、元座標)

蒸留で得た SDE は次である (x = X¹、y = X²。完全展開は `outputs/daily_neural_sde/day07/symbolic_sde.tex` と同一。
drift は各成分 8 項、diffusion は各成分 4 項であり、Day 6 の 375 項とは対照的に人間が読める規模である):

```tex
%% Day 7 symbolic SDE (Oh et al. 2024 Stable Neural SDEs, Geometric SDE; distilled GSDE teacher; x = X^1, y = X^2)
\begin{aligned}
\hat f_x &= - 0.1948 + 0.1469\,y + 1.071\,x - 0.2054\,y^{2} - 0.1089\,x y - 0.5266\,x^{2} + 0.05973\,y^{3} + 0.04408\,x^{3} \\
\hat f_y &= - 0.03444 - 0.02735\,y - 0.04451\,x - 0.3975\,y^{2} + 0.2597\,x y + 0.02073\,x^{2} + 0.05087\,y^{3} - 0.02265\,x^{2} y \\
\end{aligned}
\begin{aligned}
\hat g^1 &= 0.02521 + 0.2957\,x - 0.0156\,t + 0.00156\,t^{2} \\
\end{aligned}
\begin{aligned}
\hat g^2 &= 0.007129 + 0.2482\,y - 0.004337\,t + 0.0004337\,t^{2} \\
\end{aligned}
```

読み取り: diffusion は真値 (g¹ = 0.30x、g² = 0.25y) に近い形を回復している
(主係数 0.2957 / 0.2482、t 項は小さく、切片は 0.025 / 0.007 と小さい)。
一方 drift は、真値の 2 次形 (f_x = 0.60x − 0.25x² − 0.10xy、f_y = −0.10y + 0.20xy − 0.30y²) に対して、
切片 (−0.1948 / −0.0344) と 3 次項 (0.0597y³ + 0.0441x³ など) を持ち、f_x の線形係数は 1.071 と真値 0.60 から大きくずれる。
field 水準では on-manifold で teacher に 0.077 で迫っているにもかかわらず、係数水準では大きくずれている
(field 水準と係数水準の分離、Day 1 の教訓の再確認)。
特に切片の存在は GSDE の構造 (原点で drift = diffusion = 0) を破るものであり、
§5.6 のコーナーでの失敗の直接の原因である。

### 5.4 真値との比較と共線性 (H3・H3c の内訳)

train query 状態での共線性診断: corr(X¹, X²) = 0.215、線形変数の VIF は最大 1.05 と低い。
しかし次数 2 ライブラリ (x, y, x², xy, y²) の VIF は 16.6–26.3 (最大 24.6) と高く、
2 次項同士が強く共線である。したがって線形係数のみを仮説化した H3c の設計は正しかったが、
それでも H3c は**否**であった:

| 係数 | 真値 | symbolic | 誤差 |
|---|---|---|---|
| f¹ の X¹ 係数 | 0.60 | 1.071 | +0.471 |
| f¹ の X² 係数 | 0.00 | 0.147 | +0.147 |
| f² の X¹ 係数 | 0.00 | −0.045 | −0.045 |
| f² の X² 係数 | −0.10 | −0.027 | +0.073 |

最大絶対誤差 0.471 > しきい値 0.20 で H3c は否。2 次係数 (判定なし) の誤差は、
f¹: x² −0.277、xy −0.009、y² −0.205、f²: x² +0.021、xy +0.060、y² −0.098 であった。
解釈: 線形変数の VIF が低くても、**次数 3 まで含むライブラリの中では線形係数が高次項と打ち消し合う**ため、
線形係数だけを取り出しても回復しない。VIF ゲートは次数 2 ライブラリに対して計算したが、
実際に選択されたのは次数 3 であり、次数 3 ライブラリの共線性はさらに強い。
教訓として、係数仮説の共線性ゲートは「選択される次数のライブラリ」に対して置かなければならず、
事前に次数を固定しない選択手順のもとでは、線形係数であっても安全な係数条項にはならない。
H3 の field 条項は成る (対真値 0.1768 ≤ 0.60) が、H3c の否と合わせて読むべきである:
「field は回復したが、係数は回復していない」。

### 5.7 論文軸の詳細 — H5: GSDE vs naïve

| 比較 (test query / paired シミュレーション) | GSDE | naïve | paired 差 (平均 ± SE) | 判定 |
|---|---|---|---|---|
| drift 二乗誤差の欠測劣化 (間引き − 密) | +0.00082 | −0.00010 | −0.00092 ± 0.00003 (naïve 劣化 − GSDE 劣化) | 否 |
| 粗刻み (dt = 0.5) 負値率 | 0.0000 | 0.0052 (1/192) | +0.0052 ± 0.0052 (naïve − GSDE) | 否 (確立せず) |

H5 は**否**である。ただし 2 条項の否の意味は異なるため、分けて読む必要がある。

- **劣化条項の否は、GSDE が悪いのではなく、naïve の密データでの誤差が既に大きいために劣化が測れないことによる**。
  絶対水準では GSDE が密でも間引きでも naïve を上回る (§5.1: 間引き drift 0.197 vs 0.227)。
  劣化という差分の指標は、「出発点が良いモデルほど劣化しやすい」という構造的バイアスを持つ:
  naïve の劣化が −0.00010 (間引きの方がわずかに良い) なのは、naïve の誤差が欠測とは無関係な
  関数近似バイアスに支配されており、欠測が誤差に上乗せされないためである。
  したがって H5(a) の否は「論文のロバストネス主張への反証」ではなく、
  「劣化という指標の選び方が、この設定では論文の方向性を測れなかった」という方法論的所見である。
  論文の主張を本日の設定で測るなら、絶対水準 (間引き条件での GSDE < naïve) の方が適切な指標であり、
  その軸では論文の方向性が支持される。凍結した H5 の判定としては否を維持する。
- **負値条項の否は、証拠不足による否である**。方向は GSDE に有利 (GSDE 0 系列、naïve 1 系列) だが、
  1 系列の差では paired SE (0.0052) が差そのものと等しく、2×SE 規則を満たさない。
  密な dt = 0.05 のシミュレーションでも同じ 1 系列のみが負値化しており、
  負値化は稀なイベントである。GSDE の非負性 (Proposition 3.4(ii)) は連続時間の性質であり、
  EM 離散化のもとでは GSDE teacher でも負値化しうる (本日は 0 系列だったが、定理の保証ではない)。
  負値率の対比を確立するには、初期値を原点付近に偏らせたストレステストや、より多くの系列が必要である。

### 5.8 離散化バイアス診断の詳細 — H6: EM の粗視化

| 指標 | EM 細分対照 (Δt = 0.05) | EM 粗視化 (Δt = 0.5) | 悪化幅 |
|---|---|---|---|
| drift NRMSE (全体) | 0.3125 | 0.2133 | −0.0993 |
| drift NRMSE (小半径レジーム、n = 17,841) | 0.3578 | 0.1190 | −0.2388 |
| drift NRMSE (大半径レジーム、n = 2,872) | 0.2575 | 0.2360 | −0.0215 |
| Σ NRMSE | 0.2541 | 0.2623 | +0.0082 |

H6 は**否**である。(a) の悪化幅 −0.0993 はしきい値 +0.03 に届かないどころか符号が逆であり、
(b) のレジーム間ギャップ 0.2173 はしきい値 0.02 を満たすが、その内訳は予想と逆である:
大半径レジームでの悪化は −0.0215 (むしろ改善) であり、ギャップは小半径レジームでの大幅な改善 (−0.2388) によって生じている。
Day 6 と同じメカニズムが、より強く現れたと読むのが最も整合的である:
Δt = 0.5 では drift 信号が 10 倍 (f·Δt) になる一方ノイズの標準偏差は √10 倍にしかならないため、
per-transition の SNR が約 3 倍になり、特に drift が小さい小半径レジームでは粗視化の方が推定しやすい。
細分対照の NRMSE が 0.3125 と密データ版 (0.1662) より大幅に悪いのは、遷移数が 12,800 と少ないことと、
1 遷移あたりの SNR が低いことの両方による。粗視化は凍結バイアスを生むはずだが、
本日の系では SNR の利益がそれを上回った。Σ については粗視化と細分対照がほぼ同等 (0.262 vs 0.254) であり、
diffusion の推定は刻みよりもサンプルサイズに支配されている。
結論として、Day 1 型の「凍結バイアス」は、SNR とサンプルサイズを制御しない限り、
粗視化比較では検出できない。凍結バイアスの仮説は今後もレジーム別に置くべきだが、
比較の解釈には per-transition SNR を併記すべきである (Day 6 の反省の強化)。

## 6. 考察

1. **構造制約は絶対水準では効くが、劣化という指標では測れない**。本日の H5 は、論文の方向性を
   劣化の差分で測ろうとした設計の失敗例である。GSDE は密でも間引きでも naïve より良く、
   間引き条件での絶対水準こそが実務的に意味のある比較である。劣化指標は、出発点の誤差水準が異なる
   モデル間では「悪いモデルほど劣化しにくい」というバイアスを持つ。今後、分布シフトのロバストネスを
   仮説化する際は、劣化の差分だけでなくシフト条件での絶対水準を併記し、どちらを主条項とするかを
   事前に決めるべきである。
2. **多項式 SINDy は GSDE の構造を壊す**。GSDE の本質は「原点で drift と diffusion が消える」ことであり、
   これは正値ドメインと吸収状態の根拠である。自由な多項式ライブラリは切片を許すため、
   蒸留された式は原点付近で teacher を再現できない (§5.6 コーナー)。
   逆に diffusion は (t, 自成分) ライブラリのおかげで構造に近い形を回復した。
   構造を持つ系の蒸留では、ライブラリそのものに構造制約 (切片なし、成分ごとの変数制限) を入れることが、
   field 精度だけでなくドメイン妥当性のためにも必要である。これは Day 6 の「diffusion の入力設計は drift と別に
   検証すること」の、drift 側への拡張である。
3. **係数回復のゲートは選択される次数に対して置くこと**。本日は次数 2 ライブラリの VIF を見て
   線形係数条項を安全と判断したが、実際に選択された次数 3 のライブラリでは線形係数も打ち消しに巻き込まれた。
   係数仮説を置く場合は、選択手順が選びうる最大次数のライブラリに対して共線性を評価するか、
   次数を事前に固定して選択の自由度を制限すべきである。field 水準の成功と係数水準の失敗が両立することは、
   Day 1 から繰り返し確認されているシリーズの中心的な教訓である。
4. **離散化バイアスは SNR とのトレードオフである (Day 6 の再確認と強化)**。
   本日は粗視化が細分対照を全体で上回り、小半径レジームでは 0.36 → 0.12 と劇的に改善した。
   凍結バイアスを論じる際は、遷移数のマッチングに加えて per-transition SNR を定量化しなければ、
   バイアスと SNR とサンプルサイズの 3 つが混同される。特に diffusion の推定は刻みよりも
   サンプルサイズに支配される (粗視化と細分対照の Σ がほぼ同等) ことも、本日の新しい所見である。
5. **蒸留の成功と論文の主張は別の軸**である (Day 2–6 と同じ教訓の再確認)。
   本日の H5・H6 の否は、Oh et al. の主張への反証ではない。論文は潜在分類パイプラインと
   実データベンチマークを用いており、本日はその両方を切り取った観測可能 GSDE の合成版をテストしたに過ぎない。
   論文が主張していない軸での「失敗」を数えない、という姿勢を維持する。

## 7. 反省 (Day 8 以降に適用)

- 分布シフトのロバストネスを仮説化する際は、劣化の差分だけでなくシフト条件での絶対水準を併記し、
  どちらを主条項とするかを事前に決めること。劣化指標は、出発点の誤差が大きいモデルほど劣化しにくいという
  バイアスを持つ (GSDE の劣化 +0.00082 に対し naïve は −0.00010 だが、絶対水準では GSDE が両条件で優位)。
- 構造を持つ系 (GSDE の原点消滅など) の蒸留では、ライブラリに構造制約 (切片なし、成分ごとの変数制限) を入れること。
  自由な多項式は切片を持つため、原点付近で teacher を再現できない (コーナーで symbolic vs teacher NRMSE 1.57、
  teacher vs 真値 0.12)。diffusion の (t, 自成分) 制限が効いたのと同じ発想を drift にも適用すること。
- 係数仮説の共線性ゲートは、選択手順が選びうる最大次数のライブラリに対して置くこと。
  次数 2 の VIF (最大 24.6) を見て線形係数を安全と判断したが、実際に選択された次数 3 では線形係数も
  打ち消しに巻き込まれ、最大誤差 0.471 となった。次数を事前に固定するか、最大次数で VIF を評価すること。
- 離散化バイアスの比較では、遷移数のマッチングに加えて per-transition SNR を定量化すること。
  粗視化は小半径レジームで 0.358 → 0.119 と大幅に改善し、凍結バイアスを上回る SNR 利益が主効果であった。
  diffusion の推定は刻みよりサンプルサイズに支配される (粗視化 Σ 0.262 vs 細分対照 Σ 0.254) ため、
  drift と diffusion の粗視化比較は別々に解釈すること。
- 稀なドメインイベント (負値化 1/192 系列) の対比を確立するには、原点付近に偏らせたストレステストや
  系列数の増加が必要であること。paired-SE 規則のもとでは 1 系列の差は確立しない。
