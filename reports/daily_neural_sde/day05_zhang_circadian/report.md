## 1. 論文要約

### 1.1 問題と提案

細胞集団の遺伝子発現ダイナミクスは 2 種類のノイズに晒される:
(i) 細胞内生化学反応の本質的な確率性による「内因性ノイズ」と、
(ii) 細胞ごとの状態・パラメータのばらつきによる「外因性ノイズ」である。
論文は、内因性ノイズ (Wiener 過程) と外因性ノイズ (細胞ごとに異なる生物学的パラメータ ω) の両方を持つ
neural SDE (END-nSDE) を、時間的に分離した二乗 Wasserstein ($W_2$) 距離で学習する枠組みを提案する。
先行研究 [32] の $W_2$ 距離ベース再構成法を拡張し、状態変数とパラメータ ω の両方を入力とする
ニューラルネットで drift / diffusion を近似することで、単一の SDE ではなく SDE の族を再構成する。
$W_2$ 距離を選ぶ理由として、KL ダイバージェンスと異なり空間の計量構造を組み込み、
サポートが重ならない分布同士でも意味のある距離を与える点が挙げられる。

### 1.2 モデルと実験 (§2.2.1, §3.1: circadian clock)

*per* 遺伝子発現の最小モデルとして、線形減衰振動子 SDE

$$
\mathrm{d}x_t = (-\alpha x_t - \beta y_t)\,\mathrm{d}t + \xi_{x1}\,\mathrm{d}B^1_t + \xi_{x2}\,\mathrm{d}B^2_t, \qquad
\mathrm{d}y_t = (\beta x_t - \alpha y_t)\,\mathrm{d}t + \xi_{y1}\,\mathrm{d}B^1_t + \xi_{y2}\,\mathrm{d}B^2_t
$$

を考える。ここで $x$ は *per* mRNA、$y$ は対応する *per* タンパク質 (無次元化濃度)、
$\alpha > 0$ は減衰率、$\beta > 0$ は角周波数である。ノイズがなければ原点は安定平衡点であり、
観測される振動はノイズ誘起のゆらぎである。論文 §3.1 では $\alpha = 0.19$、$\beta = 0.21$、初期条件 $(0, 1)$ とし、
3 種類の diffusion 形 (定数型 Eq. (11)、Langevin 型 Eq. (12)、線形型 Eq. (13)) と
25 通りの $(\sigma_0, c)$ の組み合わせ (各 50 軌道) で END-nSDE を訓練する。
定数型の場合、drift の平均再構成誤差は 0.15、diffusion の平均再構成誤差は 0.16 と報告されている
(論文の誤差定義は Eq. (14)–(15) の $L^1$ 型相対誤差であり、本日の NRMSE とは定義が異なるため、数値の直接比較はしない)。
他の 2 例 (RPA-DNA 結合、NFκB シグナル伝達) は本日は扱わない。

### 1.3 選定理由 (多様性の観点)

前日までとの重なり回避: Day 1 は勾配ベース学習 (Li)、Day 2 は GAN (Kidger)、Day 3 は変分潜在モデル (Tzen)、
Day 4 は市場較正 (Gierjatowicz) であった。本日は **$W_2$ 距離による分布一致学習**という未使用の手法系、
**生物学 (概日リズム・遺伝子発現) ドメイン**という未使用のドメイン、
**線形 drift + 定数 diffusion**という Day 1–4 のいずれとも異なる field 構造を選んだ。
2 次元という次元は Day 3・4 と重なるが、手法系とドメインの新規性を優先した。
データ入手可能性: 論文は軌道データセットを公開していないが、circadian 例は Eq. (9) とパラメータが完全に特定されており、
合成データとして再生成できる (憲章の選定条件 (a) は「生成過程が特定できる」ことで満たす)。

## 2. データと Neural SDE の入手・再構成

### 2.1 データ

Eq. (9) に $\alpha = 0.19$、$\beta = 0.21$、定数型 diffusion Eq. (11) の 1 スライス
$(\sigma_0, c) = (0.20, 0.50)$ を代入した真値を宣言し、Euler–Maruyama (dt = 0.001) で再生成した:

$$
\mathrm{d}x_t = (-0.19\,x_t - 0.21\,y_t)\,\mathrm{d}t + 0.20\,\mathrm{d}B^1_t + 0.10\,\mathrm{d}B^2_t, \qquad
\mathrm{d}y_t = (0.21\,x_t - 0.19\,y_t)\,\mathrm{d}t + 0.10\,\mathrm{d}B^1_t + 0.20\,\mathrm{d}B^2_t
$$

すなわち diffusion 行列は定数 $L = 0.20 \begin{pmatrix} 1 & 0.5 \\ 0.5 & 1 \end{pmatrix}$ であり、
$\Sigma = L L^\top = \begin{pmatrix} 0.05 & 0.04 \\ 0.04 & 0.05 \end{pmatrix}$ である。
$0.05$ ごとに観測し、$t \in [0, 4]$ (81 点)、2048 軌道を生成した。
分割は trajectory-disjoint に train 1280 / validation 384 / test 384 (seed 0)。
状態統計: x の平均 −0.245、標準偏差 0.235、範囲 [−1.328, 0.558]。
y の平均 0.632、標準偏差 0.357、範囲 [−1.137, 1.656]。終端半径の平均 0.614、標準偏差 0.222。
x の範囲の非対称性は、初期条件 (0, 1) からの減衰螺旋が第 1 象限寄りに分布することの帰結である。

### 2.2 逸脱の明示

1. **外因性ノイズの族を切る**: 論文の END-nSDE は $(x, y, \sigma_0, c)$ を入力とし 25 通りの $(\sigma_0, c)$ に対する
   SDE の族を再構成するが、本日は 1 スライス $(\sigma_0, c) = (0.20, 0.50)$ のみを切り、teacher は $(\sigma_0, c)$ を入力としない。
   したがって $(\sigma_0, c)$ 間の汎化については何も主張しない。
2. **$W_2$ 損失の近似**: 論文の時間分離二乗 $W_2$ 損失 (Eq. (8)) は 2 次元結合分布の $W_2$ 距離であるが、
   2 次元結合 $W_2$ には閉形がなく、Sinkhorn ソルバーは CPU 規模外のため、
   本日は「次元ごとのソート済み周辺二乗 $W_2$ 距離 + 0.5 × 共分散行列の Frobenius 誤差二乗」を各観測時刻で平均した
   近似損失で teacher を訓練した。これは宣言された近似であり、H5 の $W_2$ 損失条項はこの近似定義のもとで読むこと。
3. **時間 horizon の延長**: PMC テキストに印刷された訓練軌道の時間範囲は $t \in [0, 1]$ であるが、
   $\beta = 0.21$ の周期は $2\pi/\beta \approx 29.9$ であり、$[0, 1]$ では 0.21 rad しか進まない。
   減衰螺旋の弧を可視化するため、$T = 4$ (0.84 rad、減衰因子 $e^{-0.76} \approx 0.47$) に延長したことを宣言する。
4. **ネットワーク規模とソルバー**: 論文は torchsde ベースの訓練だが、本日は 1 つの小さい MLP
   (隠れ層 [32, 32]、tanh) と plain Euler シミュレーション (dt_sim = 0.01) に切り取った。
   RPA-DNA 例、NFκB 例、実験データ、RNN/LSTM ベンチマークは本日は扱わない。
5. **真値 diffusion 行列の表示**: 論文の定数型 diffusion は対称行列 $L = \sigma_0 [[1, c], [c, 1]]$ として書かれているが、
   teacher の三角 Cholesky 因子とは回転の自由度が異なる。diffusion の識別対象は $\Sigma = L L^\top$ であり、
   真値との diffusion 比較は $\Sigma$ 条項で行う。生の $L$ 成分同士の比較は teacher 対 symbolic (ともに三角) でのみ行う。

## 3. 仮説 (実行前に config へ凍結)

- **H1 (drift 蒸留)**: symbolic drift の test NRMSE (対 teacher) ≤ 0.15。
- **H2 (diffusion 蒸留)**: symbolic diffusion (Cholesky 4 成分の joint) の test NRMSE (対 teacher) ≤ 0.25、かつ
  symbolic の implied $\Sigma$ の test NRMSE (対 teacher の $\Sigma$) ≤ 0.25。
- **H3 (真値回復)**: symbolic drift の test NRMSE (対真値) ≤ 0.30、かつ
  symbolic drift の線形係数 RMSE (対真値) ≤ 0.20、かつ teacher (W2) の $\Sigma$ の test NRMSE (対真値) ≤ 0.30。
  しきい値は論文の報告値 (drift 0.15、diffusion 0.16) を、1 スライスへの切り取りと $W_2$ 近似損失のために
  約 2 倍に緩めたものである。係数条項は共線性ゲートとセットで置いた (Day 1 の反省)。
- **H4 (シミュレーション)**: symbolic SDE の失敗率 ≤ 0.05 かつ neural との差 ≤ 0.02、
  paired RMSE (対 neural) の中央値 ≤ 0.20、かつドメイン逸脱率 (半径 > 2.0 を経験する割合) の symbolic − neural ≤ 0.10
  (Day 4 の反省により事前に含めたドメイン条項)。
- **H5 (推定器比較 W2 vs EM)**: (a) W2 teacher の test $W_2$ 損失 (近似定義) が EM teacher より小さい、かつ
  (b) W2 teacher の $\Sigma$ NRMSE (対真値) が EM teacher より同点域 0.01 を超えて悪くないこと。
  drift NRMSE の順序だけでは判定しない (Day 4 の反省)。
  条項 (a) は W2 teacher の訓練目的そのものであるため EM に不利なバイアスを持つことを宣言する。
  したがって H5 は中立な推定器ランキングではなく、論文軸のチェックとして読む。
- **H6 (論文軸の代理: 終端半径)**: 共通乱数による paired シミュレーションで、
  |終端平均半径 (symbolic − teacher)| ≤ 0.05。paired 標準誤差を併記し、paired SE ≥ 0.025 の場合は
  点推定が合格しても「統計的に確定しない」とする (Day 4 の反省)。
  論文の再構成誤差 (0.15 / 0.16) そのものではなく、蒸留の downstream 代理指標である。

## 4. 方法 (main と同じ流儀)

- teacher への直接 query で function distillation。query 点は各 split の観測状態
  (trajectory-disjoint)。変換 (mean/scale) と RMS 正規化は train query のみから。
- 候補: drift は次数 {1, 2, 3}、diffusion は次数 {0, 1, 2, 3}、STLSQ しきい値 {0.02, 0.05, 0.1, 0.2, 0.35}。
  field ごとに validation NRMSE で選択し、test は確定後に 1 回だけ評価。
- oracle 診断: 同じ SINDy 手順を真値 field に fit (候補ではなく天井の診断)。
- 共線性診断: fit の前に train query 状態で corr(x, y)、VIF、次数 2 特徴量間の最大相関を計算。
- off-manifold 診断 (Day 2 の反省により標準手順): (x, y) ∈ {−1, −0.5, 0, 0.5, 1}² の 25 点格子。
- シミュレーション検証: test 系列の $t = 0$ 状態 (全て (0, 1)) 384 点から、neural / symbolic / 真値の
  3 モデルを同一 Brownian 増分 (paired) で Euler–Maruyama (dt = 0.01、$t \in [0, 4]$、全行列 diffusion)。
  失敗は non-finite / 半径 > 5.0 で分類し、質量を保持する。半径 > 2.0 の経験は失敗とは別に「ドメイン逸脱」として数える。
- $W_2$ 損失の識別力チェック (§5.7、事後診断): ゼロ drift モデルと 2 倍 diffusion モデルについても
  同じ test $W_2$ 損失を計算し、損失が field の誤りを検出できることを確認した。これは凍結仮説ではなく診断である。

## 5. 結果

### 5.1 推定器の比較 — W2 vs EM (Day 1 の反省の診断)

test query 状態 (31,104 点) での field 誤差:

| 推定器 | drift NRMSE vs 真値 (RMS 誤差) | $\Sigma$ NRMSE vs 真値 (RMS 誤差) | test $W_2$ 損失 |
|---|---|---|---|
| vEM (尤度) | 0.0926 (0.0148) | 0.0559 (0.00253) | 0.00226 |
| vW2 (teacher) | 1.3221 (0.2113) | 0.9876 (0.04471) | 0.00395 |

EM teacher の validation NLL は −3.67611、W2 teacher の validation $W_2$ 損失は 0.00326 (train 損失は 200 epoch で 2.539 → 0.0059 に低下)。
レジーム別 (test query 状態):

| 推定器 | 半径 < 0.5 drift / $\Sigma$ | 半径 ≥ 0.5 drift / $\Sigma$ | 初期 t < 1 drift / $\Sigma$ | 後期 t ≥ 2 drift / $\Sigma$ |
|---|---|---|---|---|
| vEM | 0.2160 / 0.0938 | 0.0861 / 0.0490 | 0.0789 / 0.0366 | 0.1067 / 0.0666 |
| vW2 | 4.3771 / 1.5826 | 1.1037 / 0.8840 | 0.6505 / 0.5697 | 1.7897 / 1.2158 |

読み取り:

- **EM はこの系では極めて良い**。drift が線形、diffusion が定数という単純な真値に対して、
  遷移尤度は drift 0.093、$\Sigma$ 0.056 とほぼ回復する。半径 < 0.5 での EM の drift NRMSE 0.216 は、
  原点付近で真値 drift がゼロに近づく分母効果を含む (絶対 RMS 誤差は全体で 0.0148 と小さい)。
- **W2 teacher は field としては壊れている**。drift NRMSE 1.32、$\Sigma$ NRMSE 0.99 であり、
  $\Sigma$ の平均は $\begin{pmatrix} 0.0964 & 0.0116 \\ 0.0116 & 0.0963 \end{pmatrix}$ と、
  真値 $\begin{pmatrix} 0.05 & 0.04 \\ 0.04 & 0.05 \end{pmatrix}$ に対して対角が約 2 倍、相関がほぼ消えている。
  原点での teacher drift は (−0.662, 0.777) であり、真値 (0, 0) とは符号も大きさも異なる。
  すなわち W2 teacher は「強い渦 + 強いノイズ」という別の field である。
- **それでも W2 teacher の分布損失は小さい** (test 0.00395)。§5.7 のコントロールが示すとおり、
  この損失はゼロ drift (0.1505) や 2 倍 diffusion (0.0227) を検出できるだけの識別力を持つ。
  したがって「分布は合うのに field は合わない」は損失の鈍さではなく、**単一初期条件からの周辺分布一致では
  SDE の field が同定されない**という構造的な所見である (§6.1)。
- H5 は否である。$W_2$ 損失条項 (a) 自体が失敗する (0.00395 > EM の 0.00226) うえ、
  $\Sigma$ 条項 (b) も差 0.932 で同点域 0.01 を大きく超えて失敗する。
  バイアスが W2 に有利なはずの指標で W2 が負けた点が、H5 の否をさらに強くする。

### 5.2 蒸留の精度

| field | 選択 (次数, しきい値, 活性項) | validation NRMSE | test NRMSE 対 teacher | test NRMSE 対真値 |
|---|---|---|---|---|
| drift | 次数 3, 0.02, 18 項 | 0.03268 | **0.03618** | 1.3236 |
| diffusion (L 4 成分 joint) | 次数 3, 0.02, 24 項 | 0.01487 | **0.01567** | — |
| diffusion の implied $\Sigma$ | — | — | **0.03106** | 0.9898 |

diffusion の成分別 test RMS 誤差 (対 teacher): $L_{11}$ 0.00310 (RMS 0.3105)、$L_{12}$ 0 (恒等的に 0)、
$L_{21}$ 0.00345 (RMS 0.0551)、$L_{22}$ 0.00508 (RMS 0.3054)。
oracle (真値への fit) の天井は drift 次数 1 で test NRMSE $4.3 \times 10^{-16}$、
diffusion 次数 0 で $6.2 \times 10^{-15}$ であり、真値 field は多項式で厳密に表せる。
したがって symbolic の対真値誤差 (drift 1.32) は蒸留手順の失敗ではなく、**teacher の誤差の引き継ぎ**である。
蒸留そのものは on-manifold では成功している (対 teacher 0.036 / 0.016)。

### 5.3 求めた symbolic SDE (TeX、元座標)

蒸留で得た SDE は次である ($W$ は 2 次元独立 Wiener 過程、$\hat f$ / $\hat L$ は
`outputs/daily_neural_sde/day05/symbolic_sde.tex` の生成 TeX と同一。
状態は $x$ = *per* mRNA、$y$ = *per* タンパク質):

$$
\mathrm{d}\begin{pmatrix} x_t \\ y_t \end{pmatrix}
= \hat f(x_t, y_t) \,\mathrm{d}t + \hat L(x_t, y_t) \,\mathrm{d}W_t
$$

```tex
\begin{aligned}
\hat f_x &= - 0.6661 + 0.02211\,y - 0.5535\,x + 0.6057\,y^{2} - 1.997\,x y + 2.078\,x^{2} - 0.2369\,y^{3} + 1.035\,x y^{2} - 1.667\,x^{2} y + 1.571\,x^{3} \\
\hat f_y &= 0.7568 - 0.2728\,y + 0.3988\,x - 0.9582\,y^{2} + 2.439\,x y - 2.596\,x^{2} + 0.3023\,y^{3} - 1.137\,x y^{2} + 2.064\,x^{2} y - 1.778\,x^{3} \\
\end{aligned}
\begin{aligned}
\hat L_{11} &= 0.5279 - 0.3347\,y + 0.5165\,x + 0.01126\,y^{2} - 0.3456\,x y + 0.3971\,x^{2} + 0.07247\,y^{3} \\
\hat L_{12} &= 0 \\
\hat L_{21} &= 0.06232 - 0.005939\,y + 0.2205\,x + 0.01637\,y^{2} - 0.0929\,x y + 0.0531\,x^{2} + 0.009294\,y^{3} - 0.07507\,x y^{2} - 0.103\,x^{3} \\
\hat L_{22} &= 0.5227 - 0.3805\,y + 0.5117\,x + 0.05866\,y^{2} - 0.3731\,x y + 0.454\,x^{2} + 0.06569\,y^{3} + 0.08907\,x y^{2} \\
\end{aligned}
```

読み取り: 真値 drift は線形 ($f_x = -0.19x - 0.21y$、$f_y = 0.21x - 0.19y$) なのに、
symbolic drift は定数項 (−0.6661, 0.7568) と $x^2$・$xy$・$x^3$ の大きな係数 (±2 前後) を持つ。
これは teacher の MLP が学習した「強い渦」field を多項式が忠実にコピーしたものであり、
物理的な意味を持つ係数ではない (Day 4 の反省どおり、打ち消し・外挿リスクとして読む)。
diffusion 側も同様に、真値は定数なのに symbolic には $x$・$y$ の 1 次項 (0.52 / −0.33 など) が現れる。
これは teacher の diffusion が状態依存に漏れたことを SINDy がコピーしたものである。

### 5.4 真値との比較と共線性 (H3 の内訳)

train query 状態での共線性診断: $\mathrm{corr}(x, y) = 0.7839$、VIF $= 2.60$、
次数 2 特徴量間の最大絶対相関 $= 0.909$。正の相関の機構は減衰螺旋そのものである:
初期条件 (0, 1) からの軌道は $x$ と $y$ が同符号で動く弧を描きやすく、観測状態は $(x, y)$ 平面の帯に集中する。
VIF は 10 以下だが、次数 2 特徴量間の 0.909 という相関が、次数 3 までの多項式ライブラリ内での実質的な共線性の強さを示している。

H3 の判定: symbolic drift の対真値 NRMSE 1.3236 > 0.30、線形係数 RMSE 0.4555 > 0.20、
teacher の $\Sigma$ 対真値 NRMSE 0.9876 > 0.30 で、3 条項すべてが失敗する。
線形係数の内訳: symbolic の定数項は (−0.6661, 0.7568) で真値 (0, 0) から大きくずれ、
線形行列も $\begin{pmatrix} -0.5535 & 0.0221 \\ 0.3988 & -0.2728 \end{pmatrix}$ と
真値 $\begin{pmatrix} -0.19 & -0.21 \\ 0.21 & -0.19 \end{pmatrix}$ とは別物である。
失敗の主因は teacher の $W_2$ 学習の非同定性であり (§5.1)、蒸留手順の失敗ではない
(symbolic の対 teacher 誤差は 0.036 であり、teacher の誤差がそのまま引き継がれる)。
なお oracle が厳密であることから、もし teacher が EM であれば symbolic は真値をほぼ完全に回復したはずである
(EM の drift NRMSE 0.093 がその目安)。

### 5.6 off-manifold 格子診断 (3 軸)

| 比較 | drift NRMSE | diffusion (L) NRMSE |
|---|---|---|
| symbolic vs teacher | 3.7617 | 0.6778 |
| symbolic vs 真値 | 11.8019 | 3.3834 |
| teacher vs 真値 | 3.0949 | 1.8517 |

Day 3 (格子上で安定) や Day 4 (teacher は格子上で崩壊するが symbolic は teacher に近い) とは異なり、
本日は **teacher 自体が格子上で大きく崩壊し (drift 3.09)、symbolic はそれをさらに増幅する (drift 3.76 対 teacher、11.80 対真値)**。
理由は 2 つある: (a) W2 teacher の MLP field が学習状態の同時分布 (螺旋帯) の外では保証されないこと、
(b) symbolic の次数 3 多項式が teacher の野生的な field を格子上でさらに発散させること。
格子は周辺範囲ではデータ範囲の内側にあるため、これは「遠方外挿の失敗」ではなく
**「同時分布からの乖離に対する失敗」**として報告するのが正確である。
on-manifold の蒸留成功 (drift 0.036) と off-manifold の崩壊 (11.80) の落差が、本日の最大の対比である。
なお格子上の NRMSE が 1 を大きく超えるのは、格子点での真値 field の RMS が小さいこと (原点付近では drift ≈ 0) も
分母効果として寄与する。絶対誤差の観点でも teacher drift は原点で 1.0 前後の誤差を持つため、崩壊は分母効果だけではない。

### 5.7 $W_2$ 損失の識別力チェック (事後診断、凍結仮説ではない)

同じ test 軌道分布に対する近似 $W_2$ 損失:

| モデル | test $W_2$ 損失 |
|---|---|
| 真値 (新しい乱数) | 0.00111 |
| EM teacher | 0.00226 |
| W2 teacher | 0.00395 |
| 真値 drift + 2 倍 diffusion ($\sqrt{2}$ 倍の $L$) | 0.02270 |
| ゼロ drift + 真値 diffusion | 0.15054 |

真値自身のサンプリングフロア (0.00111) に対して W2 teacher (0.00395) は 3.6 倍程度であり、
ゼロ drift (0.1505) や 2 倍 diffusion (0.0227) とは明確に区別される。
したがって §5.1 の「分布は合うのに field は合わない」は、損失が鈍いためではなく、
**周辺分布の時間発展だけでは drift と diffusion の組み合わせが一意に決まらない**ためである。
強い渦 + 強いノイズは、単一初期条件からの周辺分布の流れを、真値の弱い渦 + 弱いノイズとほぼ同じに再現できる。
これは Day 3 の「終端観測のみでは $A$ が同定されない」という反省と同型の、分布一致学習版の非同定性である。

## 6. 考察

1. **分布一致は field 同定ではない**。本日の最大の所見は、$W_2$ 損失が 0.00395 と真値のサンプリングフロアに近い水準まで
   下がった teacher の drift が NRMSE 1.32、$\Sigma$ が 0.99 と壊れていることである。
   単一初期条件からの周辺分布の時間発展は、drift と diffusion のトレードオフ (強い渦 + 強いノイズ vs 弱い渦 + 弱いノイズ) を
   分離できない。論文の END-nSDE が $(\sigma_0, c)$ の族や複数条件のデータを扱うのは、この非同定性を緩和する方向であり、
   本日の 1 スライス・単一初期条件への切り取りが、非同定性を最も強く露出させた可能性がある。
   $W_2$ ベースの再構成を評価する際は、分布損失だけでなく遷移レベルの指標 (尤度や field 誤差) を併記すべきである。
2. **蒸留の成功と真値回復は別の軸**である (Day 2–4 と同じ教訓の最も強い形)。
   本日は蒸留 (H1・H2)、シミュレーション (H4)、downstream (H6) がすべて「成」でありながら、真値回復 (H3) は 3 条項すべてが失敗した。
   対 teacher 指標だけを見ると「成功した蒸留」に見えるが、teacher が真値から壊れている場合、その成功は真値について何も言わない。
   シリーズの報告では、対 teacher 指標と対真値指標を常に分けて提示する現行の流儀が、本日ほど効いた日はない。
3. **EM の強さは系の単純さと遷移情報の両方による**。EM が drift 0.093 / $\Sigma$ 0.056 と優れたのは、
   真値が線形 drift + 定数 diffusion という単純な形であることと、遷移尤度が「次の状態がどこから来たか」という
   ペア情報を用いることの両方による。$W_2$ 損失はペア情報を捨てて周辺分布だけを見るため、同じデータ量でも同定力が弱い。
   手法間の優劣を論じる際は、使う情報量 (遷移ペア vs 周辺分布) を明示すべきである。
4. **off-manifold 崩壊は teacher と symbolic の二重の失敗である**。Day 4 では symbolic が teacher に近いまま崩壊したが、
   本日は symbolic が teacher よりさらに悪化する (drift 3.76 対 teacher)。次数 3 多項式は、野生的な MLP field を
   格子上で増幅する。蒸留の次数選択は validation (on-manifold) のみで行われるため、off-manifold での増幅は選択時に見えない。
   格子診断を「選択後の報告」ではなく「次数選択のペナルティ」に使うかどうかは、Day 6 以降の検討課題である
   (ただし test 漏れにならないよう、格子は validation 的な位置づけで使う必要がある)。
5. **蒸留の成功と論文の主張は別の軸**である (Day 2–4 と同じ教訓の再確認)。
   本日の H3・H5 の否は、Zhang et al. の主張への反証ではない。論文は $(\sigma_0, c)$ の族と完全な $W_2$ 訓練を用いており、
   本日はその両方を切り取った近似版をテストしたに過ぎない。論文が主張していない軸での「失敗」を数えない、という姿勢を維持する。

## 7. 反省 (Day 6 以降に適用)

- 単一初期条件からの周辺分布一致だけでは SDE の field は同定されないこと。
  $W_2$ 型の teacher を評価する際は、分布損失に加えて遷移レベルの指標 (field 誤差または遷移尤度) を必ず併記し、
  分布損失の合格を field の合格と読まないこと。複数初期条件のデータを用いることが非同定性を緩和するかを、次回以降の $W_2$ 系では検討すること。
- teacher の field が真値から大きくずれている場合、蒸留・シミュレーション・downstream の「成」は真値について何も言わないこと。
  対 teacher 指標の合格を報告する際は、対真値指標 (field 誤差) を同じ表に並べ、teacher の真値からのずれを先に明記すること。
- off-manifold 格子上の NRMSE が 1 を大きく超える場合、分母効果 (格子点での真値 field の RMS の小ささ) と絶対誤差の両方を報告すること。
  NRMSE だけでは「分母が小さいだけの見かけの崩壊」と「絶対誤差としても大きい真の崩壊」を区別できない。
- 次数選択が on-manifold の validation のみで行われる場合、次数 3 多項式が野生的な teacher field を off-manifold で増幅しうること。
  格子診断を次数選択に組み込む場合は、格子を test ではなく validation 的な位置づけで使い、test 漏れを起こさない設計にすること。

## 8. 限界

- 本日の teacher は論文の END-nSDE ではない (§2.2 の逸脱)。
  $(\sigma_0, c)$ の族、完全な結合 $W_2$ 損失、torchsde、RPA-DNA 例、NFκB 例、実験データは本日は扱っていない。
  論文の再構成誤差 (drift 0.15、diffusion 0.16) についての主張は、本日の結果では何も言えない。
  特に、本日の $W_2$ 非同定性の所見は、論文の完全版に対する反証ではなく、1 スライス・単一初期条件・近似損失への切り取りのもとでの所見である。
- パラメータ $(\alpha, \beta, \sigma_0, c) = (0.19, 0.21, 0.20, 0.50)$ は宣言したベンチマーク値の組み合わせであり、
  $(\sigma_0, c)$ は論文のグリッド内の 1 点である。
- $W_2$ 近似損失は周辺 $W_2$ + 共分散項であり、結合 $W_2$ ではない。結合 $W_2$ を用いた場合に非同定性が緩和されるかは未測定である。
- シミュレーション horizon は $t \in [0, 4]$ のみ。長期の定常分布への収束は未検証。
- off-manifold 格子は周辺範囲ではデータ範囲の内側にあり、強い外挿テストではない (§5.6)。
  その診断力は同時分布からの乖離にある。
- 既存 repo tests (`tests/test_distill.py` 等) は本環境 (environment.yml の完全環境ではない) では未実行。
  本日追加した `tests/test_daily_neural_sde_day05.py` の 5 tests と Day 1–4 の tests は全て通過 (計 22 tests)。
