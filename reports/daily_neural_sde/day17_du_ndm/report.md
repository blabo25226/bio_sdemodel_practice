## 0. 前日までの反省の適用

実行前に config へ入れた。test のあとでしきい値は動かしていない。

1. **対 teacher と対真値を同じ表に置く (Day 5)**。残差 RMS を NRMSE の横に置く (Day 11、Day 12)。
2. **格子の RMS を軌道上の残差 RMS の横に置く (Day 16)**。\(z\) と \(t\) を独立に組んだ積格子は選択に使わない。
3. **VIF ゲートは閉じた形の許可ではない (Day 13、Day 16)**。ゲートは選択された次数のライブラリに置く (Day 7)。次数 3、定数列を除く。ゲートの内外にかかわらず係数を \(0.3(80-z)\) や \(\sqrt{z}\) として読まない。
4. **失敗の帰属に oracle 天井を置く (Day 10、Day 16)**。同じ train query への次数 3 の通常最小二乗を、teacher の場と真値の場の両方で test に 1 回だけ当てた。選択には使わない。真値 oracle が機械精度なら、ドリフトの残差はライブラリの欠落ではない。
5. **データ NLL がフロアに近いときの一致はドリフト回復ではない (Day 14、Day 16)**。\(|b|\Delta t/(\sigma\sqrt{\Delta t})\) が 0.25 未満なら `drift_step_ratio_blind`。1 步 NLL の差が 0.05 nats 未満で、かつ teacher 対真値の NRMSE が 0.30 を超えるときだけ `nll_hides_drift` とする。差が小さくても残差 RMS は併記する。
6. **法則指標にはモンテカルロフロアを置く (Day 10、Day 16)**。フロアが teacher のしきい値を超えたら H5 は不定である。終端分散を平均経路の横に残す。平均経路の数値がフロアより小さくても、それを検出とは読まない。
7. **失敗率ゲートの外の経路は採点しない (Day 16)**。H4 は失敗率が 0.05 を超えるか終端分散が定義できなければ不定である。
8. **時刻と状態の共線性 (Day 2)**。ドリフトの引数は \((z,t)\) なので、ライブラリは \((z,t)\) の冪だけである。時刻を独立に引き直した感度を事前の条項にした。
9. **\(\sqrt{z}\) は真値 0 の成分ではないが、低強度では比が荒れる (Day 11)**。拡散のゲートは test の潜在状態での NRMSE と、非正の割合である。\([0.5,4]\) の帯はゲートにせず、軌道上の誤差の横に置く。5 倍を超えたら局所的な影であり \(\sqrt{z}\) ではない。

## 1. 論文要約

### 1.1 問題と提案

過分散の点過程を、潜在強度 \(Z\) が拡散過程である Cox 過程として扱う。
観測は事象時刻だけで、\(Z\) は見えない。
事前法則は

$$
dZ_t = b_\theta(Z_t, t)\,dt + \sigma(Z_t, t)\,dB_t.
$$

\(b_\theta\) はニューラルネットである。実験の \(\sigma\) は既知で、Section 4.1 では CIR の \(\sqrt{Z}\) である。
拡大濾過の結果（Theorem 2.1）は、点過程で条件付けたあとも強度は同じ拡散係数の拡散のままで、ドリフトに \(\sigma^2\partial_z\log h\) が足される、というものである。
変分族（式 (3)）はこの形を保ち、補正 \(u_\beta\) を別のニューラルネットにする。
ELBO は Poisson 尤度から \(\tfrac12\int u_\beta^2\,dt\) を引いたもの（Theorem 3.1）である。
学習後は、新しい点過程に対する事後経路をこの SDE の 1 回の前進シミュレーションで出す。

Section 4.1 の真の強度は

$$
dZ_t = 0.3(80-Z_t)\,dt + \sqrt{Z_t}\,dB_t, \qquad Z_0 = 5,
$$

区間 \([0,4]\)、Euler–Maruyama 100 步である。
論文は、非パラメトリックなドリフトがデータに良く訪れた領域で主に学び、パラメトリックな CIR 族に制限すると係数が戻る、と図で示している。
MCMC 事後との経路比較、米国の銀行の呼、Allen のスパイク、相関付き 2 次元 CIR は別実験である。

### 1.2 選定理由

Day 16 は増分尤度の Lie 対称 surrogate である。
本日は、点過程の周辺尤度から潜在拡散のドリフトを変分 ELBO で学ぶ論文を選んだ。
採録は UAI 2026 で、ドリフトがニューラルネットである査読付き論文のうち新しいものである。
拡散は状態依存の \(\sqrt{z}\) で、冪のライブラリには入らない。
系は Section 4.1 の 1 次元 CIR 強度に時刻を足したものである。
Lorenz、OU、van der Pol、Lotka–Volterra、スコア、変分境界、NUNO、FIM、LieStoNet の \(1/x\) は避けた。
同じ 2026 年の nn-APPEX（AISTATS）は勾配流のドリフトとスカラー拡散を周辺分布から学ぶ。
本日の拡散は状態依存で、観測は軌跡ではなく Cox 過程のカウントである。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと teacher

真の Ito SDE は上の CIR である。Feller 条件 \(2\kappa\theta=48>1\) を満たす。
生成は床も反射も置かない。\(Z<0.2\)、\(Z>250\)、非有限のいずれかに触れた軌道は捨てて引き直す。
捨てた本数は train / validation / test とも 0 である。
残った軌道は \(T=4\)、\(\Delta t=0.04\)、100 步、初期値はすべて \(Z_0=5\)。
各ビンのカウントは \(\mathrm{Poisson}(Z_{t_j}\Delta t)\) である（Appendix G の Algorithm 3）。
分割は軌道単位で train 256、validation 64、test 64。seed 17 の単一ストリームでこの順に引く。
入力の平均と標準偏差は train の左端状態と残数だけから取る。
query 数は train 25600、validation 6400、test 6400。
train の \(Z\) は 4.72 から 83.4 である。
train の総イベント数の平均は 144.9、分散は 456.6、分散指数は 3.15 である。
単位 Poisson なら指数は 1 なので、過分散は生成されている。

teacher の事前ドリフトは \((z,t)\) を入力とする tanh MLP である。
事後補正は Section 3.3.1 の残数エンコーダで、

$$
u_\beta = \sigma(Z_t)\,\mathrm{MLP}_\beta(Z_t, t, r_t), \qquad
dZ_t = \bigl(b_\theta + \sigma u_\beta\bigr)dt + \sigma\,dB_t.
$$

\(\sigma(z)=\sqrt{z}\)（学習中は \(\sqrt{\max(z,0.5)}\)）。
Girsanov 罰則は \(\tfrac12 u_\beta^2\) であり、状態への加算は \(\sigma u_\beta\) である。
\(\sigma_{\mathrm{scale}}=1\) なので加算は \(z\cdot\mathrm{MLP}\) になる。
幅 64、隠れ層 2 枚、最終層の初期重みは Glorot の 0.1 倍、float64。
Adam、学習率 \(5\times 10^{-3}\)、勾配クリップ 5、外側の Brownian 経路 10 本、バッチ 32、100 epoch。
検証 ELBO が最大の重みを戻す。場の NRMSE は記録するが選択に使わない。

選択は epoch 99、検証 ELBO 389.901。
同じ検証ノイズで、真のドリフトと \(u=0\) の ELBO は 388.408、真のドリフトと学習した補正の ELBO は 389.863 である。
学習したモデルは零制御の真の事前を 1.49 nats 上回り、真のドリフトに学習した補正を足した参照とは 0.038 nats しか違わない。
test の ELBO は選択のあと 1 回で 395.928 である。test のイベント数が違うので、検証 ELBO との差は汎化ギャップとして読まない。

### 2.2 逸脱の明示

1. 論文は MLP の幅と深さを書いていない。本日は幅 64、深さ 2、最終層の初期スケール 0.1、train だけの標準化である。
2. 論文の学習集合は 256 本で、検証分割はない。本日は 256 / 64 / 64 の軌道分割で、チェックポイントは検証 ELBO の最大である。本日はその最大が最後の epoch 99 だった。
3. 補正は残数 MLP である。論文はこれを、特別な事前以外では誤特定だと書いている。Deep Sets と \(r_t/Z_t\) のハード制約は入れていない。条件付け地平は常に \(T\) なので、\(T'\) は入力にしない。
4. 事象は細分化（Algorithm 2）ではなく、Euler 格子上の Poisson カウント（Algorithm 3）である。ELBO から \(\log(N!)\) と \(N\log\Delta t\) を落とした。パラメータに依存しないので、argmax は点過程尤度の勾配と一致する。
5. 学習の Euler は 0.5 で床に投影する。H4、H5、H7 の評価はこの投影を外し、\(Z<0.2\) を `below_floor` とする。H8 の事後サンプラーは学習と同じ投影を使う。
6. 勾配は Euler–Maruyama を通した逆モード自動微分である。式 (12)、(13) の前進感度 SDE は実装していない。経路方向の微分は同じ対象である。
7. 拡散は学習しない。多項式の \(\sigma\) は \(\sqrt{z}\) へのライブラリ探針であり、ニューラル teacher ではない。
8. MCMC、銀行の呼、スパイク、多変量 CIR、部分区間の条件付け、パラメトリック CIR 族の対照は範囲外である。

## 3. 仮説（config に事前凍結）

実行前に `configs/daily_neural_sde_day17.json` へ書いた。しきい値の位置は、学習前の解析的 CIR だけで見積もった（軌跡上の次数 3 はドリフト NRMSE が機械精度、\(\sqrt{z}\) の次数 3 は軌跡上約 0.005 で \([0.5,4]\) では約 0.31、ステップ比の平均は約 0.55、独立アンサンブル 64 本の平均経路フロアは約 0.97、終端分散の相対フロアは約 0.084、ドリフトの定数バイアス 2 の対の経路 RMSE は約 3.1、バイアス 5 は約 7.7 で NRMSE 約 0.36、真値 EM の失敗率は 0、粗視化の終端 RMSE は約 0.11）。test のあとでしきい値は動かしていない。

- **H1** (ドリフト): symbolic 対 teacher \(\le 0.20\)、teacher 対真値 \(\le 0.30\)、symbolic 対真値 \(\le 0.35\)。残差 RMS は併記し、ゲートにはしない。pass は \(0.3(80-z)\) ではない。
- **H2** (拡散の探針): test の潜在状態で多項式対 \(\sqrt{z}\) の NRMSE \(\le 0.05\)、かつ非正の割合 \(\le 0.02\)。低強度帯はゲートではない。軌道上の 5 倍を超えたら局所的な影であり、\(\sqrt{z}\) ではない。
- **H3**: 係数回復の仮説は置かない。選択された次数の VIF 最大（定数列を除く）が 10 を超えたら不定。10 以下でも閉じた形としては読まない。
- **H4**: test と同じ初期値 \(Z_0=5\) の 64 本、同じ Wiener 増分。拡散は論文の \(\sqrt{z}\)。失敗率は各モデル \(\le 0.05\) かつ symbolic と teacher の差 \(\le 0.02\)。失敗クラスは `non_finite`、`below_floor`、`outside_radius`。失敗率の最大が 0.05 を超えるか終端分散が定義できなければ不定。内側のときだけ、対の経路 RMSE（symbolic 対 teacher \(\le 4\)、teacher 対真値 \(\le 6\)）、終端分散の相対誤差（\(\le 0.40\)、\(\le 0.50\)）、ドリフトの teacher 対真値 \(\le 0.30\)、をすべて要求する。**H4b** は拡散を多項式探針に替えて同じゲートを掛ける。
- **H5**: 初期値をすべて 5 にした独立な 64 本。平均経路 RMSE は teacher \(\le 4\)、symbolic \(\le 5\)。終端分散の相対誤差は teacher \(\le 0.35\)、symbolic \(\le 0.45\)。失敗率 \(>0.05\)、または真値対真値のフロアが teacher のしきい値を超えたら不定。
- **H6**: test 状態で時刻だけを \(U[0,T]\) から引き直した相対 RMS が、teacher \(\le 0.15\) かつ symbolic \(\le 0.15\)。積格子（train の \(z\) の 5–95 パーセンタイル、\(t\in[0,4]\)、\(8\times 8\)、選択には未使用）で、teacher 対真値 \(\le 0.50\)、symbolic 対 teacher \(\le 0.30\)。格子 RMS が軌道上の残差 RMS の 2 倍を超えたら増幅として記録する。
- **H7**: teacher の \(\Delta t=0.04\) と \(\Delta t=0.02\)（細かい標準正規 2 本の和を \(\sqrt{2}\) で割った粗い増分）の終端 RMSE \(\le 1.5\)、かつ両方が有限な割合 \(\ge 0.95\)。
- **H8**: test のカウントで条件付けた事後平均経路の RMSE \(\le 8\)、かつ事前（\(u=0\)）より少なくとも 1 小さい。失敗率 \(>0.05\) なら不定。これは残数エンコーダの診断であり、論文の Deep Sets 図の再現ではない。

## 4. 方法

teacher の事前ドリフトへの直接 query。特徴は左端状態 \((z,t)\)。
SINDy の標準化は train query だけから取る。
ドリフトのライブラリは \((z,t)\) の冪だけである。拡散の探針は \(z\) の冪だけである。三角関数、指数、平方根は入れない。
次数 \(\{1,2,3\}\)、しきい値 \(\{0, 0.02, 0.05, 0.1, 0.2, 0.35\}\)、ridge \(10^{-4}\)。
検証 NRMSE の最小。同点はより小さい次数、次に小さいしきい値。test はこの選択のあと 1 回。

選択結果: ドリフトは次数 3・しきい値 0（活性 10、ライブラリ 10 項、検証スコア 0.0821）。
しきい値 0.02 と 0.05 も同じ 10 項と同じスコアで、同点規則が 0 を選んだ。次数 2 の検証スコアは 0.120 である。
拡散の探針は次数 3・しきい値 0（活性 4、ライブラリ 4 項、検証スコア 0.00408）。
どちらも疎ではない。

診断として、次数 3・通常最小二乗を teacher と真値の両方に train query で当て、test で 1 回評価した。選択には使わない。
ドリフトの次数 3 ブートストラップは軌道 12 本の復元抽出である。選択には使わない。
シミュレーションは失敗をラッチし、上の 3 クラスを分ける。

ブートストラップ 12 本のサポート一致は 1 である。しきい値 0 は項を落とさないので、これは安定した疎なサポートではない。

### 5.2 推定した symbolic SDE

標準化座標の活性はドリフト 10、拡散 4 である。どちらもライブラリの全項である。
train の平均は \((z,t)=(36.21,\,1.98)\) で、\(z\) の平均は 0 ではない。
係数は `symbolic_sde.tex` と一致する。これは teacher の多項式近似であり、上の CIR ではない。
ファイル内の `6.245e-05` と `1.172e-05` は下の \(10^{-5}\) と同じ数である。

SINDy が返した式は、ドリフトも拡散も冪だけである。

$$
\begin{aligned}
dZ_t &= b(Z_t,t)\,dt + \sigma(Z_t)\,dW_t,\\
b(z,t) &= 22.76 + 6.884\,t - 0.2487\,z - 15.31\,t^{2} + 1.253\,z t - 0.04004\,z^{2} \\
&\quad + 3.55\,t^{3} - 0.3303\,z t^{2} + 0.009753\,z^{2} t + 6.245\times 10^{-5}\,z^{3},\\
\sigma(z) &= 1.485 + 0.1843\,z - 0.002042\,z^{2} + 1.172\times 10^{-5}\,z^{3}.
\end{aligned}
$$

論文の拡散、つまり H4 と H5 で使った teacher の拡散は、この多項式ではない。

$$
\sigma_{\mathrm{paper}}(z) = \sqrt{z}.
$$

\(b\) の定数 22.76 と \(z\) の係数 \(-0.249\) は、真値 \(24-0.3z\) に数値として近い。
同じ式は \(t\) の 2 次と 3 次を \(-15.31\) と \(3.55\) で持っている。
VIF は 895 で H3 は不定である。この近さは \(0.3(80-z)\) の回復ではない。
\(\sigma\) の VIF は 3.86 である。軌道上の NRMSE は 0.00424 で、\([0.5,4]\) では 0.316 である。この立方は \(\sqrt{z}\) ではない。

## 6. 考察

軌道上の H1 は通った。teacher 対真値 0.164、symbolic 対 teacher 0.084、symbolic 対真値 0.144 である。
真値への次数 3 oracle は \(10^{-15}\) なので、真のドリフトはライブラリに入っている。
symbolic 対真値の 0.144 は、ライブラリが CIR を書けないからではない。
teacher への次数 3 oracle が 0.0841 で、選択式と一致する。しきい値は項を落としていない。
残っている 0.084 は、この teacher の場が次数 3 の中でそれ以上は縮まない分である。

その teacher の場は時刻に依存する。時刻を独立に引き直すと、teacher は自分の RMS の 0.966 倍動く。真のドリフトは 0 である。
積格子では teacher 対真値の NRMSE が 0.892、RMS が 12.9 になる。軌道上の残差 RMS は 2.26 で、比は 5.71 である。
検証 ELBO は、真のドリフトに学習した補正を足した参照と 0.038 nats しか違わない。
ELBO がこの参照に乗ることと、ドリフトが \(0.3(80-z)\) であることは別である。
残数エンコーダは論文が誤特定だと書いた選択肢なので、時刻への漏れは論文の Deep Sets の性質としては主張しない。
この切り取りの中では、周辺 ELBO が事前ドリフトの時刻独立性を固定していない。

H4 と H5 の失敗は終端分散である。失敗率は 0 なので不定ではない。
対の経路 RMSE 1.43 と平均経路 1.30 はそれぞれの絶対しきい値の内側だが、平均経路は真値対真値のフロア 1.83 より小さい。
平均経路の内側は、分散の相対誤差 0.58 を消さない。
再生した終端分散は真値 71 に対して teacher 112 である。
多項式拡散に替えても対の経路 RMSE は 0.596 から 0.591 に変わるだけで、H4b も同じ分散項で落ちる。
拡散探針は、データ範囲では \(\sqrt{z}\) の局所影として十分近い。経路の失敗の原因ではない。

H8 は通った。事後平均の RMSE 4.69 は事前の 6.06 より 1.37 小さく、ゲートの 1 を超えている。
残数はカウントを使っている。改善幅は小さく、論文の MCMC 図の再現ではない。

H7 の終端 RMSE 0.106 は、学習前に真の CIR で見積もった粗視化差 0.11 と同じ桁である。
このステップでは teacher のドリフトは、評価に使った解法を壊していない。

1 步 NLL の差 \(4\times 10^{-3}\) nats は、残差 RMS 2.26 から拡散が支配する 1 步尤度へ落ちる桁と一致する。
ステップ比 0.548 は盲目ゲート 0.25 の上にある。それでも NLL は、H1 がすでに見ている場の誤差を、より細かくは見ていない。

## 7. 反省

検証 ELBO が真のドリフトの零制御 ELBO を 1.5 nats 程度しか上回らないとき、軌道上の NRMSE が 0.2 未満でも時刻シャッフル感度は 1 近くまで残りうる。
翌日は、ELBO や 1 步 NLL の一致をドリフト同定の証拠に足さず、引数を独立に壊した感度と、そのときの格子 RMS を軌道上の残差 RMS の横に置く。
平均経路がモンテカルロフロアより小さくても、終端分散は別の条項として残す。
