# Skill: literature and source verification

## Goal

コード/API/データの由来を一次情報で確認する。

## Priority

### API / implementation facts

1. installed source/runtime
2. current official docs
3. official GitHub / release
4. manuscript reproducibility repo

### Scientific claims

1. version-of-record paper
2. supplementary information
3. original dataset paper
4. preprint

## Record

新しい重要ソースを使ったら `source.md` に以下を追加する。

```text
Title:
Authors:
Year:
URL/DOI:
Why relevant:
Accessed:
```

## Avoid

- blog を primary evidence にする
- outdated API snippet を current code として扱う
- citation without checking original context
