## 1. 論文要約

### 1.1 問題と提案

多くの時系列は、連続的なフローと確率的イベントによる離散的なジャンプの組み合わせで生成される
(論文 §1)。Jia & Benson は、Neural ODE を確率的なジャンプ項で拡張した Neural Jump SDE (NJSDE) を提案する:
dz(t) = f(z(t), θ)dt + w(z(t), θ)dN(t)。ここで N(t) は、潜在状態に依存する条件付き強度 λ(z(t)) を持つ
カウント過程であり、イベント時刻における不連続性を adjoint 法で扱う (ジャンプ時の adjoint ベクトルを持ち上げる)。
モデルは、潜在軌道が区分連続であり、イベントによって中断されるようなハイブリッド系として、
古典的点過程 (Hawkes など)、Stack Overflow の受賞、医療記録、地震モニタリングといった
marked point process データの将来イベント予測に適用され、既存手法を上回る予測性能が報告されている。

### 1.2 本日の切り取りと選定理由 (多様性の観点)

前日までとの重なり回避: Day 1 は勾配ベース学習 (Li)、Day 2 は GAN (Kidger)、Day 3 は変分潜在モデル (Tzen)、
Day 4 は市場較正 (Gierjatowicz)、Day 5 は W₂ 分布一致 (Zhang)、Day 6 は遅延 SDDE (Eggen & Midtfjord)、
Day 7 は構造制約による安定化 (Oh et al.) であった。いずれも連続拡散のみのモデルである。
本日は **ジャンプ項を持つ系**という未使用の手法系、**点過程・イベント**という未使用のドメイン、
**ジャンプ強度 λ(x) の状態依存性とジャンプサイズ分布**という未使用の field 構造を選んだ。
次元は 1 次元で Day 2 と重なるが、Day 2 が時間依存 OU (ジャンプなし) であるのに対し、
本日は時間同次ジャンプ拡散であり、問いは diffusion とジャンプの分離そのものである。
データ入手可能性: 論文は実データの marked point process を用いるが、潜在座標は識別不能であるため、
憲章のスコープ境界に従い、識別可能な座標で teacher を再構成する:
観測可能な 1 次元ジャンプ拡散を真値とし、合成データとして再生成する
(憲章の選定条件 (a) は「生成過程が特定できる」ことで満たす)。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと真値

真値は論文のジャンプ形式に Brownian 拡散項を加えた 1 次元ジャンプ拡散である:

$$
dX = -0.60 X\, dt + 0.35\, dW + J\, dN(\lambda(X)), \qquad
\lambda(x) = 0.25 + 0.08 x^2, \qquad J \sim \mathcal{N}(-0.80, 0.50^2).
$$

drift は線形平均回帰、diffusion は定数、λ は 2 次多項式、ジャンプサイズは定数の平均・標準偏差である。
ジャンプが下向き (平均 −0.80) であるため、定常平均は 0 ではなく約 −0.34 にずれる
(−0.60·E[X] + E[λ]·(−0.80) ≈ 0 より)。
軌道は Euler–Maruyama (dt_fine = 0.01、細ステップごとに確率 λ(x)·dt_fine でジャンプ) でシミュレーションし、
0.05 ごとに観測した (t ∈ [0, 10]、201 点)。
軌道数は 768 本で、trajectory-disjoint に train 480 / validation 144 / test 144 (seed 0)。
初期値は X(0) ~ Normal(0, 1) の独立抽出である。
状態統計 (train 軌道): 平均 −0.343、標準偏差 0.684、範囲 [−6.42, 3.07]。
test 遷移 28,800 件のうち |ΔX| > 0.5 の大増分は 327 件 (率 0.01135) であり、
拡散のみの 1 ステップ標準偏差 0.35·√0.05 = 0.078 に対して 0.5 は約 6.4σ であるため、大増分はジャンプ支配である。

### 2.2 逸脱の明示

1. **潜在点過程パイプラインから観測可能ジャンプ拡散への置換**: 論文の NJSDE は、潜在軌道・イベント時刻 adjoint・
   marked point process の予測パイプラインである。その潜在座標は観測データから識別不能であるため、
   憲章に従い、論文のジャンプ形式 (状態依存強度 λ(z)、ジャンプ関数 w) を保ちつつ、
   識別可能な観測座標上の 1 次元ジャンプ拡散として teacher を再構成した。
   したがって本日の結果は論文のベンチマーク性能について何も主張しない。
2. **連続部分への拡散項の追加**: 論文の連続ダイナミクスは決定論的 ODE + ジャンプであり、Brownian 項を持たない。
   本日は diffusion 項 g dW を追加した。これは、観測増分における diffusion とジャンプの分離をテスト可能にするための逸脱であり、
   論文のモデルクラスそのものの再現ではない。
3. **訓練法の置換**: 論文のイベント時刻 adjoint による点過程尤度ではなく、シリーズ標準の遷移尤度に置換した。
   具体的には 2 成分ガウス混合尤度である: ジャンプなし成分 N(x + fΔt, g²Δt) (重み exp(−λΔt)) と
   1 ジャンプ成分 N(x + fΔt + μ_J, g²Δt + σ_J²) (重み 1 − exp(−λΔt))。
   Δt = 0.5 の粗視化版では複数ジャンプ (確率 ~1%) を無視する近似を含むことを明示する。
4. **Hawkes / Stack Overflow / MIMIC / 地震データ、marked point process の予測タスク、adjoint 訓練は本日は扱わない**。
   論文の予測性能の主張は、本日の合成ジャンプ拡散でのみテストした。

## 3. 仮説 (実行前に config へ凍結)

- **H1 (drift 蒸留)**: symbolic drift の test NRMSE (対 teacher) ≤ 0.30。
- **H2 (diffusion 蒸留)**: symbolic g の test NRMSE (対 teacher) ≤ 0.30、かつ
  symbolic の implied Σ (= g²) の test NRMSE (対 teacher の Σ) ≤ 0.30。
- **H2j (ジャンプ蒸留)**: symbolic λ の test NRMSE (対 teacher) ≤ 0.30、かつ
  μ_J・σ_J の teacher 平均との絶対誤差がそれぞれ ≤ 0.20。
- **H3 (真値回復、field 水準)**: symbolic drift の test NRMSE (対真値) ≤ 0.60、かつ
  symbolic λ の test NRMSE (対真値) ≤ 0.60。
- **H3c (真値回復、線形係数水準)**: 事前凍結の診断 fit (原点固定・次数 2・しきい値 0.05) の展開後の線形係数
  (真値 −0.60) の絶対誤差 ≤ 0.20。λ の 2 次係数は固定次数 fit の表に載せるだけで判定なしとする。
- **H4 (シミュレーション)**: symbolic の失敗率 ≤ 0.05 かつ teacher との差 ≤ 0.02、
  paired RMSE (対 teacher) の中央値 ≤ 1.0 (ジャンプ時刻のずれが支配するため緩いしきい値であり、主条項ではない)、
  かつドメイン条項として |X| > 8 の逸脱率の symbolic − teacher ≤ 0.10 かつ λ クリップ率 ≤ 0.05。
  失敗は non-finite または |X| > 30。symbolic の λ はシミュレーションで 0 に、σ_J は 0.01 にクリップし、クリップしたステップを数える。
- **H5 (論文軸: ジャンプ vs 拡散のみ)**: 両条項が成ること。
  (a) test 遷移の予測 NLL について、NLL(拡散のみ) − NLL(ジャンプ) > 0.02 かつ paired SE の 2 倍超。
  絶対 NLL 水準も両 teacher について併記する。
  (b) 主条項は絶対水準: シミュレーションされた大増分率 (|ΔX| > 0.5 のステップ率) について、
  symbolic と teacher がともに観測率 (0.01135) から 0.01 以内であり、かつ拡散のみ teacher が観測率から 0.01 超はずれること。
- **H6 (離散化バイアス診断、Day 1・Day 6・Day 7 の反省)**: 遷移数を揃えた制御比較で、
  (a) ジャンプ混合 EM (Δt = 0.5) の drift field NRMSE が EM (Δt = 0.05、同一遷移数) より 0.03 以上悪化すること、
  (b) 悪化幅が大 |x| レジーム (|x| > 1.5) で小 |x| レジーム (|x| < 0.5) より 0.02 以上大きいこと。
  per-transition SNR をレジーム別に定量化し、drift と diffusion (および λ) の粗視化比較は別々に解釈する。
- **H7 (論文軸の代理: one-step 予測)**: test 遷移での one-step 平均予測 (x + fΔt + μ_J·λΔt) の MSE について
  |MSE_symbolic − MSE_teacher| ≤ 0.002。paired 標準誤差を併記し、paired SE ≥ 0.001 の場合は
  点推定が合格しても「統計的に確定しない」とする (Day 4 の反省)。

## 4. 方法 (main と同じ流儀)

- teacher への直接 query で function distillation。query 点は各 split の観測状態
  (trajectory-disjoint)。変換 (mean/scale) と RMS 正規化は train query のみから。
  ただし原点固定ライブラリでは mean を 0 に固定する (scale のみ train から)。
- teacher: ジャンプ teacher (f ネット [32, 32] tanh、g・λ・μ_J・σ_J ネット各 [16] tanh、
  g = softplus + 0.01、λ = softplus + 0.01、σ_J = softplus + 0.05、入力は x のみ) と
  拡散のみ teacher (f ネット [32, 32]、g ネット [16]、ガウス EM)。
  両者とも train 遷移 (96,000 件) で訓練 (Adam lr 0.003、40 epochs、batch 8192)。
  粗視化ペアは各 9,600 遷移 (batch 2048、40 epochs)。
- 候補: drift は次数 {1, 2, 3} × {自由, 原点固定}、g は次数 {0, 1, 2}、λ は次数 {1, 2, 3}、
  μ_J・σ_J は次数 {0, 1}、STLSQ しきい値 {0.02, 0.05, 0.1, 0.2, 0.35}。
  field ごとに validation NRMSE で選択し、test は確定後に 1 回だけ評価。
- oracle 診断: 同じ SINDy 手順を真値 field に fit (天井の診断)。
- 共線性診断: fit の前に train query 状態で次数 3 ライブラリ (定数列を除く) の VIF を計算。
- 格子診断 (Day 2 の反省により標準手順): x ∈ [−4, 4] の 81 点格子で teacher / symbolic / 真値を比較する。選択には使わない (報告専用)。
- シミュレーション検証: test 軌道の初期値から、teacher / symbolic / 真値 / 拡散のみの各モデルを
  同一 Brownian 増分・同一一様ジャンプ抽出・同一ジャンプサイズ正規乱数 (paired) で
  Euler–Maruyama + ジャンプ (dt = 0.05、t ∈ [0, 10]) によりシミュレーション。
  各モデルは自分の λ(x) でジャンプを判定する (U < 1 − exp(−λΔt))。
  失敗は non-finite / |X| > 30 で分類し、質量を保持する。|X| > 8 の経験は「逸脱」、
  λ・σ_J のクリップはドメイン指標として失敗とは別に数える。
- ジャンプ汚染診断 (Day 1 の ĝ 比較のアナロジー): 拡散のみ teacher の ĝ (ジャンプを g に吸収する) と、
  大増分 (|Δ| > 0.4) をスクリーニングした二段階 ĝ 推定を真値と比較する。

## 5. 結果

### 5.1 推定器の比較 — teacher の対真値 field 誤差 (test query 状態、28,944 点)

| teacher | drift NRMSE vs 真値 (RMS 誤差) | g NRMSE vs 真値 | λ NRMSE vs 真値 | μ_J / σ_J (対真値 RMS) |
|---|---|---|---|---|
| ジャンプ (蒸留対象) | 0.1794 (0.0868) | 0.0149 | 0.2662 | 0.0358 / 0.0431 |
| 拡散のみ | — (drift は別途) | 0.7822 (0.2738) | — | — |
| ジャンプ粗視化 (Δt = 0.5) | 0.2632 (0.1274) | 0.1417 | 0.3362 | — |
| ジャンプ細分対照 (Δt = 0.05、同一遷移数) | 0.1715 (0.0830) | 0.0209 | 0.3199 | — |

読み取り:

- **ジャンプ teacher は全 field で真値に近い** (drift 0.179、g 0.015、λ 0.266)。
  λ の誤差が drift・g より大きいのは、λ が遷移尤度ではジャンプ確率として間接的にしか現れないためであり、
  混合尤度のもとでの λ の同定が drift・g より弱いことを反映している。
- **拡散のみ teacher の ĝ はジャンプ汚染で大きく膨らむ** (NRMSE 0.782、RMS 誤差 0.274、すなわち ĝ ≈ 0.62 に対して真値 0.35)。
  これは Day 1 の「ĝ の比較」診断のジャンプ版である: ジャンプを無視した推定器は、ジャンプの分散を diffusion に吸収する。
  対照的に、大増分スクリーニングによる二段階 ĝ 推定は 0.355 と真値 0.35 にほぼ一致する (スクリーニング率 98.77%)。
  すなわち、ジャンプの存在下での diffusion 推定には、混合尤度かスクリーニングのいずれかのジャンプ処理が必須である。

### 5.3 求めた symbolic SDE (TeX、元座標)

蒸留で得たジャンプ拡散は次である (x = X。完全展開は `outputs/daily_neural_sde/day08/symbolic_sde.tex` と同一。
全 field が読める規模であり、Day 6 の 375 項とは対照的である):

```tex
%% Day 8 symbolic jump-diffusion (Jia & Benson 2019 Neural Jump SDEs; distilled jump teacher; x = X)
\begin{aligned}
\hat f &= - 0.07828 - 0.618\,x + 0.02609\,x^{2} + 0.01079\,x^{3} \\
\end{aligned}
\begin{aligned}
\hat g &= 0.3464 \\
\end{aligned}
\begin{aligned}
\hat \lambda &= 0.2337 - 0.01084\,x + 0.1017\,x^{2} + 0.01331\,x^{3} \\
\end{aligned}
\begin{aligned}
\hat \mu_J &= - 0.8086 \\
\end{aligned}
\begin{aligned}
\hat \sigma_J &= 0.4977 \\
\end{aligned}
%% Jump term: dX = f dt + g dW + J dN(lambda), J ~ N(mu_J, sigma_J^2).
```

読み取り: g・μ_J・σ_J は真値 (0.35、−0.80、0.50) にほぼ一致する。
drift は真値の線形形 (−0.60x) に対して切片 −0.078 と小さな 2・3 次項を持つが、線形係数 −0.618 は真値に近い。
λ は真値 (0.25 + 0.08x²) に対して切片 0.234・2 次係数 0.102 と近く、1 次・3 次項は小さい (−0.011 / 0.013)。
field 水準では on-manifold で teacher に 0.036 (drift) / 0.070 (λ) で迫っており、係数水準でも大きく崩れていない
(Day 7 の GSDE とは対照的に、1 次元で VIF が低い (最大 3.72) ため、係数回復が field 回復と両立した例である)。

### 5.4 真値との比較と共線性 (H3・H3c の内訳)

train query 状態での共線性診断: 次数 3 ライブラリ (定数列を除く) の VIF は 1.46 (x)、3.36 (x²)、3.72 (x³) と低い。
1 次元では単調変換された単項式同士の相関が Day 7 の 2 次元ライブラリほど強くならず、係数回復が可能な条件が整っていた。
事前凍結の原点固定・次数 2 診断 fit の展開は f̂ = −0.591x − 0.0168x² であり、
線形係数の誤差は |−0.591 − (−0.60)| = 0.009 と小さく、H3c は成る。
診断 fit の対 teacher test NRMSE は 0.156 であり、選択モデル (0.036) より悪いが、これは次数 2 への固定と原点固定の代償である。
λ の固定次数 2 fit の展開は λ̂ = 0.247 − 0.0228x + 0.0510x² であり、真値 (0.25 + 0.08x²) に対して
2 次係数が 0.051 とやや小さく、1 次項 −0.023 を持つ (判定なし)。
なお、validation が原点固定ライブラリではなく自由ライブラリを選んだ理由は、teacher 自身が f(0) = −0.072 を持つためである:
teacher の MLP drift は原点で消えず、自由ライブラリの切片 −0.078 はその teacher の性質を再現している。
構造制約が validation で敗北したのではなく、teacher が構造を満たしていないことが原因である。
この点は、Day 7 の GSDE (teacher が構造を満たし、自由多項式がそれを壊した) とは対照的である。

### 5.6 格子診断 (x ∈ [−4, 4] の 81 点格子)

| 比較 | drift NRMSE (絶対 RMS 誤差) | g NRMSE (絶対 RMS) | λ NRMSE (絶対 RMS) |
|---|---|---|---|
| symbolic vs teacher | 0.0874 (0.1118) | 0.0813 (0.0298) | 1.1615 (0.6340) |
| symbolic vs 真値 | 0.1947 (0.2731) | 0.0102 (0.0036) | 0.4350 (0.3440) |
| teacher vs 真値 | 0.1263 (0.1771) | 0.0789 (0.0276) | 0.4254 (0.3364) |

symbolic の λ 負値率: 0/81 点。
読み取り: drift と g については格子でも symbolic は teacher に近い (drift 0.087、g 0.081)。
g については、teacher 自体が格子上で真値から 0.079 ずれており (MLP の g が x 依存の spurious な変動を持つため)、
symbolic (定数 0.3464) はむしろ真値に 0.010 と近い。すなわち格子の g の失敗は teacher の外挿失敗であり、蒸留の追加失敗ではない。
λ については対照的である: 格子全体では teacher 自体が真値から 0.425 と大きくずれており (大 |x| 域での飽和)、
symbolic は teacher に 1.162 (絶対 RMS 0.634) とさらに遠い。メカニズムは明確である:
真値 λ は x² で増大する (x = 4 で 1.53) が、teacher の λ は softplus MLP の飽和により大 |x| 域で頭打ちになり、
symbolic の 3 次多項式 (x = 4 で 2.67) は teacher の飽和をさらに上回って発散する。
すなわち λ の格子失敗は「teacher の飽和 + 多項式の発散」の二重の外挿失敗であり、on-manifold の成功 (0.070) とは別軸である。
λ の負値は格子上で 1 点も生じなかったため、負値ドメイン条項は本日は非拘束的であった。
これは λ の真値下限 (0.25) と symbolic の切片 (0.234) が近いことの帰結であり、原点付近のドメイン妥当性は保たれている。

### 5.7 論文軸の詳細 — H5: ジャンプ vs 拡散のみ

| 比較 (test 遷移 28,800 件 / paired シミュレーション) | ジャンプ teacher | 拡散のみ teacher | symbolic | 判定 |
|---|---|---|---|---|
| test 遷移予測 NLL (平均、nats) | −1.0318 | −0.5046 | — | 差 0.5272 ± SE 0.0270、成 |
| シミュレーション大ステップ率 | 0.00920 | 0.00156 | 0.00889 | 観測率 0.01135 との差: teacher 0.00215、symbolic 0.00247、拡散のみ 0.00979 |

H5 は**否**である。ただし否の内訳は限定的であるため、分けて読む必要がある。

- **NLL 条項 (a) は明確に成る**。ジャンプ teacher は拡散のみ teacher を 0.527 nats (paired SE 0.0270 の約 20 倍) 上回る。
  絶対水準でも、ジャンプ teacher の −1.0318 に対して拡散のみは −0.5046 であり、論文の方向性 (ジャンプ項の有効性) が
  本日の設定では強く支持される。拡散のみ teacher の NLL が悪いのは、ジャンプ増分をガウス 1 成分で説明しようとして
  分散を膨らませる (ĝ ≈ 0.62) ためであり、§5.1 の ĝ 汚染と同一のメカニズムである。
- **大増分率条項 (b) は、拡散のみの分離サブ条項だけが僅差で否である**。
  teacher と symbolic のシミュレーション大増分率は観測率からそれぞれ 0.00215 / 0.00247 以内であり、0.01 条項を満たす。
  しかし拡散のみの miss は 0.00979 であり、凍結しきい値 0.01 に 0.00021 だけ届かない。
  すなわち「拡散のみが観測率から 0.01 超はずれる」という分離条項が、僅差で未達であった。
  相対比では拡散のみの大増分率は観測率の約 1/7 であり、分離そのものは明確である。
  凍結した H5 の判定としては否を維持するが、この否は「ジャンプモデルの有効性への反証」ではなく、
  「率の絶対差で測った分離しきい値 (0.01) が、観測率自体の水準 (0.01135) に対して大きすぎた」という
  しきい値設定の所見である。今後、率の水準が小さい指標では、絶対差ではなく相対比を主条項とすべきである。
  これは Day 7 の「劣化の差分ではなく絶対水準を主条項に」という反省の、率指標版の対応物である。

### 5.8 離散化バイアス診断の詳細 — H6: EM の粗視化

| drift NRMSE (全体) | 0.1715 | 0.2632 | +0.0917 |

H6 は**成**である。(a) の悪化幅 +0.0917 はしきい値 0.03 を超え、(b) のレジーム間ギャップ 0.1166 − 0.0580 = 0.0586 は

per-transition SNR の定量化は次のとおり: 小レジームでは drift SNR が Δt = 0.05 で 0.085、Δt = 0.5 で 0.268 と約 3 倍になるが、

SNR の利益を上回ったと読むのが最も整合的である。
diffusion については、Day 7 とは異なり粗視化が大きく悪化した (g 0.021 → 0.142、Σ 0.041 → 0.274)。
これはジャンプ混合尤度のもとでは、粗視化ステップでの単一ジャンプ近似の破綻が diffusion の推定にも波及するためであり、
「diffusion の推定は刻みよりサンプルサイズに支配される」という Day 7 の所見は、ジャンプ系では成立しない。
λ 自体の粗視化悪化は小さい (0.320 → 0.336) が、これは細分対照の λ 誤差自体が既に大きい (0.320) ためであり、
λ の同定の弱さが粗視化比較を鈍らせている。

## 6. 考察

1. **ジャンプの有無は diffusion の推定そのものを変える**。本日の最も明確な所見は、拡散のみ teacher の ĝ が 0.62 まで膨らみ、
   ジャンプ teacher では 0.35 に戻ることである。ジャンプを無視することは、単にジャンプを捉え損なうだけでなく、
   連続部分のパラメータ推定を系統的に歪める。混合尤度かスクリーニング (二段階 ĝ は 0.355) のいずれかでジャンプを処理しなければ、
   diffusion の水準そのものが信用できない。これは、ジャンプ系における「diffusion の絶対水準が主題の日は 1-step 尤度でなく
   内部 substep のシミュレーションに基づく推定を使う」という Day 1 の反省の、ジャンプ版の対応物である。
2. **λ の同定は drift・g より弱い**。λ の teacher 誤差 (0.266) は drift (0.179) や g (0.015) より大きく、
   粗視化比較でも鈍い (0.320 → 0.336)。λ は遷移尤度ではジャンプ確率として間接的にしか現れず、
   1 遷移あたりのジャンプ情報量が小さい (λΔt ≈ 0.015) ためである。
   ジャンプ系の蒸留では、λ の field 誤差を drift・g と同じしきい値で判定すること自体が楽観的でありうる。
   本日は 0.30 しきい値を満たしたが、これは λ の真値が多項式そのものであったことと、遷移数が多いことのおかげである。
3. **構造制約の勝敗は teacher が構造を満たすかで決まる**。Day 7 では teacher が GSDE 構造を満たし、自由多項式がそれを壊した。
   本日は逆に、teacher 自身が f(0) ≠ 0 を持ち、自由ライブラリがそれを再現したために validation で勝利した。
   構造制約をライブラリに入れること自体は正しいが、その勝敗は teacher の性質の診断であり、蒸留手順の優劣ではない。
   構造制約を課す場合は、teacher の構造充足度 (本日でいえば f(0)) を事前に測っておくべきである。
4. **率指標のしきい値は水準に対して決めること**。H5(b) の僅差の否は、観測率 0.01135 に対して絶対差 0.01 というしきい値が
   大きすぎたために生じた。率の水準が小さい指標では、絶対差ではなく相対比 (本日では拡散のみは観測率の約 1/7) を主条項とすべきである。
   これは Day 7 の「劣化の差分ではなく絶対水準を」という反省を、率指標に翻訳したものである。
5. **蒸留の成功と論文の主張は別の軸**である (Day 2–7 と同じ教訓の再確認)。
   本日の H5 の否は、Jia & Benson の主張への反証ではない。論文は潜在点過程パイプラインと実データ予測を用いており、
   本日はその両方を切り取った観測可能ジャンプ拡散の合成版をテストしたに過ぎない。
   論文が主張していない軸での「失敗」を数えない、という姿勢を維持する。
6. **粗視化の悪化は、ジャンプ系では Day 6・7 の SNR 利益を上回る**。本日は粗視化が細分対照を全体で下回り、
   特に diffusion の悪化が大きかった。ジャンプ混合尤度のもとでは、粗視化は単なる SNR のトレードオフではなく、
   単一ジャンプ近似の破綻という構造的な誤差を導入する。粗視化比較の解釈には、近似の構造 (本日では単一ジャンプ) を明示すべきである。

## 7. 反省 (Day 9 以降に適用)

- ジャンプ系では、diffusion の推定に混合尤度か大増分スクリーニングのいずれかのジャンプ処理が必須であること。
  ジャンプを無視した推定器は ĝ を 0.35 から 0.62 へ膨らませ、連続部分のパラメータ推定そのものを歪める
  (拡散のみ teacher の g NRMSE 0.782、二段階スクリーニング推定は 0.355)。
- λ の同定は drift・g より弱いこと (teacher の λ NRMSE 0.266 に対し drift 0.179、g 0.015)。
  λ の field 判定には drift・g と同じしきい値を機械的に適用せず、ジャンプ情報量 (λΔt) を併記すること。
- 構造制約ライブラリの勝敗は teacher の構造充足度の診断であること。構造制約を課す場合は teacher の構造充足度
  (本日でいえば teacher の f(0) = −0.072) を事前に測ること。標準化座標での切片なしは train 平均での固定であって
  原点での固定ではないため、原点固定は平均 0 の標準化で実装し、展開後の切片が 0 であることをテストすること。
- 率の水準が小さい指標では、絶対差ではなく相対比を主条項とすること。
  観測率 0.01135 に対して絶対差 0.01 のしきい値は大きすぎ、拡散のみの miss 0.00979 が僅差で未達となった
  (相対比では拡散のみは観測率の約 1/7 であり、分離は明確)。
- 粗視化比較では、近似の構造 (本日では単一ジャンプ近似) を明示すること。
  ジャンプ混合尤度のもとでは粗視化は SNR のトレードオフだけでなく単一ジャンプ近似の破綻を導入し、
  diffusion の悪化 (g 0.021 → 0.142) が Day 7 とは異なる方向に出る。
- VIF の計算では定数列を除外すること。定数列の VIF は回帰の切片によって完全に説明されるため 10⁹ という偽の値になり、
  ゲートの判断を誤らせる (次数 3 ライブラリの真の VIF は最大 3.72)。
