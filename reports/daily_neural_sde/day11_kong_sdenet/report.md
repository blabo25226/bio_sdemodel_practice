## 1. 論文要約

### 1.1 問題と提案

深層ネットの認識的不確実性を、パラメータ事後分布ではなく力学系の拡散で表す。
隠れ状態の変換を次のニューラル SDE とみなす (論文式 (3) が一般形、式 (4) と式 (7) が実装)。

$$
dX_t = f(X_t, t;\theta_f)\,dt + g(X_0;\theta_g)\,dW_t.
$$

$f$ は drift net で、終端状態のタスク損失 (分類なら交差エントロピー) を下げる。
$g$ は diffusion net で、訓練分布では小さく、ガウス雑音を加えた擬似 OOD では大きくなるよう
$\mathbb{E}[g(x_{\mathrm{ID}})] - \mathbb{E}[g(x_{\mathrm{OOD}})]$ を最小化する。
出力は $\sigma_{\max}\mathrm{sigmoid}(\mathrm{net}(x_0))$ にキャップし、Lipschitz な活性化で
解の存在と一意性を保証する (Theorem 1)。学習は Euler–Maruyama、訓練中は標本あたり 1 本の経路、
drift と diffusion を交互に更新する (Algorithm 1)。
主張は、MNIST / SVHN などの OOD 検出・誤分類検出・敵対例検出・能動学習で、
アンサンブルより少ないパラメータで競争的な不確実性推定が得られたことである。
本日扱うのはこの SDE の drift net と diffusion net であり、画像ベンチマークの AUROC ではない。

### 1.2 本日の切り取りと選定理由

前日までとの重なり回避: Day 1 は勾配推定、Day 2 は GAN、Day 3 は変分潜在モデル、
Day 4 は市場較正、Day 5 は $W_2$、Day 6 は遅延、Day 7 は幾何安定性、Day 8 はジャンプ、
Day 9 は平均場、Day 10 はスコアによる逆時間生成であった。

この 2 次元座標は観測された特徴そのものであり、遺伝子規制や潜在遺伝子空間の式ではない。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと teacher

状態は観測座標 $(x, y)\in\mathbb{R}^2$。クラス 0 のモードは $(-1.5,-1.5)$ と $(1.5,1.5)$、
クラス 1 のモードは $(-1.5,1.5)$ と $(1.5,-1.5)$、各モードは標準偏差 0.30 の等方ガウスである。
4 モードを等確率で、train 1200 / validation 400 / test 400。分割単位は初期条件 $x_0$ (1 本の軌道) で、
軌道の途中状態が分割をまたぐことはない。$x_0$ への線形分類器の test 精度は 0.500 であり、
XOR は線形分離できない。OOD は論文と同じく加法ガウス雑音 (分散 4) である。

teacher は次のとおり。実行時に測った shape は $x_0:(8,2)$、$t:(8)$、$f:(8,2)$、$g:(8,)$ である。

- drift: 入力 $(x, y, t)$、Linear $3\to 64$、tanh、Linear $64\to 64$、tanh、Linear $64\to 2$。
- diffusion: 入力 $(x_0, y_0)$ のみ、同じ幅の MLP のあと $\sigma_{\max}\mathrm{sigmoid}$、$\sigma_{\max}=1$。
  スカラー $g(X_0)$ を経路のあいだ固定し、2 次元 Wiener 増分に掛ける。現在状態では再評価しない。
- 読み出し: 線形ヘッド $h_2:\mathbb{R}^2\to\mathbb{R}^2$。SDE の一部ではなく、タスク損失と精度のための読み出しである。

訓練は $T=1$、Euler–Maruyama 6 步 ($\Delta t=1/6$)、Adam (drift とヘッド $10^{-3}$、diffusion $10^{-2}$)、
2500 step、バッチ 256、経路は 1 本。タスク損失は $g$ を stop-gradient した経路の交差エントロピー、
拡散損失は $\mathrm{mean}\,g(\mathrm{ID})-\mathrm{mean}\,g(\mathrm{OOD})$ で経路を通さない。
訓練末のバッチではタスク損失 $1.0\times 10^{-4}$、$g$ の平均は ID 0.027、OOD 0.870 であった。
probe した $g$ は $(4.8\times 10^{-10},\, 0.999)$ に入り、シグモイドの範囲内であった。

### 2.2 逸脱の明示

1. **画像から 2 次元 XOR への置換**: MNIST / SVHN / YearPredictionMSD は扱わない。
   状態を観測座標にしたのは、論文の downsampling $h_1$ が隠す隠れ状態は識別不能だからである。
   XOR にしたのは、この座標で線形ヘッドが $x_0$ だけでは解けず、drift が実際に非線形な写像を担うようにするためである。
   本日の数値は論文の AUROC について何も主張しない。
2. **$h_1$ を置かない**: 上と同じ理由である。
3. **ReLU residual と SGD を tanh MLP と Adam に置換**: Theorem 1 が要求する Lipschitz 性は tanh で保たれる。
   画像用 residual block は 2 次元の切り取りでは対応物がない。
4. **$\sigma_{\max}$ は訓練値 1 のまま**: 補遺は検出指標のためにテスト時 $\sigma_{\max}=50$ へ膨らませる。
   蒸留する対象は訓練された拡散ネットであり、テスト時の定数倍は SDE に含めない。
   50 倍すれば分散が 2500 倍になり、本日の失敗半径では別の数値問題になる。

真の SDE は置かない。以降の指標はすべて対 teacher である。

## 3. 仮説 (config に事前凍結)

- **H1** (drift): symbolic drift の test NRMSE vs teacher $\le 0.30$。
- **H2** (diffusion): ID test の $g$ NRMSE $\le 0.30$、OOD test の $g$ NRMSE $\le 0.50$、
  ID の $\Sigma=g^2$ NRMSE $\le 0.40$。
- **H2c** (値域): test の拡散 query (ID と OOD) のうち symbolic $g\notin(0,\sigma_{\max}]$ の割合 $\le 0.05$。
- **H3** (共線性): 係数回復の仮説は置かない。次数 3 の VIF 最大が 10 を超えた場は、係数読みを不定とする。
- **H4** (シミュレーション): ID test の 400 本、$T=1$、$\Delta t=0.05$、対の Wiener 増分。
  symbolic の失敗率 $\le 0.05$ かつ teacher との差 $\le 0.02$、$\|X\|>8$ の逸脱率の差 $\le 0.10$、
  終端の paired RMSE $\le 1.5$、保持質量での分類精度は teacher $\ge 0.85$、symbolic $\ge 0.75$。
  失敗した軌道は不正解に数える。
- **H5** (論文の軸): 平均 $g$ は teacher が ID $\le 0.40$、OOD $\ge 0.70$、差 $\ge 0.30$、
  symbolic が ID $\le 0.50$、OOD $\ge 0.50$、差 $\ge 0.20$。
  終端分散の OOD/ID 比は teacher $\ge 2$、symbolic $\ge 1.5$。
  失敗率 $>0.05$ のときは分散条項をゲートする。
  $g=0$ のベースライン (teacher drift のまま) の OOD 終端分散 $\le 0.02$。
- **H6** (離散化): 訓練刻み $\Delta t=1/6$ と細刻み $\Delta t=1/30$ の paired 終端 RMSE $\ge 0.05$。
  粗増分は細増分 5 本の和。失敗率 $>0.05$ なら不定。

## 4. 方法

teacher への直接 query。変換は train query のみ。drift の次数としきい値は validation の pooled NRMSE 最小、
diffusion は validation の ID NRMSE と OOD NRMSE の平均が最小になる組を選ぶ
(OOD の大きいスケールに選択が支配されないようにするため)。候補は次数 $\{1,2,3\}$、
しきい値 $\{0.02, 0.05, 0.1, 0.2, 0.35\}$、ridge $10^{-4}$。test はこの選択のあと 1 回。

drift の query は各 $x_0$ から訓練刻みで 1 本積分し、各步の開始状態 $(x, y, t)$ で $f$ を評価する
(train 7200、validation 2400、test 2400、非有限の脱落は 0)。
$t$ の範囲は $[0, 5/6]$ である。diffusion の query は分割ごとの $x_0$ と、その 1 回の分散 4 摂動である。

選択結果: drift は次数 3・しきい値 0.02 (活性 38、次数 3 の 2 出力で 40 係数中)、
diffusion は次数 3・しきい値 0.02 (活性 7、10 項中)。どちらもほぼ密である。
検証 NRMSE は drift 0.224、diffusion は ID 1.79 / OOD 0.519 (平均 1.15) であった。

シミュレーションは失敗をラッチし、`non_finite` と `outside_radius` を分けて数える。
拡散関数が状態の view を返しても経路中に値が変わらないよう、$g(X_0)$ は評価時に copy する
(この取り違えはユニットテストで検出した)。

### 5.2 拡散の失敗はライブラリの天井である

H2 は ID で 1.858、OOD で 0.537 と失敗した。同じ query への次数 3 OLS 天井は
ID 1.858、OOD 0.537 で、しきい値 0.02 の SINDy と小数 4 桁まで一致する。
活性項も 10 項中 7 項で、しきい値が原因ではない。
ID の残差 RMS 0.370 は teacher 自身の RMS 0.199 より大きい。
つまりこの多項式は、ID の上では零関数より悪い。NRMSE が 1 を超えるのは分母が小さいからだけではなく、
残差が信号より大きいからである。

$g$ の VIF 最大は 2.47 でゲート内なので、係数の形は読んでよい。推定式は原点付近が底の浅い放物面である。
保存した場を点で評価すると (選択には未使用):

| 点 | teacher $g$ | symbolic $g$ |
|---|---|---|
| $(0,0)$ (環の内側) | 1.000 | 0.241 |
| $(1.5,1.5)$ (モード) | $\sim 0$ | 0.375 |
| $(4,0)$ (遠方) | 1.000 | 0.664 |
| $(-4,4)$ (遠方) | 1.000 | 1.040 |

teacher はモード上で飽和して 0、環の内側と遠方で飽和して 1 である。
次数 3 の冪乗は「環の上だけ小さい」を表せず、最良近似が上に開いた放物面になる。
OOD 平均が ID 平均より大きい (H5 の僅差 pass) のは、遠方の点が放物面の裾で持ち上がるからで、
環の回復ではない。原点では teacher が 1 のところ symbolic は 0.241 である。
H5 の平均ギャップを field の成功と読んではならない。

終端分散も同じ圧縮を示す。失敗率は 0 なので生存者バイアスではない。
teacher の OOD/ID 比は 15.71 (分散 3.973 / 0.253)、symbolic は 1.792 (1.255 / 0.700)。
比の条項は両方 pass だが、絶対水準は ID で teacher の 2.8 倍、OOD で teacher の 0.32 倍である。
$g=0$ のベースラインは分散が数値的に 0 で、ギャップの担い手は拡散項だけである。

### 5.3 drift は軌道上では近似でき、係数は読めない

H1 は 0.221 (残差 RMS 1.422) で pass し、OLS 天井 0.221 と一致する。
軌道上の残差は次数 3 の表現力の範囲内である。一方 VIF は 56.5 でゲートを超える。
$t$ の係数 ($-20.74\,t + 15.13\,t^2 + 14.85\,t^3$ など) は打ち消しであって、時間の機構として読まない。
活性 38/40 で、疎な式でもない。

格子 (選択外) では軌道上の成功が外へ出ない。drift の symbolic vs teacher は
$t=0$ で NRMSE 1.275 (RMS 7.02)、$t=0.5$ で 0.664 (RMS 4.08)、$t=1$ で 1.748 (RMS 11.58)。
query の $t$ は $5/6$ までなので、$t=1$ は時刻の外挿でもある。
$t=0$ は時刻の内挿だが空間はデータ環の外を含む。NRMSE $>1$ には絶対 RMS を併記した。
遠方スライス (最近モードから距離 $>1.2$、289 点中 205 点) の $t=0$ RMS は 8.22 である。

### 5.5 シミュレーションと離散化

ID の 400 本は teacher も symbolic も失敗率 0 (非有限 0、半径外 0) である。
分類精度は 1.000 と 0.9975 で、線形ヘッドが $x_0$ では 0.500 だったことと対比すると、
分離を作っているのは drift である。ID では $|f|\Delta t$ の平均 0.374 に対し $g\sqrt{\Delta t}$ の平均は 0.0103
(平均の比 36.3) なので、1 步の誤差は拡散の誤りをほとんど見ない。
OOD では 0.375 対 0.198 (比 1.90) で、両方が効く。one-step MSE を field の代わりに使わなかった理由はここにある。

終端状態の RMS は teacher 6.47、symbolic 6.53 で、$\|X\|>8$ の逸脱が 0.54 と 0.62 なのは
数値破綻ではなく、XOR を分離する drift が半径 8 の球を日常的に出るからである。
差 0.080 は条項を満たすが、絶対水準は高い。失敗半径 25 には届いていない。

paired 終端 RMSE 1.386 は条項 1.5 の内側だが、H6 の離散化差 1.239 と同程度である。
訓練刻み $\Delta t=1/6$ は、同じ teacher を $\Delta t=1/30$ で積分した終端からすでに 1.24 ずれる。
symbolic と teacher の 1.39 を、蒸留誤差だけとは切り分けない。

## 6. 考察

蒸留の対象は teacher の場であり、真の SDE の発見でも生物学的機構でもない。
閉じた形の真値は最初から置いていない。

軌道上の drift は次数 3 の冪乗で NRMSE 0.22 まで近似できた。これは teacher が XOR を
比較的滑らかな時間依存ベクトル場で解いた、という範囲の主張である。
係数は VIF 56.5 の打ち消しの中にあり、格子の RMS は 4 から 12 なので、式を軌道の外へ持ち出さない。

拡散は論文の本体 (認識的不確実性) であり、ここは失敗である。
シグモイドでキャップされた「モード上で 0、それ以外で 1」は、次数 3 までの冪乗の外にある。
天井が SINDy と一致するので、しきい値を下げても回復しない。
平均 $g$ のギャップと終端分散比は緩いしきい値を僅差で通過したが、
点ごとの場も、ID と OOD の分散の絶対水準も、teacher を保っていない。
タスク精度が残ったのは、ID では drift が拡散より 30 倍以上大きいからで、
不確実性の蒸留が成功したからではない。
