## 1. 論文要約

### 1.1 問題と提案

時系列はしばしば自己相関 (メモリ) を持つが、SDE-net (Kong et al. 2020) をはじめとする neural SDE は
現在値のみに依存し、過去の状態を陽に使わない。論文は、複数の遅延を持つ確率遅延微分方程式 (SDDE) を
モデルの骨格とする Delay-SDE-net を提案する。drift ネットは [t, 過去 p ステップの状態] を入力とし、
diffusion は aleatoric ネットと epistemic ネットの 2 本に分けられる (後者は ID/OOD 分類で訓練)。
3 段階の訓練法が特徴である: (1) drift ネットを one-step 予測 MSE で訓練し、(2) その残差から
aleatoric diffusion ネットを訓練し (残差二乗と g²Δt のマッチング)、(3) epistemic ネットを ID/OOD 分類で別途訓練する。
理論面では 2 層ネットの Barron 空間における誤差 bound と、Milstein 離散化の収束率を導出している。
実証面では、シミュレーション研究 (§5.1) で Delay-SDE-net が SDE-net と VAR を上回ること、
実世界ケース (§5.2、成層圏の風・気温) でも同様の優位を示すことを報告している。

### 1.2 モデルと実験 (§3, §5.1)

SDDE は d = 2、遅延 p = 4 (u = (−4, −3, −2, −1)) で、drift は 2 ユニットの tanh ネット、

$$
f^j(t, x) = \sum_{i=1}^{2} a_i^j \tanh\bigl((w_i^j)^\top [t, \Pi(X_t)]\bigr), \qquad a_i^j = 5,
$$

diffusion はシグモイド型、

$$
g^j(t, x) = a^j \sigma\bigl((w^j)^\top [t, \Pi(\eta(0))] + b^j\bigr), \qquad a^1 = 4,\ a^2 = 1/8,\ b^1 = 0,\ b^2 = 1,
$$

であり、重みは論文の Eq. (24) で与えられる。ここで Π(X_t) は 4 時点のラグ状態を並べた 8 次元ベクトルである。
重要な構造上の特徴が 2 つある: (a) diffusion は Eq. (8) により**初期履歴にのみ依存し、現在値には依存しない**
(したがって各軌道の diffusion は t の緩やかな関数に過ぎない); (b) drift の t 係数は Eq. (24) の 4 行すべてで 0 であり、
**drift は実質的に時間同次**である。比較研究 (§5.1.3) では Δt = 1、365 日、110 軌道のデータで
Delay-SDE-net、SDE-net、VAR を比較し、drift 予測 (X¹) と aleatoric 分散の RMSE で Delay が最良と報告している
(論文 Table 2: t+1 の drift RMSE は VAR 0.70、SDE-net 1.31、Delay 0.66)。

### 1.3 選定理由 (多様性の観点)

前日までとの重なり回避: Day 1 は勾配ベース学習 (Li)、Day 2 は GAN (Kidger)、Day 3 は変分潜在モデル (Tzen)、
Day 4 は市場較正 (Gierjatowicz)、Day 5 は W₂ 分布一致 (Zhang) であった。本日は **遅延 (メモリ) を持つ SDDE**
という未使用の手法系、**時系列予測・気象系ドメイン**という未使用のドメイン、
**tanh 型 drift + 初期履歴のみに依存する diffusion**という未使用の field 構造を選んだ。
2 次元という次元は Day 3–5 と重なるが、状態そのものではなく「現在値 + 8 ラグ」の 10 次元拡張状態が
分析の主対象であり、次元の意味が異なる。データ入手可能性: 論文は軌道データセットを公開していないが、
§5.1.1 の SDDE は Eq. (23)–(24) で完全に特定されており、合成データとして再生成できる
(憲章の選定条件 (a) は「生成過程が特定できる」ことで満たす)。

### 2.1 データ

状態統計 (train query 状態): X¹ の平均 −1.344、標準偏差 7.767、範囲 [−40.7, 43.3]。
X² の平均 1.241、標準偏差 1.615、範囲 [−9.8, 11.2]。
真値 diffusion は g¹ ≈ 2.00 (t の緩やかな減少のみ)、g² ≈ 0.0916 (X²(−1) のみで決まる) であり、
ほぼ定数である。真値 drift の RMS は全体で 1.470、X¹ 成分で 1.979 である。

### 2.2 逸脱の明示

1. **horizon と観測刻みの切り取り**: 論文の比較研究は Δt = 1、T = 365 だが、本日は T = 8、Δt_obs = 0.05 に切った。
   Δt = 1、T = 365 の設定では tanh drift が飽和して状態が 1 時間単位あたり約 9 の割合で線形に発散し
   (プロトタイプで X¹ が ±1100 に到達)、学習可能な範囲を逸脱するためである。論文の Δt = 1 レジームは
   再訓練した診断ペアとしてのみ報告し (§5.7)、主結果の主張には使わない。
2. **連続時間化**: 論文の離散スキーム (Eq. (23)、Δt = 1) ではなく、Eq. (8) が定義する連続時間 SDDE を
   dt_fine = 0.01 でシミュレーションし、0.05 ごとに観測した。遅延が整数であるため、すべてのラグ値は観測格子上にあり、
   粗視化 (Δt = 0.5、Δt = 1) でもラグは観測されたままである。
3. **epistemic ネットの切断**: 論文の 3 段階訓練のうち epistemic diffusion ネット (ID/OOD 分類) は切った。
   OOD 分類は field 蒸留の問いではなく、epistemic 不確実性については本日は何も主張しない。
4. **活性化の steepness の宣言**: 論文は drift 活性化を tanh(αz)、diffusion 活性化を sigmoid(λz) と書くが、
   α、λ の数値を本文・付録のどこにも与えていない。そのため α = λ = 1 (通常の tanh / sigmoid) と宣言して再構成した。
   仮に著者のコードが別の値を用いていたとしても、field の steepness が変わるだけで、遅延 vs Markovian や蒸留の問いは変わらない。
5. **ラグ順序の宣言**: 論文は Π をラグ点上の連結と定義するが、次元-major かラグ-major かを明示しない。
   Eq. (24) の diffusion 重みパターン (g¹ は t のみ、g² は最後の成分のみに依存) がきれいに読めるのは
   dim-major 順序 [X¹(t−4..t−1), X²(t−4..t−1)] の場合であるため、その順序を宣言して採用した。
6. **成層圏ケース・VAR・収束率研究の不採用**: §5.2 の実世界ケース、VAR ベンチマーク、§5.1.2 の収束率研究、
   N-step-ahead 訓練は本日は扱わない。

## 3. 仮説 (実行前に config へ凍結)

- **H1 (drift 蒸留)**: symbolic drift の test NRMSE (対 teacher) ≤ 0.30。
- **H2 (diffusion 蒸留)**: symbolic diffusion (g¹, g² の joint) の test NRMSE (対 teacher) ≤ 0.30、かつ
  symbolic の implied Σ (diag(g²)) の test NRMSE (対 teacher の Σ) ≤ 0.30。
- **H3 (真値回復)**: symbolic drift の test NRMSE (対真値) ≤ 0.60。係数条項は含めない
  (真値 drift は tanh の和であり、多項式係数回復は意味を持たない。Day 3 の教訓)。
  oracle (同じ SINDy 手順を真値 field に fit した天井) を併記する。
- **H4 (シミュレーション)**: symbolic SDDE の失敗率 ≤ 0.05 かつ teacher との差 ≤ 0.02、
  paired RMSE (対 teacher) の中央値 ≤ 2.0、かつドメイン逸脱率 (半径 > 50 を経験する割合) の symbolic − teacher ≤ 0.10
  (Day 4 の反省により事前に含めたドメイン条項)。失敗は non-finite または半径 > 100。
- **H5 (論文軸: Delay vs SDE-net teachers)**: test query 状態での paired 2 乗誤差比較で、
  (a) X¹ drift field: Markovian teacher の誤差二乗平均 − delay teacher の誤差二乗平均 > 0 かつ paired SE の 2 倍超、
  (b) X¹ aleatoric 分散 (ĝ² vs 真値 g²): 同じ paired 規則。両条項が成ること。
  固定の絶対マージンは置かない。Δt_obs = 0.05 では現在値がラグと最大 0.975 相関するため、
  遅延の優位は論文の Δt = 1 レジームより小さいと予想され、paired-SE 規則が正直な判定だからである。
  Δt = 1 での再訓練ペアは診断としてのみ報告する。
- **H6 (離散化バイアス診断、Day 1 の反省)**: 遷移数を揃えた制御比較で、
  (a) EM (Δt = 0.5) の drift field NRMSE が EM (Δt = 0.05、同一遷移数) より 0.03 以上悪化すること、
  (b) 悪化幅が飽和レジーム (tanh 引数の最大絶対値 > 0.7) で近線形レジーム (同 < 0.3) より 0.02 以上大きいこと。
- **H7 (論文軸の代理: one-step 予測)**: test 遷移での one-step-ahead X¹ MSE について
  |MSE_symbolic − MSE_teacher| ≤ 0.005。paired 標準誤差を併記し、paired SE ≥ 0.0025 の場合は
  点推定が合格しても「統計的に確定しない」とする (Day 4 の反省)。

## 4. 方法 (main と同じ流儀)

- teacher への直接 query で function distillation。query 点は各 split の観測状態
  (trajectory-disjoint)。変換 (mean/scale) と RMS 正規化は train query のみから。
- teacher: delay two-stage (蒸留対象、事前に固定)、Markovian two-stage (論文の SDE-net 比較対象)、
  EM (Δt = 0.05、主)、EM coarse (Δt = 0.5)、EM fine-sub (Δt = 0.05、coarse と同一遷移数)。
  いずれも MLP [32, 32] tanh、Adam。delay drift 入力 [t, ラグ 8]、delay diffusion 入力 [t, 初期ラグ 8]、
  Markovian 入力は [t, 現在値]。diffusion は対角 (成分ごとに独立な Brown 運動、論文 §3.1)。
  two-stage は drift を one-step MSE、diffusion を残差マッチング (||g²Δt − e²||) で訓練 (論文 §3.2)。
- 候補: drift は次数 {1, 2, 3} (10 変数ライブラリ、次数 3 は 286 項)、diffusion は次数 {0, 1, 2}
  ((t, 初期ラグ 8) の 55 項ライブラリ)、STLSQ しきい値 {0.02, 0.05, 0.1, 0.2, 0.35}。
  field ごとに validation NRMSE で選択し、test は確定後に 1 回だけ評価。
- oracle 診断: 同じ SINDy 手順を真値 field に fit (天井の診断)。
- 共線性診断: fit の前に train query 状態で corr と VIF を計算。
- shuffled-lag 診断 (Day 2 の反省により標準手順): test query のラグブロックを軌道間で置換し、
  現在値と t を保持した状態で teacher / symbolic / 真値を比較する。
- シミュレーション検証: test 軌道の履歴セグメントから、teacher / symbolic / 真値の 3 モデルを
  同一 Brownian 増分 (paired) で Euler–Maruyama (dt = 0.05、t ∈ [0, 8]) によりシミュレーション。
  失敗は non-finite / 半径 > 100 で分類し、質量を保持する。半径 > 50 の経験は失敗とは別に「ドメイン逸脱」として数える。
- 分布一致型の teacher は本日は使わないため、分布損失と field の混同は生じない (§0.5)。
  推定器の順序は field NRMSE で判断し、遷移 NLL は診断値としてのみ扱う。

## 5. 結果

### 5.1 推定器の比較 — teacher の対真値 field 誤差 (test query 状態、30,912 点)

| teacher | drift NRMSE vs 真値 (RMS 誤差) | X¹ drift NRMSE (RMS) | g NRMSE vs 真値 | Σ NRMSE vs 真値 |
|---|---|---|---|---|
| delay two-stage (蒸留対象) | 0.0812 (0.1193) | 0.0654 (0.1295) | 0.0233 | 0.0365 |
| markovian two-stage | 0.2347 (0.3448) | 0.2003 (0.3964) | 0.0186 | 0.0254 |
| EM (Δt = 0.05) | 0.0622 (0.0915) | 0.0642 (0.1271) | 0.0107 | 0.0211 |
| EM coarse (Δt = 0.5) | 0.1165 (0.1711) | 0.1165 (0.2306) | 0.0433 | 0.0677 |
| EM fine-sub (Δt = 0.05、同一遷移数) | 0.0981 (0.1442) | 0.1008 (0.1995) | 0.0258 | 0.0505 |

読み取り:

- **遅延 teacher は drift で Markovian を大きく上回る** (0.081 vs 0.235)。現在値だけではラグの非線形結合を
  再現できないことが、field 水準ではっきり出る。ただし Markovian の 0.235 は「何も分かっていない」のではなく、
  現在値がラグと 0.975 相関するための部分的な代理である (§5.7)。
- **EM が drift・diffusion ともに最良** (drift 0.062、g 0.011、Σ 0.021)。two-stage の drift (0.081) との差は
  MSE 訓練と尤度訓練の差であり、drift の弱同定というより推定効率の差と読むのが妥当である。
  Σ の同点域 0.01 で見ると、EM vs delay の差 0.0154 は同点域を超える (EM が真に良い) が、
  EM vs Markovian の差 0.0043 は同点域内 (tie) である。
- **diffusion では Markovian が delay を上回る** (g 0.0186 vs 0.0233、Σ 0.0254 vs 0.0365)。
  これが H5 の分散条項を否にした直接の原因であり、メカニズムは §5.7 で論じる。
- EM の全データ版 (0.062) と fine-sub 版 (0.098) の差は、遷移数 102,400 vs 10,240 のサンプルサイズ効果である。
  粗視化比較で遷移数を揃えなかった場合、この差 (0.036) が離散化バイアスと混同される (H6 の制御の意義)。

読み取り: 蒸留そのものは on-manifold では成功している (対 teacher 0.083 / 0.015)。
対真値 0.106 は oracle の天井 0.076 に近く、蒸留の追加誤差は約 0.03 に過ぎない。

teacher の差が蒸留後も保存される。
diffusion の oracle が 0.0002 とほぼ厳密なのは、真値 diffusion が (t, 初期ラグ) のほぼ定数関数であり、
次数 2 多項式で十分に表せるためである。

(Day 5 の反省どおり絶対誤差を併記した)。
実務的な含意は明確である: 遅延系の symbolic モデルを、観測されたラグの組み合わせ以外
(例えば外挿された履歴や人工的な初期履歴) に適用してはならない。次数選択は on-manifold の validation のみで行われるため、
この失敗は選択時には見えない。lag 系では shuffled-lag 診断を次数選択の報告に必須とすべきである (§7)。

### 5.7 論文軸の詳細 — H5: Delay vs SDE-net teachers

| 比較 (test query) | Markovian RMSE | Delay RMSE | paired 差 (平均 ± SE) | 判定 |
|---|---|---|---|---|
| X¹ drift field | 0.3964 | 0.1295 | +0.14037 ± 0.00135 | 成 |
| X¹ aleatoric 分散 (ĝ² vs 真値 g²) | 0.1014 | 0.1457 | −0.01096 ± 0.00027 | 否 |
| X¹ drift field (Δt = 1 診断ペア) | 0.5104 | 0.3237 | +0.15569 ± 0.00191 | (診断) |

H5 は**否**である。drift 条項は圧倒的に成る (paired 差は SE の 100 倍超) が、分散条項が符号を逆にして否になる。
分散条項の失敗メカニズムとして最も整合的な説明は次のとおりである。
真値の X¹ 分散 g¹² ≈ 4.0 はほぼ定数であり、delay diffusion ネットの入力 (t, 初期ラグ 8) は軌道ごとに定数である。
残差マッチングのターゲット e² は 1 自由度のカイ二乗型で極めてノイジーであり、
軌道ごとに定数の入力を持つネットは各軌道の残差平均 (ノイズ) を部分的に拾ってしまい、
真値にない軌道間変動を ĝ² に出力する。Markovian ネットの入力 (t, 現在値) はステップごとに変動するため
軌道平均を記憶しにくく、より定数に近い (真値に近い) 出力に縮む。
この説明は、delay の分散 RMSE が train (0.126) でも test (0.146) でも Markovian (train 0.092、test 0.101) より
悪いことと整合的である — すなわち汎化ギャップではなく、入力構造とノイジーな残差ターゲットの組み合わせによるものである。
ただしこれは 1 回の実行からの解釈であり、独立した検証 (例えば diffusion 入力を (t) のみに絞った対照実験) は行っていない。
そのため H5 の分散条項の否は「論文の主張への反証」ではなく、「本日の切り取りのもとでの所見」として報告する
(論文は Δt = 1、365 日、110 軌道の設定で、かつ epistemic ネット込みの完全版を用いている)。
なお Δt = 1 診断ペアでも drift の遅延優位は維持される (0.324 vs 0.510) ため、drift に関する論文の方向性は
本日の 2 つのレジームでともに支持される。

### 5.8 離散化バイアス診断の詳細 — H6: EM の粗視化

| 指標 | EM fine-sub (Δt = 0.05) | EM coarse (Δt = 0.5) | 悪化幅 |
|---|---|---|---|
| drift NRMSE (全体) | 0.0981 | 0.1165 | +0.0183 |
| drift NRMSE (近線形レジーム、n = 19,614) | 0.2636 | 0.2404 | −0.0232 |
| drift NRMSE (飽和レジーム、n = 4,926) | 0.0652 | 0.0678 | +0.0026 |
| Σ NRMSE | 0.0505 | 0.0677 | +0.0172 |

H6 は**否**である。(a) の悪化幅 0.0183 はしきい値 0.03 に届かず、(b) のレジーム間ギャップ 0.0258 は
しきい値 0.02 を満たすが、その内訳は予想と逆である: 飽和レジームでの悪化はわずか +0.0026 に過ぎず、
ギャップは近線形レジームでの**改善** (−0.0232) によって生じている。
近線形レジームで粗視化が改善する理由として最も整合的なのは per-transition の SNR である:
Δt = 0.5 では drift 信号が 10 倍 (f·Δt) になる一方ノイズの標準偏差は √10 倍にしかならないため、
近線形 (凍結バイアスが小さい) 領域では粗視化の方が推定しやすい。
飽和レジームでは凍結バイアスが SNR の利益を相殺するが、本日のしきい値では悪化は +0.0026 と小さい。
またレジーム別 NRMSE の水準差 (近線形 0.26 vs 飽和 0.065) は分母効果を含む:
真値 drift の RMS は近線形レジームで 0.513、飽和レジームで 3.002、全体で 1.470 であり、
近線形レジームの NRMSE は分母が小さいために inflated である (Day 4・5 の反省)。
結論として、Day 1 型の「凍結バイアス」は一様な悪化として現れず、レジームと SNR のトレードオフとして現れる。
凍結バイアスの仮説は今後レジーム別に置くべきであり、遷移数を揃えない粗視化比較は
サンプルサイズ効果 (EM 全データ 0.062 vs fine-sub 0.098) に埋もれるため、遷移数マッチングは必須である。

## 6. 考察

1. **遅延は drift の同定には効くが、diffusion の推定には別の罠がある**。本日の H5 は半分だけ成った。
   drift については遅延入力が決定的に優位であり (0.129 vs 0.396)、論文の主張の方向性は Δt = 0.05 でも Δt = 1 でも支持される。
   しかし diffusion については、論文の構造 (初期履歴のみに依存する diffusion) と残差マッチングの組み合わせが、
   ほぼ定数の真値に対して余計な軌道間変動を生む。これは論文の誤りではなく、推定法と入力設計の相互作用である。
   diffusion の入力設計は drift とは別に検証すべきであり、特に「入力が軌道ごとに定数」の場合は
   残差平均の記憶という失敗モードを疑うべきである。
2. **蒸留の成功と off-manifold の崩壊は両立する**。本日は teacher が shuffled-lag でも健全 (0.085) であるにもかかわらず、
   symbolic は 4.34 まで崩壊した。Day 5 では teacher の野生さが原因であったが、本日は teacher は無実であり、
   原因は多項式ライブラリと強い共線性 (VIF 102.5) である。on-manifold の NRMSE だけを見ると「成功した蒸留」に見えるが、
   その式を観測されたラグの組み合わせの外で使うことはできない。遅延系では、ラグの同時分布からの乖離に対する診断が
   次数選択の報告に必須である。
3. **離散化バイアスは SNR とのトレードオフである**。Day 1 の教訓は「粗い刻みはバイアスを生む」であったが、
   本日はそれが一様ではないことが分かった。近線形レジームでは粗視化がむしろ推定を改善しうる
   (per-transition SNR の向上)。凍結バイアスを論じる際は、レジームとサンプルサイズ (遷移数) を同時に制御しなければ、
   バイアスと SNR とサンプルサイズの 3 つが混同される。本日の遷移数マッチングは、その混同を避けるための最小限の設計であった。
4. **蒸留の成功と論文の主張は別の軸**である (Day 2–5 と同じ教訓の再確認)。
   本日の H5・H6 の否は、Eggen & Midtfjord の主張への反証ではない。論文は Δt = 1、365 日、完全な 3 段階訓練
   (epistemic ネット込み) を用いており、本日はその両方を切り取った近似版をテストしたに過ぎない。
   論文が主張していない軸での「失敗」を数えない、という姿勢を維持する。
5. **項数の多い symbolic は読むものではない**。drift の 375 項は TeX としては完全であるが、
   人間が読んで理解するものではない。線形部分と項数を要約し、完全展開を別ファイルに置く運用が、
   このシリーズの規模では現実的である。TeX の完全性と可読性は別の要件であり、両方を満たすには要約 + 完全展開の 2 層が必要である。

## 7. 反省 (Day 7 以降に適用)

- 遅延系では on-manifold の蒸留成功と shuffled-lag での崩壊が両立しうること。
  teacher 自体は shuffled-lag でも真値に近い (0.085) のに次数 3 多項式は 4.34 まで崩壊する:
  多項式の off-manifold 失敗は teacher の野生さではなくライブラリの共線性 (VIF 102.5) と多様体の薄さによる。
  次数選択を validation のみで行う限りこの失敗は選択時に見えないため、lag 系では shuffled-lag 診断を次数選択の報告に必須とすること。
- 残差マッチングによる diffusion 推定では、入力が trajectory-定数 (初期履歴) の場合、trajectory ごとの残差平均を拾って
  真値にない変動を出力しうること。真値 diffusion がほぼ定数の場合、入力を絞った (定数に近い) モデルの方が勝つことがある。
  diffusion の入力設計は drift と別に検証すること。
- 離散化バイアスは一様ではないこと。Δt 粗視化は近線形レジームでは per-transition SNR の向上でむしろ改善しうる (−0.023) 一方、
  飽和レジームでの悪化は小さい (+0.003)。凍結バイアスの仮説はレジーム別に置き、遷移数マッチングなしの粗視化比較は
  サンプルサイズ効果 (EM 全データ 0.062 vs 10k 遷移 0.098) に埋もれるため、必ず遷移数を揃えること。
- 項数の多い symbolic (375 項) は TeX としては完全でも読むものではないこと。項数と線形部分を要約し、
  完全展開は別ファイルに置く運用を維持すること。

## 8. 限界

- 本日の teacher は論文の Delay-SDE-net ではない (§2.2 の逸脱)。
  epistemic ネット、Δt = 1・T = 365 の比較設定、成層圏ケース、VAR ベンチマーク、収束率研究は扱っていない。
  論文の Table 2 の数値 (drift RMSE 0.66 など) についての主張は、本日の結果では何も言えない。
  特に、H5 の分散条項の否は、論文の完全版に対する反証ではなく、切り取りのもとでの所見である。
- 活性化 steepness α = λ = 1 とラグ順序 dim-major は宣言した再構成上の選択であり、著者のコードと異なる可能性がある。
- シミュレーション horizon は t ∈ [0, 8] のみ。長期の挙動や、観測範囲外の履歴セグメントに対する挙動は未検証。
