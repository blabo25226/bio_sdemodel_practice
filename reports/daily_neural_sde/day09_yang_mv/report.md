## 1. 論文要約

### 1.1 問題と提案

通常の Itô SDE では各軌道は独立だが、相互作用する粒子系では各粒子のドリフトが粒子全体の分布に依存する
(論文 §2)。Yang et al. は、この分布依存をニューラルネットで表現する McKean-Vlasov SDE (MV-SDE) の
アーキテクチャと推定法を提案する:

$$
dX_t = f(X_t, t)\,dt + \mathbb{E}_{y_t \sim p_t}[\varphi(X_t, y_t)]\,dt + \sigma\,dW_t,
$$

ここで p_t は X_t の法則、φ は相互作用関数である。論文は、経験測度を用いる EM (empirical measure)
アーキテクチャ、学習された測度を用いる IM アーキテクチャ、周辺法則を生成モデルで表す ML アーキテクチャの
3 種を提案し、最尤型の推定量と組み合わせる。動機付けの例は double-well ポテンシャルにおける相互作用による
相転移である (Figure 1): 相互作用なしでは粒子は独立に拡散するが、引力相互作用 φ(x, y) = −(x − y) があると、
粒子群の平均が非ゼロに留まる相が現れる。論文の主張は、分布依存を明示的に入れることで、
相互作用のある時系列・確率モデリングにおいて Itô-SDE より豊かな確率フローを表現できることである。
解析では diffusion は既知の定数 σ とされる (§2.1)。

### 1.2 本日の切り取りと選定理由 (多様性の観点)

前日までとの重なり回避: Day 1 は勾配ベース学習 (Li)、Day 2 は GAN (Kidger)、Day 3 は変分潜在モデル (Tzen)、
Day 4 は市場較正 (Gierjatowicz)、Day 5 は W₂ 分布一致 (Zhang)、Day 6 は遅延 SDDE (Eggen & Midtfjord)、
Day 7 は構造制約による安定化 (Oh et al.)、Day 8 はジャンプ拡散 (Jia & Benson) であった。いずれも
ドリフト・拡散が「現在の状態 (と時刻・履歴・ジャンプ)」のみに依存するモデルである。
本日は **ドリフトが分布そのもの (法則の平均) に依存する系**という未使用の手法系、
**相互作用粒子系・相転移**という未使用のドメイン、
**平均場入力 m_t = E[X_t] を持つ field 構造**という未使用の field 構造を選んだ。
次元は 1 次元で Day 2・Day 8 と重なるが、問いは「m を落とすと何が壊れるか」と「(x, m) の共線性のもとで
相互作用係数が同定できるか」であり、次元以外の構造はすべて新しい。
データ入手可能性: 論文は実データの時系列も用いるが、法則そのものは観測不能であるため、
憲章のスコープ境界に従い、識別可能な座標で teacher を再構成する:
有限粒子系 (アンサンブルあたり 64 粒子) の経験平均を m_t とする観測可能な MV-SDE を真値とし、合成データとして再生成する
(憲章の選定条件 (a) は「生成過程が特定できる」ことで満たす)。これは論文の EM アーキテクチャのアナロジーである。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと真値

真値は論文の Figure 1b の形式 (double-well の Itô ドリフト + 引力相互作用) である:

$$
dX_t = \big[(X_t - X_t^3) + 0.9\,(m_t - X_t)\big]\,dt + 0.6\,dW_t, \qquad
m_t = \mathbb{E}[X_t], \qquad f(x, m) = 0.1x - x^3 + 0.9m.
$$

相互作用強度 θ = 0.9、diffusion は論文の解析と同じく定数 σ = 0.6 である。
アンサンブルは 80 個 (train 40 / validation 16 / test 24、アンサンブル-disjoint)、
各アンサンブルは 64 粒子、t ∈ [0, 6]、Euler–Maruyama (dt_fine = 0.01) でシミュレーションし、
0.05 ごとに観測した (121 点)。初期条件はアンサンブルごとに m0 ~ Uniform(−1.2, 1.2) を引き、
粒子は Normal(m0, 0.6²) から独立に初期化した。
状態統計 (train query): x の範囲 [−3.42, 2.87]、m の範囲 [−1.34, 1.23]、m の標準偏差 0.737。
test 遷移は 184,320 件、train 遷移は 307,200 件である。
事前のパイロット (本パイプライン外の設計確認、seed 別) では、θ = 0.9 の系は t = 8 でもアンサンブル平均 ≈ 0.86 を保持し、
θ = 0 の系は 0.36 まで減衰することが確認されており、相互作用効果の大きさは設計段階で見込めていた。

### 2.2 逸脱の明示

1. **無限粒子極限から有限粒子系への置換**: 論文の MV-SDE は法則 p_t に依存する無限粒子極限のモデルである。
   本日は 64 粒子の有限系の経験平均を m_t とした。これは論文の EM アーキテクチャのアナロジーであり、
   有限粒子ノイズ (m_t の標準誤差 ~ 粒子標準偏差 / √64) を含む。したがって本日の結果は論文のベンチマーク性能について何も主張しない。
2. **IM・ML アーキテクチャ、実データベンチマーク、論文の最尤推定量は扱わない**。
   teacher の訓練はシリーズ標準のガウス遷移尤度 EM に置換した (方法の置換として明示する)。
3. **相互作用関数の固定**: 論文の一般の φ ではなく、Figure 1b の引力 φ(x, y) = −(x − y) に固定し、
   Itô ドリフトも同図の double-well x − x³ に固定した。ネット型の一般の f・φ のもとでの蒸留は本日とは異なる結果になりうる。
4. **粗視化の近似構造**: Δt = 0.5 の粗視化 teacher では、ステップ開始時の m をステップ全体で固定する。
   真の m はステップ内で変化するため、これは粗視化固有の近似であり、H6 の解釈に明示する。

## 3. 仮説 (実行前に config へ凍結)

- **H1 (drift 蒸留)**: symbolic drift の test NRMSE (対 teacher) ≤ 0.30。
- **H2 (diffusion 蒸留)**: symbolic g の test NRMSE (対 teacher) ≤ 0.30、かつ
  symbolic の implied Σ (= g²) の test NRMSE (対 teacher の Σ) ≤ 0.30。
- **H3 (真値回復、field 水準)**: symbolic drift の test NRMSE (対真値) ≤ 0.60、かつ
  symbolic g の test NRMSE (対真値) ≤ 0.30。
- **H3c (真値回復、係数水準)**: 事前凍結の診断 fit (factorized-free ライブラリ、しきい値 0.05) の展開後の
  線形 x 係数 (真値 0.10) の絶対誤差 ≤ 0.25、かつ m 係数 (真値 0.90、相互作用強度) の絶対誤差 ≤ 0.25。
  ただし次数 3 フルライブラリの VIF 最大値が 10 を超える場合は、係数分割は共線性制限として indeterminate と読み、
  点推定の合格・不合格として主張しない (凍結した注記)。
- **H4 (シミュレーション)**: symbolic の失敗率 ≤ 0.05 かつ teacher との差 ≤ 0.02、
  paired RMSE (対 teacher) の中央値 ≤ 1.0 (平均場フィードバックで小さい drift 差が増幅されるため緩いしきい値であり、主条項ではない)、
  かつドメイン条項として |X| > 8 の逸脱率の symbolic − teacher ≤ 0.10 かつ |m_t| > 5 の平均逸脱率 ≤ 0.05。
  失敗は non-finite または |X| > 30。各モデルは自分のシミュレーション粒子の平均から自分の m_t を計算する (自己整合的平均場)。
- **H5 (論文軸: 平均場 vs Itô)**: 両条項が成ること。
  (a) test 遷移の予測 NLL について、NLL(Itô) − NLL(MV) > 0.02 かつ paired SE の 2 倍超。
  絶対 NLL 水準も両 teacher について併記する。
  (b) 主条項は絶対水準: |m0| ≥ 0.8 の test アンサンブル部分集合において、T = 6 での平均 |m_T| について、
  MV teacher と symbolic がともに真値から 0.15 以内であり、かつ Ito の分離は相対比で測り、
  Ito の平均 |m_T| / 真値の平均 |m_T| ≤ 0.80 であること。部分集合が 4 アンサンブル未満の場合は indeterminate とする。
- **H6 (離散化バイアス診断、Day 1・Day 6・Day 7 の反省)**: 遷移数を揃えた制御比較で、
  (a) MV EM (Δt = 0.5、m 固定) の drift field NRMSE が EM (Δt = 0.05、同一遷移数) より 0.03 以上悪化すること、
  (b) 悪化幅が大 |m| レジーム (|m| > 0.8) で小 |m| レジーム (|m| < 0.3) より 0.02 以上大きいこと。
  per-transition SNR をレジーム別に定量化し、drift と diffusion (および Σ) の粗視化比較は別々に解釈する。
- **H7 (論文軸の代理: one-step 予測)**: test 遷移での one-step 平均予測 (x + f(x, m)Δt) の MSE について
  |MSE_symbolic − MSE_teacher| ≤ 0.002。paired 標準誤差を併記し、paired SE ≥ 0.001 の場合は
  点推定が合格しても「統計的に確定しない」とする (Day 4 の反省)。

## 4. 方法 (main と同じ流儀)

- teacher への直接 query で function distillation。query 点は各 split の観測 (x, m_t) ペア
  (アンサンブル-disjoint)。変換 (mean/scale) と RMS 正規化は train query のみから。
  ただし factorized-origin ライブラリでは mean を 0 に固定する (scale のみ train から)。
- teacher: MV teacher (入力 (x, m): f ネット [32, 32] tanh、g ネット [16] tanh、g = softplus + 0.01) と
  Ito teacher (入力 x のみ、同型)。両者とも train 遷移 (307,200 件) で訓練 (Adam lr 0.003、40 epochs、batch 8192)。
  粗視化ペアは各 30,720 遷移 (batch 2048、40 epochs)。
- 候補: drift はフル次数 {1, 2, 3}、factorized-free、factorized-origin、g はフル次数 {0, 1, 2}、
  STLSQ しきい値 {0.02, 0.05, 0.1, 0.2, 0.35}。
  field ごとに validation NRMSE で選択し、test は確定後に 1 回だけ評価。
- oracle 診断: 同じ SINDy 手順を真値 field に fit (天井の診断)。
- 共線性診断: fit の前に train query 状態で次数 3 フルライブラリ (定数列を除く) の VIF を計算。
- 格子診断 (Day 2 の反省により標準手順): x ∈ [−3, 3] × m ∈ [−1.5, 1.5] の 91 点格子で teacher / symbolic / 真値を比較する。選択には使わない (報告専用)。
- シミュレーション検証: test アンサンブルの初期粒子状態から、teacher / symbolic / 真値 / Ito の各モデルを
  同一 Brownian 増分 (paired) で Euler–Maruyama (dt = 0.05、t ∈ [0, 6]) によりシミュレーション。
  各モデルは自分のシミュレーション粒子の平均から自分の m_t を計算する。
  失敗は non-finite / |X| > 30 で分類し、質量を保持する。|X| > 8 の経験は「逸脱」、
  |m_t| > 5 の経験は「平均逸脱」として、失敗とは別に数える。
- 平均場汚染診断 (Day 8 のジャンプ汚染診断のアナロジー): Ito teacher の drift と MV teacher の drift を真値と比較する。

## 5. 結果

### 5.1 推定器の比較 — teacher の対真値 field 誤差 (test query 状態、184,320 点)

| teacher | drift NRMSE vs 真値 (RMS 誤差) | g NRMSE vs 真値 |
|---|---|---|
| MV (蒸留対象) | 0.1849 (0.1206) | 0.0417 (0.0250) |
| Ito (x のみ) | 0.4887 (0.3185) | 0.0407 (0.0244) |
| MV 粗視化 (Δt = 0.5) | 0.4920 (0.3207) | 0.3120 (0.1872) |
| MV 細分対照 (Δt = 0.05、同一遷移数) | 0.3243 (0.2114) | 0.0403 (0.0242) |

読み取り:

- **MV teacher は drift で真値に近い** (0.185)。Ito teacher の drift 誤差は 0.489 と 2.6 倍大きい。
  これは m を落とすことの代償である: Ito teacher は条件付き平均 E[f(x, m) | x] を学習するため、
  on-manifold では部分的に m の効果を吸収するが、field としては真値から大きくずれる。
  g については両 teacher とも真値に近い (0.041–0.042)。すなわち m の欠落は diffusion ではなく drift を汚染する。
  これは Day 8 の「ジャンプを無視すると diffusion が膨らむ」とは対照的な汚染パターンである:
  ジャンプは分散に、平均場はドリフトの平均構造に、それぞれ漏れる。
- **線形レジームと 3 次レジームでの teacher drift 誤差** (Day 1 の線形/非線形比較):
  |x| < 0.5 では NRMSE 0.0807 (RMS 0.0446、n = 44,139) と小さいが、
  |x| > 1.5 では NRMSE 0.3884 (RMS 1.5405、n = 861) と大きい。
  3 次レジームは test query の 0.5% 未満しか占めない稀な領域だが、絶対誤差は大きい。
  すなわち teacher の 3 次テールはデータが薄いために同定が弱い。

| diffusion g | フル次数 2, 0.02 | 0.0139 | **0.0145** | 0.0388 |
| diffusion の implied Σ | — | — | **0.0286** | — |
| oracle drift (天井) | フル次数 3 | — | — | 0.0000 |
| oracle g (天井) | フル次数 0 | — | — | 0.0000 |

読み取り: 蒸留そのものは on-manifold では成功しているが、drift の対 teacher 誤差 0.139 は Day 8 の 0.036 より大きい。
validation も 0.149 と同程度であり、選択の過適合ではなく、(x, m) 2 次元空間での teacher 近似そのものが難しいことを反映している
(teacher 自体の対真値誤差 0.185 が下限に近い)。
対真値の誤差は teacher の誤差でほぼ説明できる (drift: teacher 0.185 に対して symbolic 0.160 — symbolic が teacher より

### 5.3 求めた symbolic SDE (TeX、元座標)

蒸留で得た MV-SDE は次である (x = X、m = E[X]。完全展開は `outputs/daily_neural_sde/day09/symbolic_sde.tex` と同一):

```tex
%% Day 9 symbolic McKean-Vlasov SDE (Yang et al. 2024 Neural McKean-Vlasov Processes; distilled MV teacher; x = X, m = E[X])
\begin{aligned}
\hat f &= 0.01298 + 1.025\,m - 0.1439\,x - 0.002717\,m^{2} - 0.002215\,x m - 0.03416\,x^{2} - 0.1819\,m^{3} + 0.3611\,x m^{2} - 0.4363\,x^{2} m - 0.6277\,x^{3} \\
\end{aligned}
\begin{aligned}
\hat g &= 0.5939 + 6.982e-05\,m - 0.0007515\,x + 0.02788\,m^{2} - 0.05103\,x m \\
\end{aligned}
%% Mean-field SDE: dX = f(X, m) dt + g dW, m = E[X] (self-consistent ensemble mean).
```

読み取り: drift は真値 (0.1x − x³ + 0.9m) に対して、on-manifold では近いが、項別には打ち消しを含む。
m = x のスライス (相互作用が打ち消される断面) では、展開は 0.013 + 0.881x − 0.039x² − 0.885x³ となり、
真値の x − x³ に近い。すなわちスライス上では構造が回復しているが、個別係数 (特に x の線形係数 −0.144 と
m 係数 1.025 の分割) は真値 (0.1 / 0.9) とは異なる — これが §5.4 の共線性の帰結である。
g は真値 0.6 に対して 0.594 を中心とし、m² (0.028) と xm (−0.051) の小さな spurious 項を持つが、
test 対 teacher 0.014 と小さいため実害は小さい。

### 5.4 真値との比較と共線性 (H3・H3c の内訳)

train query 状態での共線性診断: 次数 3 フルライブラリ (定数列を除く) の VIF は次のとおりである:

| 項 | x | m | x² | xm | m² | x³ | x²m | xm² | m³ |
|---|---|---|---|---|---|---|---|---|---|
| VIF | 24.3 | 33.7 | 4.7 | 8.6 | 3.2 | 34.6 | **94.2** | **93.6** | 46.6 |

最大 94.2 (x²m) であり、凍結したゲート (10) を大きく超えるため、**H3c は共線性制限として indeterminate** である。
メカニズムは明確である: m は x のアンサンブル平均であり、query 点全体では m が x の位置を追跡するため、
x と m は強く連動し、特に x²m・xm²・m³ といった高次混合項は互いにほぼ重複する。
事前凍結の factorized-free 診断 fit の展開は f̂ = 0.0125 − 0.0005x − 0.036x² − 0.824x³ + 0.849m であり、
点推定としては線形 x 係数の誤差 0.101 ≤ 0.25、m 係数の誤差 0.051 ≤ 0.25 としきい値を満たすが、
ゲートが indeterminate であるため、これを「相互作用係数の回復」として主張しない。
なお、x の線形係数がほぼ 0 になったこと自体も示唆的である: 真値の 0.1 という小さな係数は、
3 次項が支配する field RMS に対して RMS 正規化しきい値 (0.05) の分解能の限界に近く、
小さい線形係数はしきい値処理で消えやすい (テストでも同現象を確認し、しきい値 0.01 では回復することを確認した)。
診断 fit の対 teacher test NRMSE は 0.149 であり、選択モデル (0.139) と同程度である。
teacher の構造充足度: teacher の f(0, 0) = 0.019 であり、原点構造はほぼ満たされている。
それでも factorized-origin ライブラリが validation で敗北したのは、teacher 自身が factorized でない spurious 項
(xm² など) を持ち、フルライブラリがそれを再現するためである。構造制約の敗北は、Day 8 と同じく teacher の性質の診断である。

### 5.7 論文軸の詳細 — H5: 平均場 vs Itô

| 比較 (test 遷移 184,320 件 / paired シミュレーション) | MV teacher | Ito teacher | symbolic | 判定 |

H5 は**否**である。ただし否の内訳は限定的であり、分けて読む必要がある。

- **phase 条項 (b) は明確に成る**。|m0| ≥ 0.8 の 8 アンサンブルにおいて、MV teacher と symbolic の平均 |m_T| は
  真値からそれぞれ 0.011 / 0.015 以内であり、Ito は真値の 0.441 倍まで減衰する。
  論文の方向性 (分布依存が相転移的な保持を生む) は、本日の設定では法則レベルで強く支持される。

  1 遷移の NLL における drift 差の寄与はおよそ (Δf²·Δt) / g² であり、

  凍結した H5 の判定としては否を維持するが、この否は「平均場モデルの有効性への反証」ではなく、
  「遷移 NLL のしきい値 (0.02) が、この Δt と drift 差の水準に対して大きすぎた」というしきい値設定の所見である。
  今後、MV vs Ito の NLL 比較では、しきい値を Δt·(drift 差)²/g² のスケールで決めるか、法則レベルの指標を主条項とすべきである。
  これは Day 8 の「率指標では絶対差ではなく相対比を」という反省の、NLL 指標版の対応物である。

## 6. 考察

1. **遷移 NLL は平均場構造に対してほぼ盲目である**。本日の最も明確な所見は、field 誤差では MV teacher (0.185) が
   Ito teacher (0.489) を大きく上回り、法則レベルでは平均 |m_T| が 0.88 対 0.39 と決定的に分かれるにもかかわらず、
   1 遷移 NLL の差が 0.0056 nats にしかならないことである。理由は dt スケーリングである:
   drift 差の NLL への寄与は (Δf²·Δt)/g² と Δt に比例し、Δt = 0.05 ではノイズフロアに埋もれる。
   平均場モデルの評価では、遷移レベルの尤度だけでなく、自己整合シミュレーションによる法則レベルの指標を主条項とすべきである。
   これは Day 5 の「分布損失だけでは field は同定されない」の裏返しである: 今度は「遷移尤度だけでは法則ダイナミクスは同定されない」。
2. **(x, m) の共線性は、平均場系における係数同定の本質的な障害である**。
   m は x の平均であるため、x と m は構造的に連動し、次数 3 ライブラリの VIF は最大 94.2 に達した。
   その結果、相互作用係数 θ の点推定 (0.849) は真値 (0.9) に近く見えても、係数分割として主張できない。
   平均場系の蒸留では、field 水準の成功と係数水準の成功を分けること (Day 1 の教訓) が特に重要であり、
   係数を論じる場合は VIF ゲートと m の変動量 (本日は m の標準偏差 0.737) を併記すべきである。
3. **構造制約の勝敗は、再び teacher の性質の診断であった**。teacher の f(0, 0) = 0.019 は原点構造をほぼ満たすが、
   factorized-origin ライブラリは validation でフル次数 3 に敗北した。敗因は原点構造の違反ではなく、
   teacher の非 factorized な spurious 項である。構造制約を課す場合は、Day 8 と同じく teacher の構造充足度を事前に測り、
   勝敗の解釈をそれに結びつけるべきである。
4. **格子の不一致は、必ずしも蒸留の失敗ではない**。本日の格子では symbolic の方が teacher より真値に近かった
   (0.432 対 0.761)。これは多項式クラスが真値の形と一致することによる平滑化効果であり、
   teacher の MLP が 2 次元 (x, m) 空間で外挿に弱いことの裏返しでもある。
   格子診断の読み取りでは、symbolic vs teacher だけでなく、teacher vs 真値と symbolic vs 真値の 3 者比較が必須である。
5. **粗視化の悪化は、平均場系では Day 6・7 の SNR 利益を上回る**。本日は粗視化が細分対照を全体で下回り、
   特に diffusion の悪化が大きかった。m 固定近似は、単なる SNR のトレードオフではなく、
   drift の誤特定を分散に漏らす構造的な誤差を導入する。粗視化比較の解釈には、近似の構造 (本日では m 固定) を明示すべきである
   (Day 8 の単一ジャンプ近似の教訓と同型)。
6. **蒸留の成功と論文の主張は別の軸**である (Day 2–8 と同じ教訓の再確認)。
   本日の H5 の否は、Yang et al. の主張への反証ではない。論文は学習された測度アーキテクチャと実データベンチマークを用いており、
   本日はその両方を切り取った経験平均版の合成系をテストしたに過ぎない。
   論文が主張していない軸での「失敗」を数えない、という姿勢を維持する。

## 7. 反省 (Day 10 以降に適用)

- 平均場系では、遷移 NLL は drift 差に対して Δt スケーリングで盲目になりうること
  (field 誤差 0.185 対 0.489、法則レベルの平均 |m_T| 0.88 対 0.39 に対し、NLL 差は 0.0056 nats に過ぎず、
  凍結しきい値 0.02 に未達)。MV vs Ito の比較では、NLL しきい値を Δt·(drift 差)²/g² のスケールで決めるか、
  自己整合シミュレーションによる法則レベルの指標を主条項とすること。
- (x, m) ライブラリの共線性は構造的であること (次数 3 フルライブラリの VIF 最大 94.2、x²m・xm² が 90 超)。
  平均場系の係数仮説には VIF ゲートと m の変動量 (標準偏差) を併記し、ゲートを超えた場合は点推定の合格を係数回復として主張しないこと。
  小さい線形係数 (真値 0.1) は 3 次項が支配する field RMS に対して RMS 正規化しきい値の分解能の限界に近く、
  しきい値処理で消えやすいため、係数仮説のしきい値は field RMS に対する相対分解能で事前に見積もること。
- 格子診断では symbolic vs teacher だけでなく teacher vs 真値と symbolic vs 真値の 3 者比較を必須とすること。
  本日は symbolic の方が teacher より真値に近く (0.432 対 0.761)、格子の不一致は主に teacher の off-manifold での野生さによるものであった
  (Day 8 とは逆の分解)。ただし絶対 RMS 誤差が大きい領域では強い外挿成功として主張しないこと。
- 粗視化比較では、平均場系の近似構造 (本日ではステップ開始時の m 固定) を明示すること。
  m 固定近似は drift の誤特定を分散に漏らし、diffusion の悪化 (g 0.040 → 0.312、Σ 0.079 → 0.513) が Day 7 とは異なる方向に出る。
- 構造制約ライブラリの勝敗は teacher の構造充足度の診断であること (本日: teacher の f(0, 0) = 0.019 で原点構造はほぼ充足するが、
  teacher の非 factorized な spurious 項のため factorized-origin は validation で敗北)。構造制約を課す場合は teacher の構造充足度を事前に測ること。
- m を落とす汚染パターンはジャンプ系とは異なること。ジャンプの無視は diffusion を膨らませたが、
  平均場の無視は drift を汚染し (Ito drift NRMSE 0.489 対 MV 0.185)、g はほぼ無傷 (0.041 対 0.042) であった。
  落とした構造がどの field に漏れるかは系ごとに測ること。

## 8. 限界

- 本日の teacher は論文の MV-SDE ではない (§2.2 の逸脱)。
  無限粒子極限の法則依存、IM・ML アーキテクチャ、論文の最尤推定量、実データベンチマークは扱っていない。
  論文のベンチマーク数値についての主張は、本日の結果では何も言えない。
  特に、H5 の NLL 条項の否は、論文の完全版に対する反証ではなく、切り取りのもとでの所見である。
- 真値の drift は多項式そのものであり、論文のネット型 f・φ の一般形ではない。
  ネット型のもとでの蒸留・係数回復は本日とは異なる結果になりうる。
- 粒子数はアンサンブルあたり 64 であり、経験平均の有限粒子ノイズを含む。粒子数を増やした場合の m_t の精度と
  VIF・係数同定への影響は未検証。
- シミュレーション horizon は t ∈ [0, 6] のみ。長期の挙動や、観測範囲外の初期平均に対する挙動は未検証。
- 格子診断は人工的な (x, m) 格子であり、実際の分布シフト (例えば相互作用強度の変化) とは異なる。
  その診断力は同時分布からの乖離と大状態域の外挿にあり、強い外挿テストではない。
- 既存 repo tests (`tests/test_distill.py` 等) は本環境 (environment.yml の完全環境ではない) では未実行。
