## 1. 論文要約

### 1.1 問題と提案

連続時間の観測から変数間の署名グラフを学ぶ。離散時間の構造方程式は、観測間隔が不揃いなとき過程を誤って表す。
SCOTCH は潜在 Itô 拡散

$$
dZ_t = f_\theta(Z_t,G)\,dt + g_\theta(Z_t,G)\,dW_t, \qquad X_t = Z_t + \epsilon_t
$$

を置き、グラフ \(G\) と潜在経路の事後を変分推論する（式 (5)、式 (9)、式 (12)、Algorithm 1）。
ドリフトと拡散はどちらもネットワークで、Appendix B の式 (33) は

$$
f_{G,d}(Z_t) = \zeta\Bigl(\sum_{i=1}^{D} G_{i,d}\, l(Z_{t,i}, e_i),\, e_d\Bigr)
$$

である。\(l\) と \(\zeta\) は共有のネットワーク、\(e_i\) はノード埋め込み、\(G_{i,d}=0\) の源は和に入らない。
拡散も同じ形で、対角かつ非零と仮定する（Assumption 2）。
観測過程そのものが Itô 拡散であるとき、大域 Lipschitz と対角拡散のもとで署名グラフは識別できる、というのが論文の識別定理である。
実験の主指標はグラフの AUROC である。

### 1.2 実験と選定理由

合成データは Lorenz-96（10 次元、\(F=10\)、\(\sigma=0.5\)）と解糖系（7 次元）である。
どちらも観測ノイズを足さない。Lorenz は 100 本、長さ 100、観測間隔 1、生成の刻み 0.005。
学習は 5000 epoch、埋め込み 32、残差接続、拡散は DECI 型で出力は sigmoid である。
DREAM3 と Netsim は範囲外である。

Day 20 は閉じた参照ドリフトの上の橋補正、Day 16 は Lie 対称、Day 11 は初期状態だけの拡散であった。
本日は、ドリフトと拡散がどちらも状態とグラフのネットワークである構造学習を選んだ。
採録は ICLR 2024 である。
Lorenz-96 の \(D=4\) は各成分が全変数に依存し、署名グラフが密になる。
疎なグラフの上で多項式が非親を落とすかを見るため、同じ観測 Itô のクラスの 3 次元立方連鎖に切った。

## 2. データと Neural SDE の入手・再構成

### 2.1 データと teacher

真の連鎖は config に凍結した。成分 1 は \((x,y)\)、成分 2 は \((y,z)\)、成分 3 は \((x,z)\) だけに依存する。

$$
\begin{aligned}
dx_t &= (-0.4\,x_t + 0.7\,y_t - 0.2\,x_t^3)\,dt + 0.4\,dW^{(1)}_t,\\
dy_t &= (-0.35\,y_t + 0.55\,z_t)\,dt + 0.4\,dW^{(2)}_t,\\
dz_t &= (0.5\,x_t - 0.45\,z_t - 0.15\,z_t^3)\,dt + 0.4\,dW^{(3)}_t.
\end{aligned}
$$

署名グラフは、行が源、列が先で

$$
G = \begin{pmatrix} 1 & 0 & 1 \\ 1 & 1 & 0 \\ 0 & 1 & 1 \end{pmatrix}.
$$

欠ける有向辺は \(z\to x\)、\(x\to y\)、\(y\to z\) である。自己ループは線形項と立方項があるので入っている。
初期値は \(N(0, 0.5^2)\)。生成は刻み 0.01、観測は 0.2、\(T=4\)、80 本。観測ノイズは足さない。
この生成の絶対値の最大は 2.16 であった。

teacher は式 (33) をドリフトと拡散に別々に置く。埋め込み 16、隠れ幅 16、softplus を 2 層、幅が合う第 2 層に残差。
拡散の頭は sigmoid で \((0,1)\) に入る。最終バイアスの初期値は \(\mathrm{logit}(0.4)\) である。
グラフは上の \(G\) に固定する。
学習は観測間隔 0.2 の Euler–Maruyama ガウス遷移の平均負対数である。
この目的は \(0.5\log(2\pi)\) を含まない。最小化の位置は変わらない。
epoch 平均は \(-1.189\) から \(-1.257\) へ下がった。
同じ訓練遷移を一括で測ると、teacher は \(-1.258\)、真の場を同じ粗い Euler で入れたものは \(-1.256\)、ドリフト 0 で \(\sigma=0.4\) のものは \(-1.210\) である。
teacher はドリフト 0 より 0.048 だけ良く、真の Euler より 0.002 だけ良い。
この 0.002 は場の同定ではない。

蒸留の query は、学習とは別の seed で teacher から進めた軌道である。
刻み 0.05、80 步、半径 8。有限な軌道は 200 本、棄却は 0 本であった。
その順に train 72、validation 24、test 24 を取り、有限な各時点を 1 行にする。
teacher の学習ノイズはこの分割を見ない。

### 2.2 逸脱の明示

1. 論文の合成系は 10 次元 Lorenz-96 と 7 次元解糖系である。本日は 3 次元の立方連鎖である。Lorenz-96 の \(D=4\) は署名グラフが完全になる。疎な非親を残すため、論文の観測 Itô クラスの中で系を取り替えた。
2. 論文は Bernoulli のグラフ事後とスパース事前 \(\exp(-\lambda_s\|G\|_F^2)\) を学ぶ。本日は \(G\) を真の署名に固定した。AUROC は範囲外である。
3. 論文の学習は潜在 ELBO である。事後ドリフト \(h_\psi\)、未来を逆順に読む GRU、制御積分 \(\tfrac12|u|^2\) を使う。本日は観測過程の 1 步ガウス尤度だけである。これは識別定理が述べる観測 Itô の側であり、Algorithm 1 ではない。
4. 埋め込みは 16 で、論文は 32 である。epoch は 600、遷移は 1600 である。論文の Lorenz は 5000 epoch、100 本、長さ 100 である。学習率の warmup は入れていない。
5. 活性化の softplus、幅が合う残差、拡散の sigmoid は、論文本文が名前を書いていない。公式実装の Lorenz 実行が `--res_connection` と `--sigmoid_output` を付け、`scotch_nns.py` が softplus を使うので、それに合わせた。
6. 拡散の最終バイアスを \(\mathrm{logit}(0.4)\) にした。論文にはない。初期の拡散を真値の定数付近に置くためである。test の数値は見ていない。
7. 実装は PyTorch の float64、CPU である。torchsde は使っていない。勾配クリップは 5 である。
8. 生成の刻みは 0.01、尤度の刻みは 0.2 である。尤度が見るのは粗い遷移であり、無限小生成そのものではない。
9. ライブラリは \((x,y,z)\) の冪だけである。ノード埋め込みもグラフも座標にしない。
10. 半径 8 は数値ガードである。

## 3. 仮説（config に事前凍結）

しきい値は、事前の試走で見た状態 RMS 約 0.9、ドリフト RMS 約 0.38、\(\sigma=0.4\)、\(T=4\)、観測刻み 0.2 の 1 步ノイズ 0.179、および系列のゲート 0.25 と VIF 10 から置いた。
その試走は真の連鎖の有限性だけを見た。teacher の fit も test 軌道も、この数値には入っていない。
test のあとでしきい値は動かしていない。

- **H1** (ドリフトの 3 成分): symbolic 対 teacher の test NRMSE \(\le 0.25\)、かつ train 平均の定数予測フロアより小さい。次数 3・しきい値 0 の天井と一致した pass は疎な回復ではない。
- **H2** (拡散の 3 成分): symbolic 対 teacher の test NRMSE \(\le 0.25\)、かつ非正の割合 \(\le 0.02\)。pass は teacher への一致であり、定数 0.4 の回復ではない。
- **H3**: 次数 3 の VIF（定数列を除く）が 10 を超えたら不定。10 以下でも閉じた形としては読まない。
- **H4**: 新しい初期状態 64 本、共有ノイズ、刻み 0.05、80 步。失敗率は teacher も symbolic も \(\le 0.05\)、差 \(\le 0.02\)。外れたら不定。内側のとき、全時点の経路 RMSE \(\le 0.45\)。
- **H5**: 別の 64 本。平均経路 RMSE は symbolic 対 teacher \(\le 0.25\)。teacher 対 teacher のフロアが 0.25 を超えたら不定。失敗率 \(\le 0.05\)。
- **H6**: 格子は各座標 \(\{-1.5,-0.75,0,0.75,1.5\}\) の直積。symbolic 対 teacher のドリフト NRMSE \(\le 0.60\)。格子の残差 RMS が軌道上の 5 倍を超えたら増幅として記録する。格子は次数の選択に使わない。訪れた範囲と重なるので、遠い外挿ではない。
- **H7**: 同じ格子の有限差分、刻み \(10^{-4}\)。teacher の非親偏微分の RMS \(\le 10^{-6}\)。symbolic の非親 RMS を親 RMS で割った比 \(\le 0.25\)。親 RMS が \(10^{-3}\) 未満なら比は不定。
- **H8**: 各成分について、真の親だけの冪ライブラリを検証だけで選ぶ。test の成分平均 NRMSE が、全変数の冪ライブラリより 0.05 を超えて悪くならない。
- **H9**: test query 上で、teacher と symbolic の両方。ドリフト対立方連鎖の NRMSE \(\le 0.45\)、拡散対定数 0.4 の NRMSE \(\le 0.20\)。teacher が 0.45 を超えたときの蒸留の pass は、立方連鎖の回復ではない。

## 4. 方法

teacher の \(f_G\) と \(g_G\) への直接 query。特徴は \((x,y,z)\)。
SINDy の標準化は train query だけから取る。
次数 \(\{1,2,3\}\)、しきい値 \(\{0, 0.02, 0.05, 0.1, 0.2, 0.35\}\)、ridge \(10^{-4}\)。
検証 NRMSE の最小。同点は小さい次数、その次に小さいしきい値。
成分ごとに別々に選ぶ。test はこの選択のあと 1 回。

選択結果: \(f_1\) は次数 3・しきい値 0（活性 20、検証 0.0205）。次数 2・しきい値 0 は検証 0.0824、次数 1 は 0.121 である。
\(f_2\) は次数 3・しきい値 0.02（活性 10、検証 0.03005）。同じ次数のしきい値 0 は検証 0.03040 で、差は \(3.5\times 10^{-4}\) である。次数 1 は 0.261 である。
\(f_3\) は次数 3・しきい値 0（活性 20、検証 0.0193）。次数 2・しきい値 0 は 0.0850 である。
拡散は 3 成分とも次数 3・しきい値 0（検証 \(6.5\times 10^{-4}\)、\(5.9\times 10^{-5}\)、\(2.6\times 10^{-4}\)）である。
親制限は、\(f_1\) が \((x,y)\) の次数 3・しきい値 0（活性 10、検証 0.0217）、\(f_2\) が \((y,z)\) の次数 3・しきい値 0（活性 10、検証 0.03005）、\(f_3\) が \((x,z)\) の次数 3・しきい値 0（活性 10、検証 0.0194）である。
2 変数の次数 3 は 10 項なので、親制限もそのライブラリの全部である。

診断として、teacher への次数 3・しきい値 0 を test で 1 回評価した。
train 行の復元抽出 8 回で、選ばれた次数としきい値の項の出現率を数えた。選択には使わない。
シミュレーションは失敗をラッチし、クラスを分ける。

訓練の一括尤度が真の Euler より 0.002 だけ良いことと、ドリフト NRMSE 0.302 は両立する。
test 上の真の線形部分の RMS は 0.256、立方部分の RMS は 0.0866、比は 0.338 である。
立方項は場の一部であって、ノイズに埋もれた端項ではない。
それでも \(x^3\) の係数は真値 \(-0.2\) に対して推定 \(+0.0329\)、\(z^3\) は真値 \(-0.15\) に対して推定 \(+0.0404\) である。
符号が逆でも H9 の 0.302 はゲート 0.45 の内側に残る。
親だけの VIF が \(f_1\) で 51.8 なので、\(x^3\) は \(x\) や \(x^2\) から分離されていない。
H9 の pass は、このゲートの内側に場の誤差が収まったという記録である。係数の回復ではない。

\(f_1\) と \(f_3\) の test NRMSE は次数 3・しきい値 0 の天井と一致する。活性は 20 で、ライブラリ 20 項の全部である。
\(f_2\) は天井 0.0307 に対して 0.0297 で、差は \(9.7\times 10^{-4}\) である。
しきい値 0 の復元抽出では、20 項のうち 9 項が 8 回とも残り、10 項は一度も残らない。1 項だけが揺れる。
しきい値 0 の \(f_1\)、\(f_3\)、拡散 3 成分は、しきい値が項を消さないので出現率は自明に 1 である。
H1 と H2 の pass は、この天井の上での teacher への近さである。

拡散の定数予測フロアは 0.016 以下である。teacher RMS 0.382 に対する絶対の揺れは約 0.006 で、水準 0.39 の 1% 台である。
symbolic の残差 RMS は \(2.7\times 10^{-4}\) まで下がるが、それはこの揺れを 20 項で追った結果である。
H2 の pass を、状態依存の拡散の式として読まない。

H4 の経路 RMSE 0.00591 は、軌道上の残差 RMS 0.00639 と同じ桁である。
共有ノイズが経路を teacher に固定している。
H5 の 0.0497 はフロア 0.0725 の横にあり、ゲート 0.25 はそのフロアの約 3.4 倍である。

## 6. 考察

SCOTCH のゲートは、非親の偏微分を構成として 0 にする。
多項式はその 0 を、偏微分の RMS では 4% 弱まで再現し、\(f_2\) では \(x\) を式から落とした。
同じ多項式は、親の中では次数 3 の全部に近く、立方項の符号を真値から反転させる。
原因は teacher の野生さだけではない。
粗い刻み 0.2 の尤度は真の Euler 尤度の 0.002 nats 以内にあり、ステップ比は 0.150 である。
teacher 自身の対真値 NRMSE が 0.302 なので、蒸留が teacher に 0.023 で付いても立方係数は戻らない。
親ライブラリの VIF 51.8 は、\(x^3\) を他の \(x\) の冪から切り離せないことを train query の上で示している。

格子の NRMSE 0.141 はゲートの内側で、絶対残差は軌道上の 15.3 倍である。
経路 RMSE 0.00591 と平均経路 0.0497 は、この軌道上の一致と、平均経路のモンテカルロフロアの横に置いて読む。

グラフ事後、AUROC、Lorenz-96、解糖系、潜在 ELBO は再現していない。
0.302 と 0.033 は、この切った teacher の場が立方連鎖と定数拡散からどれだけ離れているかの記録である。

## 7. 反省

ステップ比 0.150 のとき、粗視化した 1 步尤度は真の Euler 尤度の 0.002 nats 以内に来てもドリフト NRMSE は 0.302 のまま残る。
次数 3・しきい値 0 の天井で teacher NRMSE が 0.023 でも、真値の \(x^3\) の係数は \(-0.2\) なのに多項式は \(+0.033\) である。
親だけの次数 3 の VIF も 51.8 なので、フルライブラリの VIF の横に親ライブラリの VIF を置き、天井と一致した pass の横に、真値が持つ最高次単項式の符号を置く。
拡散の NRMSE \(10^{-4}\) は、定数予測フロア 0.016 の下にある 1% の揺れのフィットであり、状態依存の拡散の回復ではない。
